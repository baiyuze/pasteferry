隱私與必要資料

由你決定使用官方服務

新安裝預設僅使用區域網路。啟用官方公網後才連線官方信令並記錄必要連線統計；自訂伺服器不向官方回報。先嘗試直連，失敗才申請中繼並讀取機器額度摘要。

最少必要資料

網關保留去識別化裝置編號、首次與最近連線時間、每日中繼用量、必要額度綁定和累計彙總。每日裝置明細保留 90 天。這是官方服務裝置數，不是人數或全部安裝量。

內容與機器識別碼

內容與真實裝置名稱透過裝置間加密通道傳送。不收集檔名、路徑、使用者名稱、MAC、UA 或行為軌跡。原始系統識別碼不上傳；摘要只用於額度分組，並非不可偽造。

網路資訊與額度

網路端點暫時可見路由和網路位址，官方統計庫及一般代理日誌不保存這些資訊。每日 100 MB 中繼額度，含上下行，北京時間午夜重設；直連不計入。啟用後用戶端只憑裝置簽章查詢自己的額度，不申請中繼，也不讀取機器識別碼。關閉官方服務會停止其請求、輪詢及通道。

網站與稽核

本站使用既有的 Cloudflare Web Analytics，瀏覽量不代表軟體使用者數。用戶端、信令及 TURN 持續開源，網關協定和欄位公開；私有正式環境的儲存行為仍需部署稽核。
