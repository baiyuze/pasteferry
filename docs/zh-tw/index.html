2.13.1：介面縮放，文字、圖示一起放大 →

跨裝置，
複製貼上。

在 Mac、Windows、Linux 之間同步剪貼簿，不必使用同一帳號。複製記錄能搜尋、收藏，檔案和資料夾也能拖放互傳。

免費開源 · Mac / Windows / Linux / Android

快速入門 →
伺服器只負責介紹 直連，端對端加密在區域網路裡直接找到，不用伺服器

點 Mac 上的任一項目，複製到另一台電腦

複製記錄，
隨時找回。

按 ⌥VAlt+V 開啟複製記錄，搜尋並選取一筆，直接貼到目前 App。常用內容可以收藏，檔案會另存副本。

了解快速貼上 →

拖過去，
就到了。

電腦之間，檔案與整個資料夾都能拖放傳送，支援大檔案與續傳。收到的檔案集中存到「下載」。

了解隔空傳送 →

手機也能用了。

同一網路內，安卓 App 可與電腦雙向傳送照片和檔案，支援多選、儲存與分享。iPhone、iPad 可掃碼使用網頁，查看複製記錄或傳送內容，網頁須保持開啟。

了解手機端怎麼用 →

不只是同步剪貼簿。

  • 傳檔案給好友

    加入好友後直接傳送檔案，由對方確認接收。好友不會看到你的剪貼簿與複製記錄。

  • 九套主題，也能自己做

    預設、像素與七套風格主題都有深淺色。可自訂配色與背景圖，或讓 AI 產生並套用主題。

  • 端對端加密

    端對端加密，配對時核對安全指紋。伺服器只負責連線與轉送，無法解密複製或傳送的內容。
