2.6 新功能

同事的電腦，
也能拖過去。

別人的電腦不用配對，加個好友就行：對方給出好友碼，你輸入，兩邊各點一下確認。之後在隔空傳送裡把檔案拖給對方，還能附一句備註。好友之間只傳檔案，不同步剪貼簿，也看不到彼此的複製記錄。

了解給好友傳檔案 →

拖過去，
就到了。

把檔案或整個資料夾拖到雷達上的一台電腦，就直接傳過去了。不限大小，中斷了會接著傳，也不佔複製記錄。

了解隔空傳送 →

按 ⌥VAlt+V，
最近複製的都在手邊。

在任何 App 裡按一下，複製記錄就出現在螢幕中間。按數字或 Enter，選取的內容直接貼上；常用的內容收藏起來，隨時取用。

了解快速貼上 →

不只是同步剪貼簿。

  • 隔空傳送 新

    把檔案、資料夾拖到另一台電腦或好友那裡，多大都可以。

  • 快速貼上

    按 ⌥VAlt+V 叫出複製記錄，選取就貼上。

  • 檔案與資料夾

    50 MB 以內複製時就已傳好，更大的需要時再取。

  • 複製記錄與收藏

    所有裝置複製過的都在這裡，能搜尋（打拼音也行），常用的收藏起來。

  • 跨網路

    開啟「服務」，家裡和公司之間也能同步。

  • 端對端加密

    優先直連，伺服器看不到你複製了什麼。

為什麼不用現有的方法

通用剪貼板要同一個 Apple ID、距離夠近；AirDrop 每次都要點接受；傳給自己要手動下載，檔案還留在別人的伺服器上。一台 Mac 加一台 Windows 時，系統內建的方法一個都用不了。

兩台電腦怎麼連起來

同一網路裡裝好就能配對；不同網路裡，啟用「服務」即可，無需自建。也保留自建伺服器與 Tailscale，依需求選擇。

跨網路，無需自建

服務

開啟一個開關，讓家裡與公司的電腦找到彼此。優先打洞直連，失敗後自動中繼，不需購買雲端主機或填寫位址。

啟用「服務」 → 什麼都不用架設

同一網路

家裡或辦公室，連著同一台路由器。兩台電腦裝好 App，輸入配對碼就能同步，不需要伺服器，也不需要一直開著的電腦。

同一網路教學 → 自行管理容量與部署

自建公網伺服器

一台有公用 IP 的 Linux 雲端主機，最低規格就夠了。每台電腦直接連到它，在家、在公司、在外面都能用，不必另外安裝軟體。

雲端伺服器架設教學 → 跨網路，不用伺服器

Tailscale

每台電腦裝上 Tailscale、登入同一個帳號，配對時輸入對方的 Tailscale 位址。在家、在公司都能同步，不需要伺服器，也不需要一直開著的電腦。

Tailscale 教學 →

第一次用？跟著快速開始。「服務」為選用，目前預設每日 100 MB 中繼額度，直連不扣此額度。
