隔空貼 / 下載

下載隔空貼

免費開源，目前版本 2.4.1。每台要同步的電腦各裝一個，Mac、Windows、Linux 可以混用。

Windows

下載安裝程式

在中國大陸下載很慢的話，可以改用 Gitee 鏡像：安裝程式 · 可攜版

不想執行安裝程式的話，可以下載免安裝版，解壓縮後直接執行。

  1. 執行 PasteFerry-Setup.exe，它會安裝在目前使用者的目錄下，不需要系統管理員權限。出現「Windows 已保護您的電腦」時，點「其他資訊」，再點「仍要執行」。
  2. 打開隔空貼，點「啟用背景同步」。防火牆詢問時選擇允許。
  • Windows 10 與 Windows 11，x64。
  • 安裝程式約 23 MB，免安裝版約 29 MB。
  • 關掉視窗後，隔空貼會在工作列右下角的通知區域繼續執行。

macOS

Apple 晶片（M1 及更新機型） Intel 晶片

在中國大陸下載很慢的話，可以改用 Gitee 鏡像：Apple 晶片 · Intel 晶片 · 通用版

也有兩種晶片都能用的通用版，檔案大一倍。

  1. 打開下載的 DMG，把隔空貼拖進「應用程式」。
  2. 從「應用程式」裡打開。第一次會提示「無法驗證開發者」：到「系統設定 → 隱私權與安全性」，點頁面下方的「強制打開」。
  3. 點「啟用背景同步」。系統詢問是否允許讀取剪貼簿、是否允許尋找區域網路上的裝置時，都選擇允許。

不確定是哪種晶片？

  • 點螢幕左上角的蘋果選單，選「關於這台 Mac」。
  • 寫著「晶片：Apple M1」（或 M2、M3、M4 等）的是 Apple 晶片；寫著「處理器：… Intel Core …」的是 Intel 晶片。
  • 2020 年底以後買的 Mac 幾乎都是 Apple 晶片。選錯了也沒關係，換另一個下載就行：Intel 版在 Apple 晶片的 Mac 上要先安裝 Rosetta，Apple 晶片版在 Intel 的 Mac 上打不開。
  • 需要 macOS 13 Ventura 以上。

Linux

Ubuntu、Debian 及其衍生版本

x64 ARM64 
sudo apt install ./PasteFerry-linux-amd64.deb

其他發行版

x64 ARM64 
tar xzf PasteFerry-linux-amd64.tar.gz
./PasteFerry/install.sh

在中國大陸下載很慢的話，可以改用 Gitee 鏡像：.deb x64 · .deb ARM64 · tar.gz x64 · tar.gz ARM64

  • 需要圖形桌面：X11，或附有 XWayland 的 Wayland 桌面，GNOME、KDE 等主流桌面預設都有。
  • 不確定是 x64 還是 ARM64：在終端機執行 uname -m，顯示 x86_64 是 x64，aarch64 是 ARM64。
  • .deb 會裝在 /opt/PasteFerry，並出現在應用程式選單裡。tar.gz 解壓縮到哪裡都能執行，install.sh 會把它加進應用程式選單。
  • 打開後點「啟用背景同步」，之後登入時會自動啟動。GNOME 預設不顯示系統匣圖示，請從應用程式選單打開視窗。
  • 需要 GTK 3。已在 Ubuntu 24.04 的 GNOME（Wayland）上實測過。

其他

伺服器
兩台電腦在同一個網路裡不需要伺服器。跨網路時的幾種方式見快速入門，伺服器的安裝檔在各自的教學裡。
驗證檔案
所有檔案的 SHA-256 都在 SHA256SUMS 裡。
