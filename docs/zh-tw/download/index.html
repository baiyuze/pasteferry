下載隔空貼

免費開源 · 版本 2.14.1

Windows

下載安裝程式

GitHub：安裝程式 · 免安裝版

可攜版（免安裝）

快速入門 →

  • Windows 10 與 Windows 11，x64。

macOS

Apple 晶片（M1 及更新機型） Intel 晶片

GitHub：Apple 晶片 · Intel 晶片 · 通用版

也可下載通用版。

Homebrew：brew install --cask baiyuze/tap/pasteferry。安裝與升級

快速入門 →

不確定是哪種晶片？

  • 在蘋果選單中開啟「關於這台 Mac」。
  • 顯示「晶片」選 Apple 晶片版；顯示「Intel」選 Intel 版。
  • 需要 macOS 13 以上。

Linux

Ubuntu、Debian 及其衍生版本

x64 ARM64 
sudo apt install ./PasteFerry-linux-amd64.deb

其他發行版

x64 ARM64 
tar xzf PasteFerry-linux-amd64.tar.gz
./PasteFerry/install.sh

GitHub：.deb x64 · .deb ARM64 · tar.gz x64 · tar.gz ARM64

  • 需要 X11 或含 XWayland 的 Wayland 桌面，以及 GTK 3。
  • 執行 uname -m：x86_64 選 x64，aarch64 選 ARM64。

手機（安卓 App 或網頁版）

下載安卓版（APK）

GitHub：安卓版

Android 9 以上 · ARM64

網頁版（不用安裝）

電腦開啟「裝置 › 手機網頁傳輸」，用手機掃碼連線。

  1. 裝好 App 後，在電腦的「裝置」裡像配對另一台電腦一樣配對手機。
  2. 手機上複製的內容貼到隔空貼再傳送；電腦複製的內容會自動出現在手機的記錄裡。
  • 手機與電腦須在同一網路。
  • iPhone、iPad 請使用網頁版。
