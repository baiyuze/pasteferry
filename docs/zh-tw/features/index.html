隔空貼的功能

複製貼上，
本該這麼順手。

Mac、Windows、Linux 之間同步剪貼簿，複製過的隨叫隨到。

下載隔空貼 ▶ 看完整示範

在這台複製，
到那台貼上。

按下 ⌘CCtrl+C，內容就同步到你的其他電腦，到那邊按 ⌘VCtrl+V 貼上。不用同一個帳號，Mac、Windows、Linux 隨意搭配。

MacBook⌘C
WindowsCtrl+V
LinuxCtrl+V

  • 文字、圖片、檔案、資料夾

    帶格式的文字貼到只認純文字的地方，也不會冒出標籤。

  • 50 MB 以內，複製時就傳好

    更大的先同步一筆記錄，需要時點一下再取。上限可以調。

  • 對方離線也不會漏

    這段期間複製的，連上後補進對方的複製記錄。

2.5 新功能

檔案再大，
拖過去就行。

打開「隔空傳送」，同一網路和別處的電腦都在雷達上。把檔案或資料夾拖到其中一台，就直接傳過去：不經雲端硬碟，不用傳輸線，也不進複製記錄。

  • 不限大小

    幾個 GB 的影片、上萬個檔案的資料夾，一次傳過去。列表裡看得到進度、速度和剩餘時間。

  • 中斷了接著傳

    斷網、睡眠或程式結束，連上後從中斷處繼續。每個檔案都會校驗，不完整的不會出現。

  • 收到的放在一起

    預設存到「下載」，可以在設定裡更改。點一下就能在 Finder 或資料夾裡找到。

跨網路也能傳：能直連就直連；只能走服務中繼時，每天有 100 MB 額度，傳之前會先問你，用自己的伺服器中繼則沒有這個限制。兩台都要是 2.5 或更新的版本。

按 ⌥VAlt+V，
最近複製的都在手邊。

不用切到隔空貼，也不用翻聊天記錄。在任何 App 裡按一下快速鍵，選一筆，它就貼到你剛才的游標處。

  2. 2

    打幾個字

  3. 3

    按 ↩Enter，就貼好了

    內容直接貼到剛才的游標處。⇧↩Shift+Enter 貼上純文字，⌘↩Ctrl+Enter 只複製不貼上。

快速鍵可以在設定裡更換或關閉。Mac 上直接貼上需要授予「輔助使用」權限，沒授權時選取的內容放進剪貼簿，再由你按 ⌘V；Linux 的 Wayland 桌面上也是選取後按 Ctrl+V。

常用的，
收藏起來。

週報範本、會議連結、常用回覆，點一下星號就另存一份。收藏不會過期，清空複製記錄也還在。

  • 不會被清除

    複製記錄到期自動清除，收藏一直留著。

  • 另存一份

    原檔案之後改動或刪除，都不影響收藏裡的那份。

  • 快速貼上視窗裡也有

    切到「收藏」分頁，或者按 ⌘DCtrl+D 收藏選取的那一筆。

停一下，就看到全文

滑鼠在一筆上停半秒，彈出完整的文字、放大的圖片或全部檔名，不用點開。

三天裡複製的，搜得到

按文字內容或檔名搜尋，中文還能打拼音（hy 就能找到「會議」）。點一下就放回剪貼簿，記錄預設保留 3 天，最長 30 天。

整個資料夾也行

複製一個資料夾，到另一台貼上的就是同樣的資料夾，結構不變。

  • design-assets
  • logo.svg
  • banner@2x.png
  • fonts

檔名不打架

Mac 上能用、Windows 上不合法的字元，收到時換成全形字元，檔名照樣看得懂。

Mac會議記錄 10:30?.md
Windows會議記錄 10：30？.md

家裡和公司，
也能直連。

同一網路裡裝好就能配對。不在同一網路時，開啟「服務」就行，不用自己架伺服器。兩台電腦優先打洞直連，打不通才加密中繼。

  • 同一網路

    不需要伺服器，輸入配對碼就行。

  • 跨網路

    「服務」、自架伺服器或 Tailscale，任選一種。

  • 端對端加密

    配對時核對安全指紋，伺服器看不到內容。
