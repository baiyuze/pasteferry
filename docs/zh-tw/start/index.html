快速入門

裝好 App，選一種連線方式，再把兩台電腦配對。同一個網路裡幾分鐘就好。

  1. 安裝 App
  2. 選擇連線方式
  3. 配對
  4. 手機怎麼用

第 1 步

在每台電腦上安裝 App

每台要同步的電腦都裝一個，Mac、Windows、Linux 可以混用。

Mac

  1. 下載 DMG，打開後把隔空貼拖進「應用程式」。Apple 晶片與 Intel 晶片各有一個版本，下載頁會告訴你怎麼選。
  2. 從「應用程式」裡打開。第一次會提示「無法驗證開發者」：到「系統設定 → 隱私權與安全性」，點頁面下方的「強制打開」。
  3. 點「啟用背景同步」。系統詢問是否允許讀取剪貼簿、是否允許尋找區域網路上的裝置時，都選擇允許。
下載 Mac 版

Windows

  1. 執行 PasteFerry-Setup.exe，不需要系統管理員權限。出現「Windows 已保護您的電腦」時，點「其他資訊」，再點「仍要執行」。
  2. 打開隔空貼，點「啟用背景同步」。防火牆詢問時選擇允許。關掉視窗後，它會在右下角的通知區域繼續執行。
下載 Windows 版

Linux

  1. Ubuntu、Debian 等發行版安裝 .deb；其他發行版解壓縮 tar.gz，執行裡面的 install.sh。
  2. 從應用程式選單打開隔空貼，點「啟用背景同步」。
下載 Linux 版

第 2 步

選擇一種連線方式

在同一個網路裡，裝好就能配對。不在同一個網路，開啟「服務」就行。想自己掌控，也可以自建伺服器或用 Tailscale。

服務

  1. 每台電腦裝好最新版，點「啟用背景同步」。
  2. 在「設定 → 連線」裡開啟「使用服務」。
  3. 兩台電腦配對。已經配對過的不用重配。

新安裝預設關閉。伺服器收不到你複製的內容，詳見隱私權說明。

開啟「服務」 →
能直連就不中繼
能直連就直連，連不上才經伺服器轉送。內容加密，伺服器解不開。
中繼每天 100 MB，直連不限
中繼每台電腦每天 100 MB，直連不限。用量頁能看到還剩多少。

同一網路

  1. 每台電腦裝好 App，點「啟用背景同步」。
  2. Windows 防火牆和 macOS「尋找區域網路上的裝置」的詢問都選允許。
  3. 一台顯示配對碼，另一台輸入，核對指紋。不在同一網段時，再填配對碼下方的位址，見同一網路教學。

不用填伺服器位址。

同一網路教學 →
適合
家裡或辦公室，兩台電腦連同一個 Wi‑Fi 或有線網路。
要準備
不用準備，每台電腦裝好 App 就行。
要注意
離開這個網路就不同步，回來自動恢復。有線和無線不在同一個網段時，配對時多填一個位址。

自建公網伺服器

  1. 在雲端服務商的安全群組裡開放 TCP 8787、UDP 3478 和 UDP 32768–60999。
  2. 用 ssh 登入伺服器，下載並執行安裝腳本：sudo ./install.sh 公用IP。
  3. 每台電腦在「設定 → 連線」裡填 ws://公用IP:8787/signal，按 Enter，再配對。

用瀏覽器打開 http://公用IP:8787/healthz，顯示 ok 就裝好了。

雲端伺服器架設教學 →
適合
想自己掌控伺服器，或中繼流量用得多。
要準備
一台有公用 IP 的 Linux 雲端主機，需要 root。
要注意
雲端主機要花錢；中繼速度受它的頻寬限制。用中國大陸的雲端主機、網域沒有 ICP 備案時，用戶端要填 IP。

Tailscale

  1. 每台電腦裝上 Tailscale，登入同一個帳號。
  2. 在對方電腦上執行 tailscale ip -4，記下 100 開頭的位址。
  3. 配對時點「不在同一網段？」，填上這個位址。

不需要伺服器。Tailscale 位址不會變，配對時填一次就行。

Tailscale 教學 →
適合
已經在用 Tailscale，或不想依賴任何伺服器。
要準備
每台電腦都裝 Tailscale，登入同一個帳號。
要注意
Tailscale 要一直連著。它自己打不通時會走海外中繼，在中國大陸會慢。

第 3 步

把兩台電腦配對

每兩台電腦之間配對一次，之後就不用再管了。

  1. 在一台電腦上打開「裝置」，點「新增裝置」，會顯示一組 6 碼的配對碼，5 分鐘內有效，下面是這台電腦的位址。
  2. 在另一台電腦上點「新增裝置 → 輸入配對碼」。用「服務」時不用填 IP；只有區域網路跨網段或用 Tailscale 時，才展開位址欄填對方的位址。
  3. 兩邊螢幕會顯示同樣的兩行安全指紋。逐字核對一致後，再點確認。這一步能防止有人在中間冒充你的裝置，不要跳過。

手機怎麼用

兩台電腦照上面配好之後，手機隨時可以加入：掃碼用網頁版，或者裝安卓 App。

網頁版：不用安裝

  1. 電腦：打開「裝置 › 手機網頁傳輸」，把開關打開，出現 QR 碼。
  2. 手機：用相機或瀏覽器掃這個碼，起個名字（比如「我的iPhone」）。
  3. 之後手機瀏覽器裡就是電腦的複製記錄：點「複製」到手機，或在「傳送」裡把文字、照片、檔案傳到電腦。

安卓 App：像配電腦一樣配對

  1. 手機：下載 APK 並安裝（設定裡允許安裝未知來源的應用）。
  2. 電腦：「裝置 → 新增裝置 → 顯示配對碼」。
  3. 手機：輸入配對碼，核對兩邊的指紋一致後確認。
  4. 之後電腦複製的內容自動出現在手機的記錄裡並寫入剪貼簿。

複製看看。

在一台電腦上複製文字、圖片或檔案，到另一台按 ⌘V 或 Ctrl+V。兩邊複製過的內容都在「複製記錄」裡。
