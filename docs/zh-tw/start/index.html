隔空貼 / 快速入門

快速入門

裝好 App，選一種連線方式，再把兩台電腦配對。在同一個網路裡幾分鐘就好，之後複製就會自動同步。

  1. 安裝 App
  2. 選擇連線方式
  3. 配對

第 1 步

在每台電腦上安裝 App

每台要同步的電腦都裝一個，Mac、Windows、Linux 可以混用。

Mac

  1. 下載 DMG，打開後把隔空貼拖進「應用程式」。Apple 晶片與 Intel 晶片各有一個版本，下載頁會告訴你怎麼選。
  2. 從「應用程式」裡打開。第一次會提示「無法驗證開發者」：到「系統設定 → 隱私權與安全性」，點頁面下方的「強制打開」。
  3. 點「啟用背景同步」。系統詢問是否允許讀取剪貼簿、是否允許尋找區域網路上的裝置時，都選擇允許。
下載 Mac 版

Windows

  1. 執行 PasteFerry-Setup.exe，不需要系統管理員權限。出現「Windows 已保護您的電腦」時，點「其他資訊」，再點「仍要執行」。
  2. 打開隔空貼，點「啟用背景同步」。防火牆詢問時選擇允許。關掉視窗後，它會在右下角的通知區域繼續執行。
下載 Windows 版

Linux

  1. Ubuntu、Debian 等發行版安裝 .deb；其他發行版解壓縮 tar.gz，執行裡面的 install.sh。
  2. 從應用程式選單打開隔空貼，點「啟用背景同步」。
下載 Linux 版

第 2 步

選擇一種連線方式

同一網路裡裝好就能配對；不同網路裡，啟用官方服務即可，無需自建。也保留自建伺服器與 Tailscale，依需求選擇。

官方服務

  1. 在每台需要同步的電腦上安裝最新版本，啟用背景同步。
  2. 在每台電腦的「設定」中開啟「使用官方服務」，閱讀並確認必要統計說明。不需填寫官方網域或連接埠。
  3. 一台產生配對碼，另一台輸入；核對兩邊的安全指紋後確認。原有配對關係可繼續使用。

新安裝預設關閉。啟用後記錄必要連線統計；僅申請中繼時衍生專案專用機器摘要。真實裝置名稱、原始系統識別碼和複製內容不作為統計上傳。完整欄位與保留期限見隱私說明。

啟用官方服務 →
先直連，再中繼
官方信令只協助在線裝置交換連線資訊。用戶端先透過 STUN 探測和打洞；本輪直連失敗後，才申請官方中繼。傳輸內容始終端到端加密。
直連不消耗中繼額度
目前預設每機器額度組每日 100 MB 中繼流量，上傳與下載合計，北京時間午夜重設。重新安裝不保證獲得新額度。開啟後用量頁即顯示今日額度、剩餘量與更新時間，不必先使用中繼，並列出每台裝置目前是直連還是中繼；額度用完仍可直連。額度與服務可用性可能調整，以用戶端顯示為準。

同一網路

  1. 每台電腦裝好 App，點「啟用背景同步」。
  2. Windows 防火牆詢問時選擇允許；macOS 詢問是否允許尋找區域網路上的裝置時，也選擇允許。
  3. 一台顯示配對碼，另一台輸入它，再核對指紋。不在同一個網段時，還要輸入配對碼下方顯示的位址，見同一網路教學。

不需要填伺服器位址。

同一網路教學 →
適合
電腦都在同一個 Wi‑Fi 或有線網路裡，例如家裡或辦公室。
要準備
什麼都不用。每台電腦裝好 App 就行。
要注意
離開這個網路就不會同步，回來後自動恢復。公司裡有線和無線不在同一個網段時，配對時要多輸入一個位址。

自建公網伺服器

  1. 在雲端服務商的安全群組裡開放 TCP 8787、UDP 3478 和 UDP 32768–60999。
  2. 用 ssh 登入伺服器，下載並執行安裝腳本，帶上它的公用 IP：sudo ./install.sh 公用IP。
  3. 在每台電腦的「設定」裡填入伺服器位址 ws://公用IP:8787/signal，按 Enter，再進行配對。

在瀏覽器裡開啟 http://公用IP:8787/healthz，看到 ok 就表示裝好了。

雲端伺服器架設教學 →
適合
自行管理容量與部署
要準備
一台有公用 IP 的 Linux 雲端主機，最低規格就夠，需要 root。
要注意
雲端主機要花錢。直連打不通時改走中繼，速度受伺服器頻寬限制。用中國大陸的雲端主機、網域又沒有 ICP 備案時，用戶端要填 IP。

Tailscale

  1. 每台電腦裝上 Tailscale，登入同一個帳號。
  2. 在要配對的那台電腦上執行 tailscale ip -4，記下 100 開頭的位址。
  3. 配對時，在輸入配對碼的那台點「不在同一網段？」，填上這個位址。

不需要伺服器。Tailscale 位址不會變，只在配對時輸入一次。

Tailscale 教學 →
適合
電腦在不同的網路裡，又沒有雲端伺服器。
要準備
每台電腦都裝 Tailscale，登入同一個帳號。
要注意
所有使用隔空貼的電腦都要裝 Tailscale 並保持連線。Tailscale 自己打不通時會經海外中繼，在中國大陸會比較慢。

第 3 步

把兩台電腦配對

每兩台電腦之間配對一次，之後就不用再管了。

  1. 在一台電腦上打開「裝置」，點「新增裝置」，會顯示一組 6 碼的配對碼，5 分鐘內有效，下面是這台電腦的位址。
  2. 在另一台電腦點「新增裝置 → 輸入配對碼」。官方服務無需填寫 IP；僅區域網路跨網段或 Tailscale 配對時，展開位址欄填寫對方位址。
  3. 兩邊螢幕會顯示同樣的兩行安全指紋。逐字核對一致後，再點確認。這一步能防止有人在中間冒充你的裝置，不要跳過。

複製看看。

在一台電腦上複製文字、圖片或檔案，到另一台按 ⌘V 或 Ctrl+V。兩邊複製過的內容都在「複製記錄」裡。
