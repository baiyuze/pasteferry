隔空貼 / 快速入門

快速入門

  1. 安裝 App
  2. 選擇連線方式
  3. 配對
  4. 手機怎麼用

第 1 步

在每台電腦上安裝 App

Mac

  1. 下載 DMG，將隔空貼拖入「應用程式」。
  2. 首次開啟受阻時，到「系統設定 → 隱私權與安全性」按「強制打開」。
  3. 啟用背景同步，允許剪貼簿與區域網路權限。
下載 Mac 版

Windows

  1. 執行安裝程式；SmartScreen 阻擋時，按「其他資訊 → 仍要執行」。
  2. 啟用背景同步，並允許防火牆存取。
下載 Windows 版

Linux

  1. Ubuntu、Debian 等發行版安裝 .deb；其他發行版解壓縮 tar.gz，執行裡面的 install.sh。
  2. 從應用程式選單打開隔空貼，點「啟用背景同步」。
下載 Linux 版

第 2 步

選擇一種連線方式

同一網路直接連線；跨網路請選「服務」、自架伺服器或 Tailscale。

服務

  1. 在「設定 → 連線」裡開啟「使用服務」。
開啟「服務」 →

每台電腦每天 100 MB 中繼流量，直連不限。

同一網路

  1. 兩台電腦連接同一 Wi-Fi 或有線網路。
同一網路教學 →

不需伺服器

自建公網伺服器

  1. 依架設教學安裝伺服器。
  2. 在「設定 → 連線」填入產生的伺服器位址。
雲端伺服器架設教學 →

自己的伺服器，中繼不限量

Tailscale

  1. 每台電腦裝上 Tailscale，登入同一個帳號。
  2. 在對方電腦上執行 tailscale ip -4，記下 100 開頭的位址。
Tailscale 教學 →

跨網路，不用伺服器

第 3 步

把兩台電腦配對

  1. 一台電腦開啟「裝置 → 新增裝置」，顯示配對碼。
  2. 另一台輸入配對碼；跨網段或使用 Tailscale 時，補填對方位址。
  3. 核對兩邊的安全指紋一致後確認。

手機怎麼用

手機與電腦連接同一網路，選擇安卓 App 或網頁版。

網頁版：不用安裝

  1. 電腦開啟「裝置 › 手機網頁傳輸」。
  2. 手機掃碼，輸入裝置名稱。
  3. 查看複製記錄，或傳送文字、照片與檔案。

安卓 App：像配電腦一樣配對

  1. 手機：下載 APK 並安裝（設定裡允許安裝未知來源的應用）。
  2. 電腦：「裝置 → 新增裝置 → 顯示配對碼」。
  3. 手機：輸入配對碼，核對兩邊的指紋一致後確認。
  4. 之後電腦複製的內容自動出現在手機的記錄裡並寫入剪貼簿。

複製看看。
