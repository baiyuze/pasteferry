隔空貼 / 主題教學

換主題，
做主題，讓 AI 幫你做。

隔空貼 2.10 起支援主題：內建預設和像素兩套，也可以複製一份改成自己的，或者讓 AI 幫你配一套。主題只用於設定它的那台裝置。

下載 2.10

直接看 AI 怎麼做主題 ↓

換一個主題

  1. 打開隔空貼，進入 設定 › 外觀。
  2. 在「內建」或「自訂」裡點一張主題卡片，介面馬上換好；快速貼上視窗也跟著換。
  3. 在「淺色與深色」裡選 跟隨系統、淺色 或 深色。
  4. 用像素主題時，還可以打開 掃描線，整個視窗疊一層很淡的 CRT 掃描線。
  5. 手機（Android）上在 設定 › 外觀 裡單獨選，電腦和手機互不影響。

內建的兩套主題

  • 預設：安靜的系統風格，和以前的隔空貼一樣。
  • 像素：點陣字、切角粗邊、凸起的按鈕，石墨與紙兩套配色加像素綠；頁首有夜景或白天的場景，傳檔案時紙飛機飛過去，送達迸出星星。

做自己的主題

最簡單的辦法是複製一份內建主題再改：

  1. 在 設定 › 外觀 裡，滑鼠移到一張主題卡片上，點右下角的 ⋯，選 複製一份。新主題出現在「自訂」裡。
  2. 在副本的 ⋯ 裡選 匯出…，得到一個 .pasteferry-theme.json 檔案。
  3. 用任何文字編輯器修改裡面的顏色、名稱等（格式見下一節）。
  4. 回到外觀頁，點 匯入主題… 選這個檔案。同一個 id 會覆蓋原來那份，匯入後自動套用。
  5. 不要的自訂主題，在 ⋯ 裡選 刪除主題。內建主題不能刪除。

儲存時會檢查文字和背景的對比度。看不清楚的顏色會提示出來，但仍然可以儲存。主題檔案可以傳給朋友，對方匯入即可。

主題檔案長什麼樣

主題是一份 JSON。只寫想改的地方就好，沒寫的從 base 指定的主題補齊。下面這份以像素主題為底，只換了強調色和幾處底色：

{
  "schema": 1,
  "id": "sunset-pixel",
  "name": { "zh-Hans": "落日像素", "en": "Sunset Pixel" },
  "base": "pixel",
  "modes": {
    "dark": { "accent": "#FF8A5B", "background": "#16110F", "surface": "#1E1714" },
    "light": { "accent": "#C2410C" }
  }
}

常用欄位

id
主題的識別碼，只能用小寫字母、數字和 -；不能是 default、pixel。
name
各語言的名稱，例如 zh-Hans、zh-Hant-TW、zh-Hant-HK、en、ja。
base
以哪套主題為底：default、pixel 或另一套自訂主題。
modes.light / modes.dark
淺色、深色兩套顏色，寫成 #RRGGBB 或帶透明度的 #AARRGGBB。常用的有 accent（強調色）、background（內容區底色）、sidebar、surface（分組與對話框）、border、text、textDim、textFaint、onAccent（強調色上的文字）。
typography
字型：family 可選 system 或內建的像素字型 FusionPixel。
shape
形狀：corner 是 round（圓角）或 pixel（像素切角），還有圓角大小、邊框粗細、陰影樣式。
motion、icons
動態 smooth / stepped / reduced；圖示 system / pixel。

完整的格式與每個顏色用在哪裡： design/themes.md

讓 AI 幫你做主題

隔空貼內建一個 MCP 服務 pasteferry-cli mcp。把它加到 Claude Desktop、Claude Code、Cursor 等支援 MCP 的 AI 應用程式裡，直接用一句話描述你想要的樣子，AI 會讀取主題格式、配色、檢查對比度，再儲存並套用。

1. 找到 pasteferry-cli

Mac
/Applications/PasteFerry.app/Contents/Helpers/pasteferry-cli（用 Homebrew 安裝的可以直接寫 pasteferry-cli）
Windows
%LOCALAPPDATA%\Programs\PasteFerry\pasteferry-cli.exe
Linux
deb 套件：/usr/bin/pasteferry-cli；tar.gz：解壓目錄裡的 PasteFerry/pasteferry-cli

也可以在 設定 › 外觀 › 讓 AI 幫你做主題 裡直接複製本機的完整設定，路徑已經填好。

2. 加到 AI 應用程式裡

Claude Desktop（設定 › 開發者 › 編輯設定）和 Cursor（~/.cursor/mcp.json）的設定相同，以 Mac 為例：

{
  "mcpServers": {
    "pasteferry": {
      "command": "/Applications/PasteFerry.app/Contents/Helpers/pasteferry-cli",
      "args": ["mcp"]
    }
  }
}

Claude Code 在終端機裡執行：

claude mcp add pasteferry -- /Applications/PasteFerry.app/Contents/Helpers/pasteferry-cli mcp

改完設定後重新啟動 AI 應用程式。隔空貼要保持執行，AI 透過它在本機的背景服務修改主題。

3. 直接說你想要什麼

  • “幫我做一套賽博龐克風的主題，霓虹粉配深紫，然後套用上。”
  • “以像素主題為底，做一套落日色調的，深色模式用暖一點的底色。”
  • “現在這套主題的灰色文字看不清楚，幫我調亮一點。”
  • “把我的主題匯出給我看看，再做一個淺色版本。”

AI 能做什麼

  • 列出主題、讀取某套主題的完整內容；
  • 讀取主題格式說明：每個顏色用在哪裡、要和誰達到多少對比度；
  • 只檢查不儲存，看看哪對顏色對比度不夠；
  • 儲存、套用、刪除自訂主題，切換淺色深色；
  • 匯入本機的一張圖片作為背景，並分析亮度和主色。

安全範圍

MCP 服務只在本機執行，不開網路連接埠。它只能讀寫主題和背景圖，看不到複製記錄、裝置和好友，也不能改其他設定；背景圖只接受本機檔案，不會去網路上下載。

常見問題

主題會同步到我的其他裝置嗎？

不會。主題只用於設定它的那台裝置。想在別台電腦上用同一套，匯出再匯入即可。

AI 把主題改亂了怎麼辦？

在 設定 › 外觀 裡點回 預設 或 像素 就恢復了；不要的自訂主題可以刪除。

匯入時提示文字可能看不清楚？

代表有幾處文字和底色的對比度偏低。可以照提示把對應的顏色調亮或調暗，也可以直接讓 AI 幫你調。

舊版本能用主題嗎？

需要 2.10 或更新的版本。裝置之間的協定沒有變化，新舊版本照常互傳。
