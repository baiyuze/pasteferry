隔空貼

常見問題

沒找到答案的話，歡迎回報。

和 Mac 內建的「通用剪貼板」有什麼不同？

通用剪貼板只在同一個 Apple ID 的蘋果裝置之間、離得近時有效。隔空貼不看帳號，Mac、Windows、Linux 都行，家裡和公司之間也能用。

和 AirDrop 有什麼不同？

AirDrop 只在附近的蘋果裝置之間能用。隔空貼的「隔空傳送」Mac、Windows、Linux 互相都能傳，不在同一個網路也行。它不能和蘋果的 AirDrop 互通，兩邊都要裝隔空貼。

一定要自己準備伺服器嗎？

不用。同一個網路裡裝好就能配對；不在同一個網路，開啟服務就行。也可以用自建伺服器或 Tailscale。

家裡沒有公用 IP，能在家和公司之間同步嗎？

可以，開啟服務就行。

伺服器能看到我複製的內容嗎？

看不到，內容是端對端加密的。詳見隱私說明。

中繼額度有多少？

每台電腦每天 100 MB，直連不算。用完了直連照樣能用；要不限量可以自建伺服器。

在同一個網路裡，為什麼找不到另一台？

多半是不在同一個網段，或被防火牆擋了。配對時點「不在同一網段？」填對方位址，詳見同一網路教學。

能把檔案傳到別人的電腦上嗎？

可以。2.6 起加個好友就能傳，不用配對，對方點接受才開始傳。好友看不到你的剪貼簿和複製記錄。

大檔案怎麼處理？

50 MB 以內複製時就傳好；更大的要用時再取，或用「隔空傳送」直接傳，不限大小。

支援 Windows 和 Linux 嗎？iPhone 呢？

支援 Windows 10、11 和 Linux（x64、ARM64）。iPhone 和 iPad 暫不支援，iOS 不讓 App 在背景讀取剪貼簿。

為什麼第一次打開時系統會擋一下？

還沒有做 Apple 公證和 Windows 程式碼簽章。Mac 上到「系統設定 → 隱私權與安全性」點「強制打開」；Windows 上點「其他資訊」→「仍要執行」。只需要一次。

免費嗎？公司能用嗎？

免費，個人和公司都能用。隔空貼以 GNU AGPL-3.0 開源。

公司網路（雙線路、多出口）能直連嗎？

可以，隔空貼會把每個出口都試一遍。

開著 UU 遠端時，為什麼一直冒出 .uuremote_ 檔案？

這是舊版本的問題，更新到新版就好了。
