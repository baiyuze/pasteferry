隔空貼

常見問題

安裝、連線、同步、費用。沒找到答案的話，歡迎回報。

和 Mac 內建的「通用剪貼板」有什麼不同？

通用剪貼板只在同一個 Apple ID 的蘋果裝置之間有效，還要離得近。隔空貼不看帳號，Mac、Windows、Linux 都能互通，家裡和公司之間也能同步，複製過的內容還能在複製記錄裡找回來。

如果你只有兩台同一個 Apple ID 的 Mac，平時主要複製文字，系統內建的就夠用了。

和 AirDrop 有什麼不同？

AirDrop 只在蘋果裝置之間、離得近時能用，每次都要對方點接受。隔空貼的「隔空傳送」在 Mac、Windows、Linux 之間都能傳，不在同一個網路也行，大檔案斷了能接著傳。自己的電腦之間不用點接受；傳給好友時，對方點一下接受。

一定要自己準備伺服器嗎？

不用。兩台電腦在同一個網路裡，裝好就能配對。不在同一個網路，在兩台電腦上開啟服務就行，不用買雲端主機，也不用填位址。

想自己掌控的話，也可以用自建伺服器或 Tailscale。

家裡沒有公用 IP，能在家和公司之間同步嗎？

可以。開啟服務，兩台電腦會先嘗試直接相連，大多數家用寬頻和公司網路都連得上；連不上時經伺服器轉送，每天有 100 MB 額度。

伺服器能看到我複製的內容嗎？

看不到。內容只有你的裝置能解密：直連時不經過伺服器，走中繼時伺服器轉送的也只是加密後的資料。

用「服務」時，伺服器會記錄連線和計算額度所需的資訊，詳見隱私說明。用戶端和伺服器的程式碼都是公開的。

中繼額度有多少？用完了怎麼辦？

每台電腦每天 100 MB，上傳下載合計，北京時間午夜重設。直連不算額度，用完了直連照樣能用。額度以後可能調整，以 App 裡顯示的為準。

中繼用得多的話，可以自建伺服器，不限量。

在同一個網路裡，為什麼找不到另一台？

先確認兩台真的在同一個網段：公司裡的有線和無線、訪客網路、開了「AP 隔離」的 Wi‑Fi 常常不互通。這時在輸入配對碼的那台點「不在同一網段？」，填上另一台配對碼下方顯示的位址。

Windows 上，第一次執行時防火牆會詢問，要選允許；按過取消的話，在「設定 → 連線」裡點「允許」。Mac 上，在「系統設定 → 隱私權與安全性 → 本機網路」裡開啟 PasteFerry Daemon。更多說明見同一網路教學。

能把檔案傳到別人的電腦上嗎？

可以。2.6 起可以加好友：對方在「好友」頁點「新增好友」給出好友碼，你輸入，兩邊確認就加上了，不用配對。之後把檔案拖到對方的頭像上，對方點接受就開始傳，還能附一句備註。

好友之間只傳檔案和圖片，看不到彼此的剪貼簿、複製記錄和裝置。誰能傳給你，在隔空傳送頁底部選：均不允許、僅限好友或所有人（只在區域網路，10 分鐘後自動關閉）。

大檔案怎麼處理？

50 MB 以內的內容，複製時就已經傳到另一台，那邊直接貼上。更大的檔案先只同步一筆記錄，需要時在複製記錄裡點「接收」再傳。這個上限可以在設定裡改。

想把大檔案直接傳給某一台，用「隔空傳送」：不限大小，斷了接著傳。

公司網路（雙線路、多出口）能直連嗎？

可以。這類網路有好幾個出口，隔空貼會把每個出口的位址都偵測出來，交給對方逐一嘗試。實測公司 4 個出口的網路和家用寬頻之間可以直連。對方的路由器每次隨機換連接埠時，還是只能中繼。

支援 Windows 和 Linux 嗎？iPhone 呢？

支援 Windows 10、11（x64）和 Linux（x64、ARM64，X11 或附有 XWayland 的 Wayland 桌面，GNOME、KDE 預設都有）。複製的檔案貼上後就是真正的檔案，能直接貼進檔案總管、檔案管理員、WeChat、Office。

iPhone 和 iPad 暫不支援：iOS 不讓 App 在背景讀取剪貼簿，做不到複製完就同步。

為什麼第一次打開時系統會擋一下？

隔空貼還沒有做 Apple 公證和 Windows 程式碼簽章，這兩樣都要每年付費買憑證。

Mac 上到「系統設定 → 隱私權與安全性」，點頁面下方的「強制打開」；Windows 上在「Windows 已保護您的電腦」裡點「其他資訊」，再點「仍要執行」。只需要一次。

免費嗎？公司能用嗎？

免費。隔空貼以 GNU AGPL-3.0 開源，個人和公司都能免費使用、自由修改。如果你散布它，或把改過的版本放到網路上給別人用，需要同樣公開原始碼。

開著 UU 遠端時，為什麼一直冒出 .uuremote_ 檔案？

UU 遠端會往剪貼簿裡寫入暫時的佔位檔案，1.3.2 以前的隔空貼把它們當成一般檔案同步。更新到新版就好了，正常的空檔案、隱藏檔案不受影響。
