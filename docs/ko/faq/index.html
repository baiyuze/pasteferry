PasteFerry

질문

답을 찾을 수 없나요? 우리에게 알려주세요.

이것이 범용 클립보드와 어떻게 다릅니까?

범용 클립보드는 동일한 Apple ID에 있는 근처 Apple 장치 사이에서만 작동합니다. PasteFerry 는 계정에 신경 쓰지 않고 Mac, Windows 및 Linux, 집과 사무실 사이에서 작동합니다.

이것이 AirDrop와 어떻게 다른가요?

AirDrop 는 근처의 Apple 장치 사이에서만 작동합니다. PasteFerry의 파일 보내기는 네트워크를 통해 Mac, Windows 및 Linux간에도 작동합니다. AirDrop와 통신하지 않습니다. 양쪽 모두 PasteFerry가 필요합니다.

나만의 서버가 필요합니까?

아니요. 동일한 네트워크에 설치하고 페어링하세요. 다른 네트워크에서 서비스를 켜세요. 자체 서버 또는 Tailscale를 사용할 수도 있습니다.

집에는 공개 IP가 없습니다. 집과 사무실을 동기화할 수 있나요?

예, 서비스를 활성화합니다.

내가 복사한 내용을 서버가 볼 수 있나요?

아니요, 콘텐츠는 엔드투엔드 암호화됩니다. 개인정보 보호정책을 참조하세요.

릴레이는 얼마나 받나요?

하루에 컴퓨터당 100MB; 직접 연결은 포함되지 않습니다. 소진되어도 direct는 계속 작동합니다. 제한 없이 는 자체 서버를 실행합니다.

두 컴퓨터 모두 동일한 네트워크에 있습니다. 왜 그들은 서로를 찾을 수 없습니까?

일반적으로 서로 다른 서브넷에 있거나 방화벽이 이를 차단하고 있습니다. 페어링할 때 다른 서브넷에 있습니까?를 클릭합니다. 그리고 다른 주소를 입력하세요. 동일한 네트워크 가이드에서 자세한 내용을 확인하세요.

다른 사람의 컴퓨터로 파일을 보낼 수 있나요?

그렇습니다. 2.6부터는 페어링이 필요 없이 연락처로 추가할 수 있습니다. 수락하면 전송이 시작됩니다. 연락처는 클립보드나 기록을 볼 수 없습니다.

대용량 파일은 어떻습니까?

복사할 때 최대 50MB가 전송됩니다. 필요할 때 더 큰 파일을 가져오거나 크기 제한이 없는 파일 보내기를 사용하세요.

Windows? Linux? 아이폰?

Windows 10 및 11, x64 및 ARM64의 Linux . iPhone 및 iPad는 지원되지 않습니다. iOS 는 앱이 백그라운드에서 클립보드를 읽을 수 없도록 합니다.

시스템이 처음으로 경고하는 이유는 무엇입니까?

PasteFerry 는 아직 Apple에서 공증을 받지 않았거나 Windows 에 대해 코드 서명되지 않았습니다. Mac에서는 시스템 설정 → 개인 정보 보호 및 보안에서 어쨌든 열기를 클릭하세요. Windows에서 추가 정보 → 실행을 클릭합니다. 이 작업은 한 번만 수행합니다.

무료인가요? 우리 회사에서 사용할 수 있나요?

네, 개인과 회사 모두 무료입니다. PasteFerry 는 GNU AGPL-3.0의 오픈 소스입니다.

여러 업링크가 있는 사무실 네트워크에 직접 연결됩니까?

그렇습니다. PasteFerry 는 모든 업링크를 시도합니다.

UU Remote가 실행되는 동안 .uuremote_ 파일이 계속 나타나는 이유는 무엇입니까?

이전 버전의 버그였습니다. 최신으로 업데이트하세요.
