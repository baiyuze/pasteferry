PasteFerry / 서비스

집과 사무실 사이에서 일함

두 대의 컴퓨터가 동일한 네트워크에 있지 않은 경우 서비스를 켜면 동기화됩니다.

최신 버전을 다운로드하세요

켜는 방법

  1. 각 컴퓨터에 최신 버전을 설치하고 백그라운드 동기화 켜기를 클릭합니다.
  2. 설정 → 연결에서 서비스 사용을 켜주세요.
  3. 두 대의 컴퓨터를 페어링합니다. 이미 페어링한 컴퓨터는 다시 페어링할 필요가 없습니다.
전송 방식
직접 연결을 우선하고, 불가능하면 암호화된 내용을 중계합니다.
데이터 한도
컴퓨터당 하루 100MB 릴레이. 직접 전송은 무제한입니다.
활성화
기본값은 꺼짐입니다. 각 컴퓨터에서 켜세요.
다른 방법
동일한 네트워크에서는 필요하지 않습니다. 자체 서버를 실행하거나 Tailscale를 사용할 수도 있습니다.
