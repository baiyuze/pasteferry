PasteFerry / 테마 가이드

변경하고, 만들거나,
로 만들거나 AI가 만들도록 하세요.

PasteFerry 2.12.1 에는 Default, Pixel, Jazz Records, Space Age, Memphis, Y2K Future, Vintage Print, Pixel Arcade 및 Retro Desktop의 9가지 테마가 포함되어 있습니다. 각각은 밝은 모드와 어두운 모드를 지원합니다. 하나를 복사하여 사용자 정의하거나 AI가 테마 디자인을 도와줄 수 있습니다. 테마는 각 장치에 로컬로 유지됩니다.

2.12.1다운로드

AI가 만든 테마 바로가기 ↓

테마 변경

  1. PasteFerry 를 열고 설정 › 모양로 이동합니다.
  2. 내장 또는 사용자 정의 아래에서 테마를 클릭합니다. 창이 즉시 바뀌고 Quick Paste도 마찬가지입니다.
  3. 밝은 색과 어두운 색에서 일치 시스템, 밝은 또는 어두운를 선택합니다.
  4. 픽셀 테마를 사용하면 전체 창에 희미한 CRT 선인 스캔라인을 켤 수도 있습니다.
  5. Android에서 앱 자체의 설정 > 모양를 선택하세요. 컴퓨터와 휴대폰은 서로 영향을 미치지 않습니다.

9가지 내장 테마

  • 기본: PasteFerry 는 항상 조용하고 시스템적인 스타일을 유지해 왔습니다.
  • 픽셀: 비트맵 유형, 노치 테두리 및 경사진 버튼, 픽셀 녹색이 포함된 흑연 및 종이 팔레트. 밤이나 낮의 장면이 위로 올라가고, 종이비행기가 전송되는 동안, 그리고 도착할 때 쏟아지는 별들.
  • 재즈 레코드: 레코드 슬리브 기하학, 코발트 블루, 따뜻한 종이 및 압축된 제목.
  • 우주시대: 오렌지 에나멜, 실버 톤, 궤도 일러스트레이션 및 캡슐 컨트롤.
  • 멤피스: 분홍색과 노란색, 기하학적 콜라주와 강렬한 윤곽선.
  • Y2K 미래: 일렉트릭 블루, 크롬 별 및 둥근 디지털 컨트롤.
  • 빈티지 프린트: 크림색과 따뜻한 빨간색, 망점 및 티켓 일러스트.
  • 픽셀 아케이드: 휴대용 녹색, 비트맵 유형 및 노치가 있는 인벤토리와 유사한 컨트롤.
  • 레트로 데스크탑: 청록색과 회색, 사각 경사진 버튼과 클래식한 창 그림.

나만의 테마 만들기

가장 쉬운 방법은 기본 제공 테마를 복제하여 변경하는 것입니다.

  1. 설정 › 모양에서 테마 위로 마우스를 가져간 다음 ⋯ 를 클릭하고 Duplicate를 선택합니다. 복사본이 사용자 정의 아래에 나타납니다.
  2. 복사본의 ⋯ 메뉴에서 내보내기… 를 선택하여 .pasteferry-theme.json 파일을 저장합니다.
  3. 텍스트 편집기에서 색상, 이름 등을 변경합니다(형식은 아래에 설명되어 있음).
  4. 모양 페이지로 돌아가서 테마 가져오기... 를 클릭하고 파일을 선택합니다. 동일한 ID의 테마가 교체되고, 가져온 테마가 적용됩니다.
  5. 사용자 정의 테마를 제거하려면 ⋯ 메뉴에서 테마 삭제를 선택하세요. 내장 테마는 삭제할 수 없습니다.

테마 저장 시 텍스트 대비를 확인합니다. 읽기 힘든 색상이 지적되어 있지만 그래도 저장할 수 있습니다. 테마 파일은 공유할 수 있습니다. 다른 사람이 테마 파일을 가져오기만 하면 됩니다.

배경 이미지 사용

  1. 설정 › 모양를 열고 배경 이미지로 스크롤하고 이미지 선택… 를 클릭하고 JPEG, PNG 또는 GIF를 선택합니다.
  2. 이미지가 사이드바와 페이지 뒤의 창을 채우고 사이드바와 목록이 반투명해집니다. 기본 제공 테마를 사용 중인 경우 먼저 복사본이 만들어집니다. 내장 테마 자체는 동일하게 유지됩니다.
  3. Blur, Scrim 및 패널 에는 각각 3단계가 있습니다. 이미지 색상 사용 는 ​​이미지에서 강조 색상을 가져오고 빠른 붙여넣기에 표시 도 거기에 표시합니다.
  4. 돌아가려면 제거를 클릭하세요. Android의 설정 › 모양 › 배경 이미지에서 사진을 선택합니다.

텍스트는 항상 읽기 쉬운 상태로 유지됩니다. PasteFerry 는 이 이미지의 테마 텍스트 색상에 대한 스크림의 강도를 계산하고 더 밝게 표시하지 않습니다. 다크 모드의 어두운 이미지와 라이트 모드의 밝은 이미지는 사진의 대부분을 보여줍니다.

풍경을 바꾸다

  1. 풍경은 페이지 상단의 넓은 사진과 사이드바 하단의 작은 사진입니다. 픽셀 테마는 픽셀 풍경과 그곳에 작은 캠프를 그립니다. 다른 테마에는 아무것도 없습니다.
  2. 아래에 설정 › 모양 › 풍경, 클릭 이미지 선택… 옆에 페이지 상단 또는 사이드바 하단 어떤 테마로든 자신의 사진을 사용할 수 있습니다. 페이지 제목 아래에 스크림이 추가되어 계속 읽을 수 있습니다.
  3. 재설정 는 원본을 다시 가져옵니다. 를 끄고 풍경 를 표시하여 둘 다 숨깁니다. 배경 이미지가 창을 채우는 동안 풍경은 숨겨집니다.

테마 파일의 모습

테마는 JSON 파일입니다. 변경하고 싶은 내용만 작성하세요. 다른 모든 것은 base라는 테마에서 나옵니다. 이것은 Pixel에서 시작하여 악센트와 몇 가지 배경을 변경합니다.

{
  "schema": 1,
  "id": "sunset-pixel",
  "name": { "zh-Hans": "落日像素", "en": "Sunset Pixel" },
  "base": "pixel",
  "modes": {
    "dark": { "accent": "#FF8A5B", "background": "#16110F", "surface": "#1E1714" },
    "light": { "accent": "#C2410C" }
  }
}

공통 필드

id
테마 식별자: 소문자, 숫자 및 -. default 또는 pixel일 수 없습니다.
name
zh-Hans, zh-Hant-TW, zh-Hant-HK, en 및 ja와 같은 각 언어의 이름입니다.
base
시작할 테마: default, pixel 또는 다른 사용자 정의 테마.
modes.light / modes.dark
밝은 색상과 어두운 색상(알파 포함 #RRGGBB 또는 #AARRGGBB ). 일반적인 것: accent, background (콘텐츠 영역), sidebar, surface (그룹 및 대화 상자), border, text, textDim, textFaint 및 onAccent (악센트 텍스트).
typography
글꼴: family 는 system 또는 내장 픽셀 글꼴 FusionPixel입니다.
shape
모양: corner 는 round 또는 pixel (노치)에 반경, 테두리 너비 및 그림자 스타일을 더한 것입니다.
motion, icons
모션 smooth / stepped / reduced; 아이콘 system / pixel.
background
창 배경 이미지: image (가져온 후user:<sha256> ), blur, scrim, surfaceOpacity (패널 불투명도), scope (창에 표시됨), accentFromImage.
scenery, scene
풍경 켜기/끄기 및 나만의 사진: scene.header (페이지 헤더) 및 scene.sidebar (사이드바 하단), 다크 모드용 headerDark 및 sidebarDark 옵션 포함.

전체 형식과 각 색상이 사용되는 위치: design/themes.md

AI가 테마를 만들도록 하세요

PasteFerry 에는 MCP 서버인 pasteferry-cli mcp가 포함되어 있습니다. Claude Desktop, Claude Code, Cursor 등 MCP를 지원하는 AI 앱에 추가하고, 원하는 모습을 한 문장으로 표현해보세요. AI는 테마 형식을 읽고 색상을 선택하고 대비를 확인한 다음 테마를 저장하고 적용합니다.

1.pasteferry-cli를 찾아보세요

Mac
/Applications/PasteFerry.app/Contents/Helpers/pasteferry-cli ( Homebrew포함, pasteferry-cli만 사용)
Windows
%LOCALAPPDATA%\Programs\PasteFerry\pasteferry-cli.exe
Linux
deb: /usr/bin/pasteferry-cli; tar.gz: 추출된 폴더의 PasteFerry/pasteferry-cli

또는 설정 > 모양 > AI에게 테마 만들기에서 이 컴퓨터에 대해 미리 만들어진 구성을 복사합니다.

2. AI 앱에 추가하세요

Claude Desktop(설정 › 개발자 › 구성 편집) 및 커서(~/.cursor/mcp.json)는 동일한 구성을 사용합니다. Mac의 경우:

{
  "mcpServers": {
    "pasteferry": {
      "command": "/Applications/PasteFerry.app/Contents/Helpers/pasteferry-cli",
      "args": ["mcp"]
    }
  }
}

Claude Code의 경우 터미널에서 실행하세요.

claude mcp add pasteferry -- /Applications/PasteFerry.app/Contents/Helpers/pasteferry-cli mcp

구성을 변경한 후 AI 앱을 다시 시작하세요. PasteFerry 를 계속 실행하세요. AI는 이 컴퓨터의 백그라운드 서비스를 통해 테마를 변경합니다.

3. 원하는 것을 말하세요

  • “네온핑크, 딥퍼플 사이버펑크 테마를 만들어서 적용해보세요.”
  • “Pixel 테마에서 시작하여 더 따뜻하고 어두운 배경의 일몰 버전을 만들어 보세요.”
  • “현재 테마의 회색 텍스트는 읽기 어렵습니다. 더 가볍게 만드세요.”
  • “내가 볼 수 있도록 테마를 내보낸 다음 라이트 버전을 만드세요.”
  • “~/Pictures/beach.jpg를 배경으로 사용하고 색상을 사진과 일치시킵니다.”
  • “픽셀 테마의 헤더 풍경을 ~/Pictures/mountains.png로 바꿉니다.”

AI가 할 수 있는 일

  • 테마를 나열하고 테마 전체를 읽으세요.
  • 테마 형식을 읽어보세요. 각 색상이 사용되는 위치와 필요한 대비가 무엇인지 알아보세요.
  • 테마를 저장하지 않고 확인하여 대비가 너무 낮은 색상을 찾으세요.
  • 사용자 정의 테마를 저장, 적용 및 삭제하고 밝음과 어두움을 전환합니다.
  • 이 컴퓨터의 사진을 창 배경이나 풍경으로 가져와 밝기와 주요 색상을 분석합니다.

할 수 없는 것

MCP 서버는 이 컴퓨터에서만 실행되며 네트워크 포트를 열지 않습니다. 테마와 배경 이미지만 읽고 쓸 수 있습니다. 기록, 장치, 친구를 볼 수 없으며 다른 설정을 변경할 수 없습니다. 배경 이미지는 로컬 파일이어야 합니다. 인터넷에서 아무것도 다운로드되지 않습니다.

질문

테마가 다른 장치와 동기화됩니까?

아니요. 테마는 귀하가 설정한 장치에만 적용됩니다. 동일한 테마를 다른 곳에서 사용하려면 해당 테마를 내보낸 후 가져오세요.

AI가 내 테마를 엉망으로 만들었습니다. 어떻게 돌아가나요?

설정 › 모양에서 기본 또는 픽셀을 선택하세요. 원하지 않는 맞춤 테마를 삭제하세요.

가져오기에 따르면 일부 텍스트를 읽기 어려울 수 있습니다.

일부 텍스트와 배경색의 대비가 낮습니다. 제안된 대로 해당 색상을 밝게 또는 어둡게 하거나 AI에게 수정을 요청하세요.

이전 버전에서는 테마를 지원합니까?

2.10 이상이 필요합니다. 장치 프로토콜은 변경되지 않았으므로 이전 버전과 새 버전이 계속해서 함께 작동합니다.

사진에서 텍스트를 읽기가 어렵나요?

아니요. 스크림 강도는 테마의 텍스트 색상에 따라 결정되며 결코 필요 이상으로 밝지 않습니다. 바쁜 사진의 경우 흐림 또는 패널 불투명도를 높이세요.
