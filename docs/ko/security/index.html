서버는 복사한 내용을 볼 수 없습니다.

종단 간 암호화. 페어링할 때 지문을 확인하세요.

  • 계정도 없고 저장된 콘텐츠도 없습니다.장치의 ID는 키이므로 서버에는 사용자 테이블이 필요하지 않습니다.
  • 페어링 시 지문을 확인하세요.두 화면 모두 동일한 지문을 표시합니다. 누군가가 키를 바꾸면 일치하지 않습니다.
  • 모든 메시지는 서명되어 있습니다.따라서 서버는 귀하의 장치인 것처럼 가장할 수 없습니다.
  • 릴레이는 암호문만 전달합니다.릴레이 자격 증명은 12시간 후에 만료됩니다.
  • 로컬 네트워크에서도 비공개입니다.장치는 매일 변경되는 익명 토큰을 브로드캐스트하므로 어느 컴퓨터인지 아무도 알 수 없습니다.
