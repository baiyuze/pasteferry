작동 원리

복사하면 어떻게 되는지, 컴퓨터는 어떻게 연결되는지, 복사할 수 없으면 어떻게 되는지 알아보세요.

복사하면 어떻게 되나요?

텍스트, 이미지, 파일은 모두 동일한 경로를 사용합니다.

  1. 공지사항

    백그라운드 서비스는 클립보드가 변경되었음을 확인합니다.

  2. 보내기

    최대 50MB의 텍스트와 파일이 바로 넘어갑니다. 더 큰 것들은 먼저 레코드로 전송됩니다.

  3. 붙여넣기

    다른 컴퓨터는 이를 로컬에 저장하고 클립보드에 넣습니다. 실제 파일을 붙여넣습니다.

PasteFerry 연결 방법

동일한 네트워크에서 컴퓨터는 서로를 직접 찾습니다. 다른 네트워크에서는 서버가 이를 소개하여 직접 연결을 시도하고 연결이 실패한 경우에만 중계합니다. 콘텐츠는 항상 암호화됩니다.

사무실 네트워크에서도 직접 사용 가능

릴레이를 통과하는 데 사용되는 여러 업링크가 있는 사무실 네트워크. PasteFerry 는 모든 업링크를 찾아 상대방이 각각을 시도하도록 합니다.

기능

  • 하나의 공유 포트.모든 연결은 동일한 UDP 포트를 사용합니다.
  • 모든 업링크가 조사되었습니다.한 번에 7개의 서버에 요청하고 업링크당 하나의 주소를 얻습니다.
  • 모두 반대편으로 보냈습니다.다른 컴퓨터는 한 컴퓨터가 통과할 때까지 각 컴퓨터를 시도합니다.
  • 유휴 상태에서 직접 재시도하세요.릴레이는 계속 작동하며 유휴 상태에서는 직접 전환됩니다.

실제 네트워크 설정에서 테스트됨

모든 커밋은 시뮬레이션된 네트워크에서 자동으로 테스트됩니다.

시나리오결과
단일 업링크 ⇔ 홈 라우터직접 연결
업링크 2개, 이전 버전(제어)중계
업링크 4개 ⇔ 홈 라우터직접 연결
업링크 2개 ← 업링크 2개직접 연결
2개의 업링크 ⇔ 포트를 무작위로 지정하는 NAT중계
처음에는 차단되었다가 나중에 네트워크가 복구됨릴레이 후 직접
서버 없음, 동일한 서브넷직접 연결
서버 없음, 서브넷이 서로 분리됨연결되지 않음

측정됨: 4업링크 사무실 네트워크의 Mac과 이전에 0.6MB/s로 릴레이된 집의 Mac. 이제 그들은 직접 연결됩니다.

자세한 내용은 설계 문서 (중국어)에 나와 있습니다.

일이 잘못될 때

일반적인 경우를 처리합니다.

네트워크에서 다른 컴퓨터를 찾을 수 없습니다
페어링할 때 주소를 입력하세요. 나중에 생각나네요.
직접 연결 없음
데이터는 암호화된 상태로 서버를 통해 중계됩니다.
다른 컴퓨터가 잠자기 상태이거나 꺼집니다.
돌아오면 저절로 다시 연결됩니다.
파일 전송 중 연결이 끊어졌습니다.
전송이 중지된 위치에서 다시 시작됩니다.
파일 이름 Windows 는 허용되지 않습니다.
잘못된 문자는 전자 문자가 되므로 이름은 여전히 동일하게 읽혀집니다.
비밀번호 복사
Windows에서는 비밀번호 관리자에서 복사된 모든 내용을 건너뜁니다.

Linux 앱x64 및 ARM64; .deb (Debian, Ubuntu 및 유사) 또는 tar.gz (기타 배포판), 약 22MB X11 데스크탑 또는 XWayland가 있는 Wayland 데스크탑이 필요합니다(GNOME, KDE 및 기타 제품에는 기본적으로 포함되어 있음). GTK 3
서버서비스 또는 동일한 네트워크에서는 필요하지 않습니다. 직접 실행하려면: Linux x86_64/ARM64, macOS또는 Windows 10/11 x64.
언어18개 언어: 영어, 중국어 간체 및 번체(대만 및 홍콩), 일본어, 한국어, 아랍어(오른쪽에서 왼쪽으로), 독일어, 프랑스어, 스페인어, 포르투갈어(브라질), 이탈리아어, 러시아어, 우크라이나어, 폴란드어, 터키어, 베트남어, 인도네시아어 기본적으로 시스템을 따르며 설정에서 전환 가능
내용일반 텍스트, 서식 있는 텍스트, 이미지 및 스크린샷, 파일, 폴더 각 유형을 끌 수 있습니다
운송WebRTC 데이터 채널, TURN 릴레이 폴백을 통한 직접 우선; 동일한 네트워크에서 UDP 8788을 통한 mDNS 검색 및 연결 세부 정보 다중 업링크 네트워크에서 모든 업링크를 조사합니다. tar + zstd로 스트리밍되는 파일
암호화 및 ID엔드 투 엔드 DTLS; Ed25519 장치 키; 모든 신호 메시지에 서명됨
페어링0/O 및 1/I와 같은 유사 문자가 없는 알파벳을 사용하여 5분간 유효한 6자리 코드입니다. 당신이 확인한 지문
자동 동기화 한도기본적으로 50MB, 1MB에서 1GB까지 조정 가능
파일 보내기하나의 장치, 모든 크기, 파일 또는 전체 폴더에; 암호화된 TCP 링크(양쪽 모두 2.5.1필요)를 통해 로컬 네트워크에서 사용할 수 없는 경우 WebRTC 로 대체됩니다. 인터넷 및 중계를 통한 WebRTC ; 연결이 끊어진 후 다시 시작됩니다. 파일당 SHA-256. 측정된 Mac에서 Linux VM, 1GB: 144.3MB/s; 실제 속도는 네트워크와 디스크에 따라 다릅니다.
연락처F로 시작하는 7자리 연락처 코드는 로컬 네트워크나 서비스를 통해 교환되며 선택적인 안전 코드 확인도 가능합니다. 연락처는 최대 200자의 메모를 포함하여 서로 파일과 이미지만 보낼 수 있으며 각 일괄 처리를 수락해야 합니다. 상대방은 귀하의 클립보드, 기록 또는 장치를 절대 볼 수 없습니다. 수신된 파일은 실행 비트가 손실되고 Mac에 격리됩니다. 양쪽 모두 2.6 이상이 필요합니다
기록기본적으로 3일이며, 1시간에서 30일까지 조정 가능합니다. 만료된 항목은 자동으로 제거됩니다.
측정된 속도20MB 파일은 직접 LAN 연결을 통해 약 330ms 내에 전송되며 체크섬은 일치합니다.
