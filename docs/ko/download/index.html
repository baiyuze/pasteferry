무료 오픈 소스 · 버전 2.14.0

Windows

설치 프로그램 다운로드

휴대용 버전 — 설치 불필요

빠른 시작 →

  • Windows 10 및 Windows 11, x64.

macOS

Apple 칩(M1 이상) 인텔

유니버설 버전도 있습니다.

Homebrew: brew install --cask baiyuze/tap/pasteferry. 설치 및 업데이트

빠른 시작 →

어떤 칩인지 모르시나요?

  • 화면 왼쪽 상단에 있는 Apple 메뉴를 클릭하고 이 Mac에 관하여를 선택합니다.
  • "칩: Apple M1"(또는 M2, M3, M4…)은 Apple 실리콘을 의미합니다. "프로세서: … Intel Core …"는 Intel을 의미합니다.
  • macOS 13 Ventura 이상이 필요합니다.

Linux

Ubuntu, Debian 및 파생 상품

x64 ARM64 
sudo apt install ./PasteFerry-linux-amd64.deb

기타 배포판

x64 ARM64 
tar xzf PasteFerry-linux-amd64.tar.gz
./PasteFerry/install.sh
  • GTK 3와 X11 또는 XWayland가 있는 Wayland 데스크톱이 필요합니다.
  • uname -m: x86_64는 x64, aarch64는 ARM64입니다.

전화(Android 앱 또는 웹페이지)

Android (APK) 다운로드

Android 9 이상 · ARM64

웹페이지(설치할 항목 없음)

컴퓨터에서 장치 › 전화 웹 전송을 켜고 휴대폰으로 코드를 스캔하세요.

  1. 앱을 설치한 후 다른 컴퓨터를 페어링하는 것과 같은 방법으로 컴퓨터의 장치에서 휴대폰을 페어링하세요.
  2. 휴대폰에 복사한 내용을 붙여넣고 보내세요. 컴퓨터에서 복사한 내용이 휴대폰 기록에 나타납니다.
  • 휴대폰과 컴퓨터를 같은 네트워크에 연결하세요.
  • iPhone과 iPad에서는 웹 버전을 사용하세요.

서버
동일한 네트워크에 있는 두 컴퓨터에는 서버가 필요하지 않습니다. 네트워크를 통해 연결하는 방법은 빠른 시작에 있습니다. 각 가이드에는 자체 서버 다운로드가 있습니다.
체크섬
모든 파일의 SHA-256 체크섬은 SHA256SUMS에 있습니다.
