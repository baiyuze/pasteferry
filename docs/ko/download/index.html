PasteFerry / 다운로드

PasteFerry다운로드

무료 오픈 소스 버전 2.13.1. 동기화하려는 각 컴퓨터에 설치하세요. Mac, Windows 및 Linux 는 자유롭게 혼합됩니다.

Windows

설치 프로그램 다운로드

설치 프로그램을 실행하지 않으시겠습니까? 휴대용 zip를 가져와서 압축을 풀고 거기에서 PasteFerry 를 실행하세요.

  1. PasteFerry-Setup.exe를 실행합니다. 현재 사용자용으로 설치되며 관리자 권한이 필요하지 않습니다."Windows 가 PC를 보호했습니다."가 표시되면 추가 정보를 클릭한 다음 어쨌든 실행을 클릭합니다.
  2. PasteFerry 를 열고 백그라운드 동기화 켜기를 클릭합니다. Windows 방화벽이 요청하면 허용합니다.
  • Windows 10 및 Windows 11, x64.
  • 설치 프로그램은 약 23MB이고 휴대용 zip은 약 29MB입니다.
  • 창을 닫은 후에도 PasteFerry 는 알림 영역에서 계속 실행됩니다.

macOS

Apple 칩(M1 이상) 인텔

두 가지 모두에서 실행되는 범용 버전 도 크기가 두 배로 제공됩니다.

brew install --cask baiyuze/tap/pasteferry를 사용하여 데스크톱 앱과 번들 CLI를 설치할 수도 있습니다. 이미 수동으로 설치한 경우 먼저 기존 앱을 종료하고 이동하세요. 애플리케이션 데이터를 유지하세요. 설치 및 업그레이드 가이드를 참조하세요.

  1. 다운로드한 DMG를 열고 PasteFerry 를 애플리케이션으로 드래그하세요.
  2. 응용 프로그램에서 엽니다.처음으로 macOS 는 개발자를 확인할 수 없다고 말합니다. 시스템 설정 → 개인 정보 보호 및 보안으로 이동하여 하단 근처에 있는 어쨌든 열기를 클릭합니다.
  3. 백그라운드 동기화 켜기를 클릭하세요. macOS 가 클립보드 액세스 및 로컬 네트워크에서 장치 찾기에 대해 묻는 경우 두 가지를 모두 허용하세요.

어떤 칩인지 모르시나요?

  • 화면 왼쪽 상단에 있는 Apple 메뉴를 클릭하고 이 Mac에 관하여를 선택합니다.
  • "칩: Apple M1"(또는 M2, M3, M4…)은 Apple 실리콘을 의미합니다. "프로세서: … Intel Core …"는 Intel을 의미합니다.
  • 2020년 후반 이후 구입한 거의 모든 Mac에는 Apple 실리콘이 탑재되어 있습니다. 잘못된 것을 선택했다면 다른 것을 다운로드하면 됩니다. Apple Silicon Mac에서는 Intel 버전을 먼저 Rosetta 설치해야 하며 Intel Mac에서는 Apple Silicon 버전이 열리지 않습니다.
  • macOS 13 Ventura 이상이 필요합니다.

Linux

Ubuntu, Debian 및 파생 상품

x64 ARM64 
sudo apt install ./PasteFerry-linux-amd64.deb

기타 배포판

x64 ARM64 
tar xzf PasteFerry-linux-amd64.tar.gz
./PasteFerry/install.sh
  • 그래픽 데스크탑이 필요합니다: X11 또는 GNOME, KDE 및 기타 주요 데스크탑에 기본적으로 포함되는 XWayland가 포함된 Wayland.
  • x64 또는 ARM64가 있는지 확실하지 않습니까? 터미널에서 uname -m 를 실행합니다. x86_64 는 x64를 의미하고, aarch64 는 ARM64를 의미합니다.
  • .deb는 /opt/PasteFerry 에 설치되고 PasteFerry 를 앱 메뉴에 추가합니다. tar.gz는 추출한 모든 위치에서 실행되며 install.sh 는 이를 앱 메뉴에 추가합니다.
  • 일단 열리면 백그라운드 동기화 켜기를 클릭하세요. 그 이후부터 로그인하면 시작됩니다. 그놈은 기본적으로 트레이 아이콘을 표시하지 않으므로 앱 메뉴에서 창을 엽니다.
  • GTK 3이 필요합니다. GNOME(Wayland)을 사용하여 Ubuntu 24.04에서 테스트되었습니다.

전화(Android 앱 또는 웹페이지)

Android (APK) 다운로드

Android 9 이상, arm64 전화기. Android 는 설치하기 전에 한 번 묻습니다.

웹페이지(설치할 항목 없음)

컴퓨터에서 장치 › 전화 웹 전송을 켜고 휴대폰으로 코드를 스캔하세요.

  1. 앱을 설치한 후 다른 컴퓨터를 페어링하는 것과 같은 방법으로 컴퓨터의 장치에서 휴대폰을 페어링하세요.
  2. 또는 웹페이지를 사용하세요. 컴퓨터에서 장치 › 전화 웹 전송을 켜고 코드를 스캔하세요.
  3. 휴대폰에 복사한 내용을 붙여넣고 보내세요. 컴퓨터에서 복사한 내용이 휴대폰 기록에 나타납니다.
  • 텍스트, 스크린샷, 파일은 양방향으로 전송됩니다.
  • iPhone 또는 iPad 앱이 없습니다. iOS 는 앱이 백그라운드에서 클립보드를 읽을 수 없도록 하며 배포하려면 인증서가 필요합니다. 대신 웹페이지를 사용하세요.
  • 콘텐츠는 휴대폰과 컴퓨터 간에 암호화됩니다. 집에서나 신뢰할 수 있는 네트워크에서 사용하세요.
