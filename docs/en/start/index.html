PasteFerry / Quick start

Quick start

Install the app, pick a way to connect, and pair your computers. On the same network it takes a few minutes.

  1. Install the app
  2. Pick a way to connect
  3. Pair
  4. Using a phone

Step 1

Install the app on each computer

One on every computer you want to sync. Mac, Windows and Linux mix freely.

Mac

  1. Download the DMG, open it and drag PasteFerry into Applications.There's one for Apple silicon and one for Intel; the download page helps you choose.
  2. Open it from Applications.The first time, macOS says it can't verify the developer: go to System Settings → Privacy & Security and click Open Anyway near the bottom.
  3. Click Turn on background sync. When macOS asks about clipboard access and finding devices on your local network, allow both.
Download for Mac

Windows

  1. Run PasteFerry-Setup.exe; no administrator rights needed.If you see "Windows protected your PC", click More info, then Run anyway.
  2. Open PasteFerry and click Turn on background sync. Allow it if Windows Firewall asks. After you close the window it keeps running in the notification area.
Download for Windows

Linux

  1. On Ubuntu, Debian and similar, install the .deb; on other distributions, extract the tar.gz and run the install.sh inside.
  2. Open PasteFerry from the app menu and click Turn on background sync.
Download for Linux

Step 2

Pick a way to connect

On the same network, install and pair. On different networks, turn on Service. If you want full control, run your own server or use Tailscale.

Service

  1. Install the latest version on each computer and click Turn on background sync.
  2. Turn on Use the service in Settings → Connection.
  3. Pair the two computers. Computers you've already paired don't need to pair again.

Service is off in a new install. The server never receives what you copy; see the privacy notice.

Turn on Service →
Direct whenever possible
The computers connect directly when they can and go through the server only when they can't. Content is encrypted, and the server can't decrypt it.
100 MB of relay a day, direct unlimited
Relay is limited to 100 MB per computer per day; direct is unlimited. The usage page shows how much is left.

Same network

  1. Install the app on each computer and click Turn on background sync.
  2. Allow PasteFerry when Windows Firewall or macOS asks about the local network.
  3. Show a code on one computer, enter it on the other and compare fingerprints. On a different subnet, also enter the address shown under the code; see the same network guide.

No server address to enter.

Same network guide →
Best for
Home or office, with both computers on the same Wi‑Fi or wired network.
You need
Nothing but the app on each computer.
Keep in mind
Sync stops when you leave the network and resumes when you're back. If wired and Wi‑Fi are on different subnets, you enter one extra address when pairing.

Your own public server

  1. In your cloud provider's security group, open TCP 8787, UDP 3478 and UDP 32768–60999.
  2. Log in with ssh, download the install script and run it: sudo ./install.sh PUBLIC_IP.
  3. In Settings → Connection on each computer, enter ws://PUBLIC_IP:8787/signal, press Return, then pair.

Open http://PUBLIC_IP:8787/healthz in a browser. If it says ok, it's running.

Public server guide →
Best for
Running the server yourself, or relaying a lot of traffic.
You need
A Linux VM with a public IP and root access.
Keep in mind
The VM costs money, and relay speed is limited by its bandwidth. In mainland China, enter the IP unless the domain has an ICP filing.

Tailscale

  1. Install Tailscale on each computer and sign in to the same account.
  2. On the other computer, run tailscale ip -4 and note the address starting with 100.
  3. When pairing, click On a different subnet? and enter that address.

No server needed. A Tailscale address doesn't change, so you enter it once, when pairing.

Tailscale guide →
Best for
You already use Tailscale, or don't want to depend on any server.
You need
Tailscale on every computer, signed in to the same account.
Keep in mind
Tailscale has to stay connected. When it can't connect two computers directly, it relays through its own servers, which can be slow.

Step 3

Pair your computers

Pair any two computers once, and that's it.

  1. On one computer, open Devices and click Add device. It shows a 6-character code, valid for 5 minutes, and this computer's address below it.
  2. On the other computer, choose Add device → Enter a code. With Service there's no IP to enter; only across subnets or with Tailscale do you open the address field and enter the other computer's address.
  3. Both screens show the same two fingerprint lines. Check them character by character, then confirm.This stops anyone in the middle from posing as your device. Don't skip it.

Using a phone

Once the computers are paired above, a phone can join any time: scan a code for the web page, or install the Android app.

The web page: nothing to install

  1. Computer: open Devices › Phone web transfer, turn the switch on, and a code appears.
  2. Phone: scan the code with the camera or a browser and give the phone a name.
  3. The phone’s browser then shows the computer’s records: tap Copy to take a text to the phone, or use Send to push text, photos and files to the computer.

The Android app: pairs like another computer

  1. Phone: download the APK and install it (allow installing from unknown sources when asked).
  2. Computer: Devices → Add device → Show a code.
  3. Phone: enter the code and confirm when the two fingerprints match.
  4. What you copy on the computer then appears in the phone’s records and clipboard.

Now copy something.

Copy text, an image or a file on one computer and press ⌘V or Ctrl+V on the other. Everything copied on either side is in the history.
