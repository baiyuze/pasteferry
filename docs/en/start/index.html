PasteFerry / Quick start

Quick start

Install the app, pick a way to connect, and pair your computers. On the same network it takes a few minutes; after that, copying just syncs.

  1. Install the app
  2. Pick a way to connect
  3. Pair

Step 1

Install the app on each computer

One on every computer you want to sync. Mac, Windows and Linux mix freely.

Mac

  1. Download the DMG, open it and drag PasteFerry into Applications.There's one for Apple silicon and one for Intel; the download page helps you choose.
  2. Open it from Applications.The first time, macOS says it can't verify the developer: go to System Settings → Privacy & Security and click Open Anyway near the bottom.
  3. Click Turn on background sync. When macOS asks about clipboard access and finding devices on your local network, allow both.
Download for Mac

Windows

  1. Run PasteFerry-Setup.exe; no administrator rights needed.If you see "Windows protected your PC", click More info, then Run anyway.
  2. Open PasteFerry and click Turn on background sync. Allow it if Windows Firewall asks. After you close the window it keeps running in the notification area.
Download for Windows

Linux

  1. On Ubuntu, Debian and similar, install the .deb; on other distributions, extract the tar.gz and run the install.sh inside.
  2. Open PasteFerry from the app menu and click Turn on background sync.
Download for Linux

Step 2

Pick a way to connect

Same network? Install and pair. Different networks? Enable official access without hosting a server. Custom servers and Tailscale remain available when you prefer to manage the connection yourself.

Official service

  1. Install the latest app and turn on background sync on every computer.
  2. Enable Settings → Use official service on each computer and review the essential-data notice. No official hostname or port to enter.
  3. Show a pairing code on one computer, enter it on the other, and compare both fingerprint lines before confirming. Existing pairings are kept.

Official access is off on fresh installs. Enabling it records essential access statistics; an application-specific machine digest is derived only when relay is requested. Real device names, raw system identifiers and copied content are not uploaded as statistics. See the privacy notice for fields and retention.

Enable official access →
Direct first, relay when needed
Official signaling exchanges connection information between online peers. The clients try STUN discovery and NAT traversal first, requesting relay only after that direct attempt fails. Content remains end-to-end encrypted.
Direct traffic does not use relay allowance
The current default is 100 MB per machine quota group per day, upload plus download, resetting at midnight Beijing time. Reinstalling does not guarantee a fresh allowance. Once enabled, the usage page shows today's allowance, the remaining amount and the update time without needing relay first, and lists whether each device is connected directly or through relay. Direct connections still work when relay allowance runs out. Allowances and availability may change; check the app.

Same network

  1. Install the app on each computer and click Turn on background sync.
  2. Allow PasteFerry if Windows Firewall asks, and allow it to find devices on your local network if macOS asks.
  3. Show a code on one, enter it on the other and compare fingerprints. On a different subnet, also enter the address shown under the code; see the same network guide.

No server address to enter.

Same network guide →
Best for
Computers on the same Wi‑Fi or wired network, such as at home or in the office.
You need
Nothing. Just the app on each computer.
Keep in mind
No sync away from that network; it resumes when you're back. If wired and Wi‑Fi are on different subnets, as in many offices, you also enter an address when pairing.

Self-hosted server

  1. In your cloud provider's security group, open TCP 8787, UDP 3478 and UDP 32768–60999.
  2. Log in with ssh, download the install script and run it with the public IP: sudo ./install.sh PUBLIC_IP.
  3. In Settings on each computer, enter ws://PUBLIC_IP:8787/signal, press Return, then pair.

Open http://PUBLIC_IP:8787/healthz in a browser; ok means it's running.

Public server guide →
Best for
Control your own capacity
You need
A Linux VM with a public IP, as root; the smallest one is enough.
Keep in mind
The VM costs money. When a direct connection fails, the relay is limited by the server's bandwidth. In mainland China, use the IP unless the domain has an ICP filing.

Tailscale

  1. Install Tailscale on each computer and sign in to the same account.
  2. On the computer you'll pair with, run tailscale ip -4 and note the address starting with 100.
  3. When pairing, on the computer entering the code, click On a different subnet? and enter that address.

No server. A Tailscale address doesn't change, so you enter it once, when pairing.

Tailscale guide →
Best for
Computers on different networks, without a public server.
You need
Tailscale on every computer, signed in to one account.
Keep in mind
Every computer that runs PasteFerry needs Tailscale, connected. When Tailscale can't connect peer to peer it relays through DERP servers, which can be slow.

Step 3

Pair your computers

Pair each two computers once, and you're done.

  1. On one computer, open Devices and click Add device. It shows a 6-character code, valid for 5 minutes, and this computer's address below it.
  2. On the other computer, choose Add device → Enter a code. Official access needs no peer IP. Expand the address field only for pairing across LAN subnets or through Tailscale.
  3. Both screens show the same two fingerprint lines. Check them character by character, then confirm.This stops anyone in the middle from posing as your device. Don't skip it.

Now copy something.

Copy text, an image or a file on one computer and press ⌘V or Ctrl+V on the other. Everything copied on either side is in the history.
