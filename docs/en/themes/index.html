PasteFerry / Themes guide

Change it, make it,
or let an AI make it.

From 2.10, PasteFerry has themes: Default and Pixel are built in, you can duplicate one and make it yours, or ask an AI to design one. A theme applies only to the device you set it on.

Download 2.10

Skip to themes made by AI ↓

Change the theme

  1. Open PasteFerry and go to Settings › Appearance.
  2. Click a theme under Built in or Custom. The window changes right away, and so does Quick Paste.
  3. Under Light and dark, choose Match system, Light or Dark.
  4. With a pixel theme you can also turn on Scanlines, faint CRT lines over the whole window.
  5. On Android, choose in the app’s own Settings › Appearance; computers and phones don’t affect each other.

The two built-in themes

  • Default: The quiet, system-style look PasteFerry has always had.
  • Pixel: Bitmap type, notched borders and bevelled buttons, graphite and paper palettes with pixel green. A night or daytime scene up top, a paper plane while sending and a burst of stars when it arrives.

Make your own theme

The easiest way is to duplicate a built-in theme and change it:

  1. In Settings › Appearance, hover over a theme, click ⋯ and choose Duplicate. The copy appears under Custom.
  2. In the copy’s ⋯ menu, choose Export… to save a .pasteferry-theme.json file.
  3. Change the colors, name and so on in any text editor (the format is described below).
  4. Back on the Appearance page, click Import theme… and choose the file. A theme with the same id is replaced, and the imported theme is applied.
  5. To remove a custom theme, choose Delete theme in its ⋯ menu. Built-in themes can’t be deleted.

Text contrast is checked when a theme is saved. Hard-to-read colors are pointed out, but you can still save. Theme files can be shared: the other person just imports it.

What a theme file looks like

A theme is a JSON file. Write only what you want to change; everything else comes from the theme named in base. This one starts from Pixel and changes the accent and a few backgrounds:

{
  "schema": 1,
  "id": "sunset-pixel",
  "name": { "zh-Hans": "落日像素", "en": "Sunset Pixel" },
  "base": "pixel",
  "modes": {
    "dark": { "accent": "#FF8A5B", "background": "#16110F", "surface": "#1E1714" },
    "light": { "accent": "#C2410C" }
  }
}

Common fields

id
The theme’s identifier: lowercase letters, digits and -. It can’t be default or pixel.
name
The name in each language, such as zh-Hans, zh-Hant-TW, zh-Hant-HK, en and ja.
base
The theme to start from: default, pixel or another custom theme.
modes.light / modes.dark
Colors for light and dark, as #RRGGBB or #AARRGGBB with alpha. Common ones: accent, background (content area), sidebar, surface (groups and dialogs), border, text, textDim, textFaint and onAccent (text on the accent).
typography
Fonts: family is system or the built-in pixel font FusionPixel.
shape
Shapes: corner is round or pixel (notched), plus radii, border width and shadow style.
motion, icons
Motion smooth / stepped / reduced; icons system / pixel.

The full format and where each color is used: design/themes.md

Let an AI make a theme

PasteFerry includes an MCP server, pasteferry-cli mcp. Add it to an AI app that supports MCP, such as Claude Desktop, Claude Code or Cursor, and describe the look you want in one sentence. The AI reads the theme format, picks colors, checks contrast, then saves and applies the theme.

1. Find pasteferry-cli

Mac
/Applications/PasteFerry.app/Contents/Helpers/pasteferry-cli (with Homebrew, just pasteferry-cli)
Windows
%LOCALAPPDATA%\Programs\PasteFerry\pasteferry-cli.exe
Linux
deb: /usr/bin/pasteferry-cli; tar.gz: PasteFerry/pasteferry-cli in the extracted folder

Or copy the ready-made configuration for this computer from Settings › Appearance › Ask AI to make a theme.

2. Add it to your AI app

Claude Desktop (Settings › Developer › Edit Config) and Cursor (~/.cursor/mcp.json) use the same configuration. On a Mac:

{
  "mcpServers": {
    "pasteferry": {
      "command": "/Applications/PasteFerry.app/Contents/Helpers/pasteferry-cli",
      "args": ["mcp"]
    }
  }
}

For Claude Code, run in a terminal:

claude mcp add pasteferry -- /Applications/PasteFerry.app/Contents/Helpers/pasteferry-cli mcp

Restart the AI app after changing its configuration. Keep PasteFerry running: the AI changes themes through its background service on this computer.

3. Say what you want

  • “Make me a cyberpunk theme with neon pink and deep purple, then apply it.”
  • “Start from the Pixel theme and make a sunset version with a warmer dark background.”
  • “The gray text in my current theme is hard to read. Make it lighter.”
  • “Export my theme so I can see it, then make a light version.”

What the AI can do

  • list themes and read a theme in full;
  • read the theme format: where each color is used and the contrast it needs;
  • check a theme without saving it, to find colors with too little contrast;
  • save, apply and delete custom themes, and switch light and dark;
  • import an image from this computer as a background and analyze its brightness and main colors.

What it can’t do

The MCP server runs only on this computer and opens no network port. It can read and write themes and background images only: it can’t see your history, devices or friends, or change other settings. Background images must be local files; nothing is downloaded from the internet.

Questions

Are themes synced to my other devices?

No. A theme applies only to the device you set it on. To use the same theme elsewhere, export it and import it there.

The AI made a mess of my theme. How do I go back?

Choose Default or Pixel in Settings › Appearance. Delete custom themes you don’t want.

Importing says some text may be hard to read.

Some text and background colors have low contrast. Lighten or darken those colors as suggested, or ask the AI to fix them.

Do older versions support themes?

You need 2.10 or later. The device protocol is unchanged, so old and new versions still work together.
