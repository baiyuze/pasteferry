PasteFerry / Download

Download PasteFerry

Free and open source, version 2.3.0. Install it on each computer you want to sync; Mac, Windows and Linux mix freely.

Windows

Download the installer

Rather not run an installer? Get the portable zip, extract it and run PasteFerry from there.

  1. Run PasteFerry-Setup.exe. It installs for the current user, no administrator rights needed.If you see "Windows protected your PC", click More info, then Run anyway.
  2. Open PasteFerry and click Turn on background sync. Allow it if Windows Firewall asks.
  • Windows 10 and Windows 11, x64.
  • The installer is about 23 MB, the portable zip about 29 MB.
  • After you close the window, PasteFerry keeps running in the notification area.

macOS

Apple silicon (M1 and later) Intel

A universal version that runs on both is also available, at twice the size.

  1. Open the DMG you downloaded and drag PasteFerry into Applications.
  2. Open it from Applications.The first time, macOS says it can't verify the developer: go to System Settings → Privacy & Security and click Open Anyway near the bottom.
  3. Click Turn on background sync. When macOS asks about clipboard access and finding devices on your local network, allow both.

Not sure which chip?

  • Click the Apple menu in the top-left corner of the screen and choose About This Mac.
  • "Chip: Apple M1" (or M2, M3, M4…) means Apple silicon; "Processor: … Intel Core …" means Intel.
  • Almost every Mac bought since late 2020 has Apple silicon. If you pick the wrong one, just download the other: on an Apple silicon Mac the Intel version needs Rosetta installed first, and the Apple silicon version won't open on an Intel Mac.
  • Requires macOS 13 Ventura or later.

Linux

Ubuntu, Debian and derivatives

x64 ARM64 
sudo apt install ./PasteFerry-linux-amd64.deb

Other distributions

x64 ARM64 
tar xzf PasteFerry-linux-amd64.tar.gz
./PasteFerry/install.sh
  • Needs a graphical desktop: X11, or Wayland with XWayland, which GNOME, KDE and other major desktops include by default.
  • Not sure whether you have x64 or ARM64? Run uname -m in a terminal: x86_64 means x64, aarch64 means ARM64.
  • The .deb installs to /opt/PasteFerry and adds PasteFerry to the app menu. The tar.gz runs from wherever you extract it, and install.sh adds it to the app menu.
  • Once it's open, click Turn on background sync; from then on it starts when you log in. GNOME shows no tray icon by default, so open the window from the app menu.
  • Needs GTK 3. Tested on Ubuntu 24.04 with GNOME (Wayland).
