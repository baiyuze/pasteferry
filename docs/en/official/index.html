PasteFerry / Service

Works between home and office

When two computers aren't on the same network, turn on Service and they sync.

Download the latest version

How to turn it on

  1. Install the latest version on each computer and click Turn on background sync.
  2. Turn on Use the service in Settings → Connection.
  3. Pair the two computers. Computers you've already paired don't need to pair again.

Direct whenever possible

The computers connect directly when they can and go through the server only when they can't. Content is encrypted, and the server can't decrypt it.

100 MB of relay a day, direct unlimited

Relay is limited to 100 MB per computer per day; direct is unlimited. The usage page shows how much is left.

Off by default

Service is off in a new install. The server never receives what you copy; see the privacy notice.

You don't have to use it

On the same network you don't need it. You can also run your own server or use Tailscale.
