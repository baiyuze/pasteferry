Privacy and essential data

Official service is optional

Fresh installs use LAN mode. Official access and essential connection statistics begin only when enabled. Custom servers do not report to the official service. Direct connections are attempted first; machine quota identification and relay authorization happen only after direct failure.

Minimal service records

The gateway retains pseudonymous device numbers, first/last access times, daily relay usage, essential quota bindings and cumulative totals. Daily device detail is retained for 90 days. Official device counts are not people or total installations.

Content and identifiers

Content and real device names travel through the encrypted device channel. The gateway does not collect filenames, paths, usernames, MAC addresses, UA or behavior trails. Raw system identifiers are not uploaded; the application-specific digest groups relay quota and can be forged by a modified client.

Network visibility and allowance

Network endpoints necessarily see transient routing/address metadata; official statistics and ordinary proxy logs do not retain it. The default allowance is 100 MB/day, upload plus download, reset at midnight Beijing time. Direct traffic is not charged. Once enabled, the client checks its own allowance with its device signature only; this neither requests relay nor reads a machine identifier. Disabling official access stops its requests, polling and tunnels.

Update checks

Since 2.3.0 the app checks for a new version a minute after it starts and then daily. It downloads the signed update list from GitHub and Gitee with no device ID, account or other identifier, so those services see only an ordinary download from your network address. Automatic checks can be turned off in Settings → About. Updates install only after you confirm, and only if the package matches the checksum in a list signed with the PasteFerry release key.

Website and audit boundary

This website uses Cloudflare Web Analytics and aggregates website page views and download clicks by date, page path (without query strings), page language, release version, file and source (Gitee or GitHub). These counters use no analytics cookies or persistent visitor identifiers and retain no IP addresses or browser user agents. Random event IDs are retained for up to three days for deduplication; anonymous daily aggregates are retained indefinitely. Do Not Track and Global Privacy Control are respected. Clicks do not prove completed downloads, installations or people, and downloads made directly on Gitee cannot be measured. The client and signaling/TURN server remain open source, with gateway fields and protocol published. Actual private production retention still requires deployment audit.
