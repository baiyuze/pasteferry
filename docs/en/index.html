Why not what's already there

Universal Clipboard needs the same Apple ID and both Macs close together. AirDrop asks you to accept every time. Messaging yourself means manual downloads and files left on someone else's server. With one Mac and one Windows PC, none of the built-in options work at all.

How your computers connect

Same network? Install and pair. Different networks? Enable official access without hosting a server. Custom servers and Tailscale remain available when you prefer to manage the connection yourself.

Across networks, no hosting

Official service

One switch helps your home and office computers find each other. Direct connections first, automatic encrypted relay if needed. No cloud VM or server address to configure.

Enable official access → Nothing to set up

Same network

At home or in the office, behind the same router. Install the app on both computers and enter a pairing code. No server, and no computer that has to stay on.

Same network guide → Control your own capacity

Self-hosted server

A Linux VM with a public IP; the smallest one is enough. Every computer connects to it directly, at home, at the office or anywhere else, with nothing extra to install.

Public server guide → Across networks, no server

Tailscale

Install Tailscale on each computer under one account and enter the other computer's Tailscale address when pairing. Syncs at home and at the office, with no server and no computer that has to stay on.

Tailscale guide →
