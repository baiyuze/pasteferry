How your computers connect

On the same network, install and pair. On different networks, turn on Service, or run your own server or Tailscale.

Works between home and office

Service

Turn on one switch and your home and office computers sync, with no server to buy.

Turn on Service → Nothing to set up

Same network

Two computers on the same router: install the app, enter a pairing code, and you're done. No server needed.

Same network guide → Your server, unlimited relay

Your own public server

A Linux VM with a public IP; the smallest size is enough. Every computer connects to it and syncs from anywhere.

Public server guide → Across networks, no server

Tailscale

Install Tailscale on each computer, sign in to the same account, and enter the other computer's Tailscale address when pairing.

Tailscale guide →
