2.4 新功能

按 ⌥VAlt+V，
最近复制的都在手边。

在任何 App 里按一下，复制记录就出现在屏幕中间。按数字或回车，选中的内容直接粘贴进去；常用的内容收藏起来，随时取用。

了解快捷粘贴 →

不只是同步剪贴板。

  • 快捷粘贴 新

    按 ⌥VAlt+V 呼出复制记录，选中就粘贴。

  • 收藏 新

    常用的内容另存一份，不会过期。

  • 文件与文件夹

    50 MB 以内复制时就已传好，更大的需要时再取。

  • 复制记录

    所有设备复制过的都在这里，能搜索，能按类型筛选。

  • 跨网络

    开启官方服务，家里和公司之间也能同步。

  • 端到端加密

    优先直连，服务器看不到你复制了什么。

为什么不用现有的办法

通用剪贴板要同一个 Apple ID、离得够近；隔空投送每次都要点接收；发给自己要手动下载，文件还留在别人的服务器上。一台 Mac 一台 Windows 时，系统自带的办法一个都用不了。

隔空贴与其他方式的对比
隔空贴通用剪贴板隔空投送聊天软件
不同 Apple ID 之间可以不行要对方接收可以
Mac 与 Windows 之间可以不行不行可以
不在同一个网络（家里和公司）可以不行不行可以
复制后直接粘贴，不用点接收可以可以不行不行
文件与整个文件夹可以不稳定可以要先打包
找回之前复制过的内容可以不行不行翻聊天记录
仅自己的设备可解密内容可以可以可以视软件而定

两台电脑怎么连起来

同一网络里装好就能配对；不同网络里，开启官方服务即可，无需自建。也保留自建服务器与 Tailscale，按你的需要选择。

跨网络，无需自建

官方服务

打开一个开关，让家里与公司的电脑找到彼此。优先打洞直连，失败后自动中转，无需购买云主机或填写地址。

开启官方服务 → 什么都不用部署

同一网络

家里或办公室，连着同一个路由器。两台电脑装好 App，输入配对码就能同步，不需要服务器，也不需要常开的电脑。

同一网络教程 → 自己管理容量与部署

自建公网服务器

一台有公网 IP 的 Linux 云主机，最低配置就够。每台电脑直接连它，在家、在公司、在外面都能用，不用另装软件。

公网服务器部署教程 → 跨网络，不用服务器

Tailscale

每台电脑装上 Tailscale、登录同一个账号，配对时输入对方的 Tailscale 地址。在家、在公司都能同步，不需要服务器和常开的电脑。

Tailscale 教程 →
