所有设备上复制过的，都在这里

复制记录保留最近 3 天的内容，随时可以放回剪贴板，图片点开就能预览。50 MB 以内的文件在你复制的时候就已经传好了，更大的文件需要时点一下再拉取。想找以前复制过的，按文字内容或文件名搜一下就有。

按下复制之后

文字、图片、文件、整个文件夹，都走同一条路。

  1. 察觉

    Mac 上，后台服务每隔一小段时间看一眼剪贴板的变更计数，只看计数和类型，不需要授权，也不会弹出系统提示；Windows 上，复制的那一刻系统就会通知它。

  2. 传输

    文本随消息一起发出；50 MB 以内的图片和文件打包成流立即推送；更大的文件只发一条记录，等你需要时再传。

  3. 粘贴

    另一台电脑先把内容存到本地，再写入剪贴板。按下 ⌘V 或 Ctrl+V 粘贴出来的，就是本地的真实文件。

为什么不用现有的办法

通用剪贴板要同一个 Apple ID、离得够近；隔空投送每次都要点接收；发给自己要手动下载，文件还留在别人的服务器上。一台 Mac 一台 Windows 时，系统自带的办法一个都用不了。

工作原理

同一网络里，设备无需服务器就能找到彼此；跨网络时，官方服务或自建服务器帮助交换连接信息。优先打洞直连，失败后才使用加密中转。下图展示通用的信令与中转结构。

公司网络也能直连

公司双线、运营商地址池这类网络有多个出口，按目标地址选走哪一个。只探测一次只会知道其中一个出口，只能经服务器中转。隔空贴会探测每个出口，把地址都告诉对端。

做了什么

  • 共用一个端口。所有连接从同一个本地 UDP 端口收发，向不同服务器问到的地址才对得上。
  • 探测每个出口。在这个端口上同时询问 7 台 IP 分散的服务器，网络有几个出口就拿到几个地址；被 DNS 污染的地址先过滤掉。
  • 全部告诉对端。对端逐个尝试，与实际出口吻合的那一个能打通。
  • 记住见过的出口。某次漏掉的出口如果不改端口，就用「出口 IP + 本地端口」推算补上。
  • 定好谁先发包。有的路由器收到对方先到的包会占住端口。一方先公布出口地址，另一方先往那边发包再公布自己的；重试时两种顺序轮流用。
  • 空闲时重试直连。直连失败且中转可用时，先通过中转保持同步。连接空闲时可重试打洞，成功后切回直连并释放中转。

服务器看不到你复制了什么

  • 服务器不存账号，也不存内容。设备身份是一把 Ed25519 密钥，设备 ID 由公钥算出，服务器不需要用户表就能验证身份。
  • 配对时由你核对安全指纹。两块屏幕会显示同样的两行：双方各自公钥的指纹。服务器有能力替换转发中的公钥，但替换之后两块屏幕就对不上了，这一步就是防中间人的闸门。
  • 之后的每条消息都带签名，服务器无法冒充你的设备。直连通道的证书在握手后还会再核对一次，不一致立即断开。
  • 中转也只是转发密文。TURN 转发的是加密后的数据包，中转凭证按设备单独签发，12 小时后过期。
  • 局域网里也一样。设备在局域网里广播的只是一个每天都变的匿名标识，看不出是谁的电脑，只有打开「搜索附近设备」时才带上设备名；配对同样要核对指纹，之后的消息同样带签名。

出问题的时候会发生什么

每个人的网络环境都不一样。下面这些情况都考虑过，也都有对应的测试。

同一网络里找不到对方
不同网段、访客网络、开了 AP 隔离的 Wi‑Fi 会挡住局域网发现。配对时输入对方配对码下面显示的地址就行；之后地址会被记住，两边都换了地址时，在设备列表里给它重新输入一次。
系统拦着局域网
macOS 15 起，后台服务连接局域网里的设备要你允许；Windows 第一次运行时会问防火墙。没放行时 App 会提示，并给出直达的按钮。
两台电脑打不通直连
官方模式在直连失败后，按当前额度申请中转；自建模式使用自己的 TURN 中转。两种方式的内容均保持端到端加密。
公共 STUN 服务器连不上
国内访问公共 STUN 时通时断。服务器自带 STUN，客户端优先用它。
从中转切回直连
直连失败且中转可用时，先通过中转保持同步。连接空闲时可重试打洞，成功后切回直连并释放中转。
对方睡眠、断网或重启
连接悄悄断了也能发现，立即关闭重连。这期间复制的内容会记下来，连上后补发到对方的复制记录里，但不会覆盖对方此刻剪贴板里的内容。
服务器断开
自动重连，间隔从 1 秒开始翻倍、最长 30 秒，并带随机抖动，避免一群设备同时重连。同一网络里的设备不受影响，照常同步。
文件太大
超过上限的只同步一条记录，需要时再拉取。拉取时源文件已经被删，会明确告诉你，而不是不明不白地失败。
粘贴到只认纯文本的地方
从网页复制的带格式文字会同时写入 HTML 和纯文本两份，粘贴到哪里都不会冒出标签。
文件名在 Windows 上不合法
Mac 上可以用的冒号、问号等字符，收到时换成对应的全角字符，名字照样看得懂；只差大小写的两个文件也不会互相覆盖。
复制的是密码
Windows 上，密码管理器复制的内容会带一个「不要记录」的标记，隔空贴看到就跳过：不同步，也不进复制记录。
还没授权读取剪贴板
不去读内容，否则后台进程会卡在一个看不见的系统弹窗上。App 里会提示你去授权，并给出直达按钮。
后台服务崩溃
Mac 上由系统的 launchd、Windows 上由隔空贴自带的守护进程自动拉起，10 秒节流，不会疯狂重启。
更新了 App，或者把它挪了位置
打开 App 时会自动校正登录项，并把后台服务重启到新版本。

安装

每台电脑装一个 App。同一个网络里装好就能配对；跨网络时，再选一种方式让两台电脑找到彼此。第一次装可以跟着快速开始。

Mac

  1. 下载 DMG，打开后把隔空贴拖进「应用程序」。Apple 芯片与 Intel 芯片各有一版，下载页会告诉你怎么看自己的 Mac 是哪种。
  2. 从「应用程序」里打开。第一次会提示「无法验证开发者」：隔空贴还没有经过 Apple 公证。到「系统设置 → 隐私与安全性」，点页面下方的「仍要打开」，只需要这一次。
  3. 点「启用后台同步」。系统询问是否允许读取剪贴板、能否查找本地网络上的设备时，都选择允许。
  4. 跨网络时，在每台电脑的「设置」中开启「使用官方服务」，无需填写服务器地址；也可以继续自建。
下载 Mac 版

Windows

  1. 运行 PasteFerry-Setup.exe。装在当前用户目录下，不需要管理员权限。隔空贴还没有代码签名，Windows 会提示「Windows 已保护你的电脑」：点「更多信息」，再点「仍要运行」。不想运行安装程序的话，可以下载便携版。
  2. 打开隔空贴，点「启用后台同步」。关掉窗口后它在右下角的托盘里继续运行。防火墙询问时选择允许。
  3. 跨网络时，在每台电脑的「设置」中开启「使用官方服务」，无需填写服务器地址；也可以继续自建。

Linux

  2. 从应用菜单里打开隔空贴，点「启用后台同步」。之后它随登录自动启动。
  3. 跨网络时，在每台电脑的「设置」中开启「使用官方服务」，无需填写服务器地址；也可以继续自建。

常见问题

UU 远程开启时，为什么不断出现 .uuremote_ 文件？

UU 远程会在系统剪贴板里写入临时占位文件，旧版隔空贴把它们当成普通文件反复记录和转发。1.3.2 在发送和接收时过滤已确认的占位命名，启动时清理纯占位记录。正常空文件、隐藏文件和大文件不受此规则影响。50 MB 只决定是否自动传输，与 UU 的 UDP P2P 设置无关。建议两端都升级；其他软件如果也同步剪贴板，仍可能产生普通内容的重复记录。

和 macOS 自带的「通用剪贴板」有什么区别？

Mac、Windows、Linux 互通，文字、图片、文件、整个文件夹都可以，不要求同一个账号。现在开启官方服务就能跨网络同步，无需自己搭服务器。优先直连，始终端到端加密。

如果你的两台 Mac 是同一个 Apple ID、总在一起、主要复制文字，系统自带的已经够用了。

服务器会看到我复制的内容吗？

服务器无法解密复制内容：直连时内容不经过中转服务器；中转时转发的是端到端加密数据包。官方服务保留必要设备与用量统计，详见隐私说明。客户端和服务器源码公开，但源码可审计不等于对私有生产存储行为的证明。

公司网络（双线、多出口）能直连吗？

能。这类网络按目标地址选出口，隔空贴会在同一个端口上向多台服务器探测，拿到每个出口的地址一并发给对端，对端逐个尝试。实测公司 4 个出口与家用宽带之间可以直连。对端是端口随机分配的 NAT 时仍会走中转。

必须自己准备服务器吗？

不需要。不同网络时，在两台电脑上开启官方服务即可，不用购买云主机或填写地址。默认关闭，当前提供每日 100 MB 中转额度，直连不消耗此额度。局域网、自建服务器与 Tailscale 继续可用。

家里没有公网 IP，能在家和公司之间同步吗？

不需要。不同网络时，在两台电脑上开启官方服务即可，不用购买云主机或填写地址。默认关闭，当前提供每日 100 MB 中转额度，直连不消耗此额度。局域网、自建服务器与 Tailscale 继续可用。

在同一个网络里，为什么找不到另一台？

先看两台是不是真的在同一个网段：公司里有线和无线、访客网络、开了「AP 隔离」的 Wi‑Fi 常常不互通，局域网发现过不去。这时在输入配对码的那台点「不在同一网段？」，填上另一台配对码下面显示的地址。

Windows 上，第一次运行时防火墙会询问，要选允许；点过取消的话，在「设置 → 局域网」里点「放行」。Mac 上，要在「系统设置 → 隐私与安全性 → 本地网络」里打开 PasteFerry Daemon。更多见同一网络教程。

支持 Windows 和 Linux 吗？iPhone 呢？

支持 Windows 10 与 Windows 11（x64），与 Mac 互通。复制的文件在 Windows 上粘贴出来就是真实文件，能直接粘进资源管理器、微信、Office。

也支持 x64 与 ARM64 的 Linux 桌面：X11，或者带 XWayland 的 Wayland 桌面（GNOME、KDE 等默认都带）。复制的文件能直接粘进文件管理器。

iPhone 和 iPad 暂不支持：iOS 不允许 App 在后台监听剪贴板，做不到复制后立即同步。

为什么第一次打开时系统会拦一下？

隔空贴还没有经过 Apple 公证，Windows 版也还没有代码签名，两者都需要每年付费的证书。

Mac 上到「系统设置 → 隐私与安全性」，点页面下方的「仍要打开」；Windows 上在「Windows 已保护你的电脑」提示里点「更多信息」，再点「仍要运行」。都只需要这一次。

大文件怎么处理？

默认 50 MB 以内的内容在你复制时就推送到另一台电脑，那边可以直接粘贴；更大的文件只同步一条记录，需要时在复制记录里点「拉取到本机」再传。上限可以在设置里调整。

免费吗？公司能用吗？

免费。隔空贴以 GNU AGPL-3.0 开源，个人和公司都可以免费使用和修改。分发它、或通过网络提供修改过的版本时，需要以同样的许可公开源码。

官方中转无限量吗？

当前默认每机器额度组每日 100 MB 中转流量，上传与下载合计，北京时间零点重置。重新安装不会保证获得新额度。用量页显示实际额度、剩余量与更新时间；额度用尽仍可直连。额度与服务可用性可能调整，以客户端显示为准。
