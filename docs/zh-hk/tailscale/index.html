隔空貼 / 連線方式

用 Tailscale 跨網絡使用

沒有公網 IP，也不想部署伺服器？每部電腦安裝 Tailscale，配對時輸入對方的 Tailscale 地址，在家、在公司都能同步。

  2. 查地址

  4. 常見問題

就像在同一個區域網絡裏

Tailscale 是一個虛擬網絡工具：安裝了它、登入同一個帳戶的裝置，各自會分配到一個固定的、以 100 開頭的地址，不論實際身處哪個網絡，都能用這個地址互相連接。隔空貼配對時記住對方的這個地址，之後就像在同一個網絡裏一樣直接連線。

  • 不需要伺服器，也不需要長期開着的電腦：兩部電腦開着、連着 Tailscale，就能同步。
  • 地址只需輸入一次。Tailscale 地址不會改變，配對時輸入一次，之後兩部電腦會自動找到彼此。
  • 兩層加密。Tailscale 的 WireGuard 隧道裏，跑的是隔空貼自己端對端加密的連線，Tailscale 看不到內容。

Windows、macOS、Linux 都有用戶端。使用隔空貼的電腦都要安裝，並保持連線。

每部電腦安裝好 App、啟用了後台同步，見快速開始。伺服器地址留空就可以。
用 ZeroTier 也可以
其他能為每部裝置分配固定虛擬地址的網絡工具，做法相同：配對時輸入它分配的地址。下面以 Tailscale 為例。

第 1 步

在每部電腦上安裝 Tailscale

每部要同步的電腦，都安裝並登入同一個帳戶。

  1. 到 Tailscale 官方網站下載對應系統的用戶端並安裝。Linux 上執行 curl -fsSL https://tailscale.com/install.sh | sh，再執行 sudo tailscale up，開啟它提供的連結登入。
  2. 開啟 Tailscale 並登入。每部電腦都用同一個帳戶。
  3. 登入後，在 Tailscale 的管理控制台能看到所有裝置，每部都有一個以 100 開頭的地址。
下載 Tailscale

讓 Tailscale 保持連線

  • Windows：在工作列右下角的 Tailscale 圖示上按右鍵，在「Preferences」裏勾選「Run unattended」，登出之後也會保持連線。
  • Mac：確認 Tailscale 設定為登入後自動開啟。
  • 關閉密鑰過期：Tailscale 預設每 180 天要求裝置重新登入一次。長期不動的電腦，可以在管理控制台的 Machines 頁面，按那一行最右邊的選單，選擇「Disable key expiry」。

第 2 步

查看對方的 Tailscale 地址

在要配對的另一部電腦上按一下 Tailscale 的圖示（Mac 在選單列，Windows 在工作列右下角），選單裏能看到本機的地址；或者在終端機執行 tailscale ip -4。

下面以家裏那部 Windows 電腦的 100.92.41.17 為例，請換成你的地址。

第 3 步

配對時輸入這個地址

和在同一網絡裏配對一樣，只是多輸入一個地址。

  1. 在家裏那部 Windows 電腦上開啟「裝置」，按「新增裝置」，記下 6 位配對碼。
  2. 在公司的 Mac 上按「新增裝置」，切換到「輸入配對碼」，輸入它；再按「不在同一網段？」，填上 100.92.41.17，按「繼續」。
  3. 兩邊螢幕會顯示同樣的兩行安全指紋，逐字核對一致後確認。之後兩部電腦在哪裏都能同步。

兩部電腦都在家裏時，隔空貼也會在區域網絡裏直接找到對方，資料不會繞路。

常見問題

裝置之間顯示「直連」，速度卻很慢？

隔空貼顯示的「直連」，是指兩部電腦在 Tailscale 的虛擬網絡裏直接相連。Tailscale 本身打不通兩部電腦時，會經它在境外的中轉伺服器（DERP）轉發，在內地使用就會比較慢。

在終端機執行 tailscale ping 對方的地址：顯示 via DERP，代表 Tailscale 正在中轉；顯示 via 一個 IP 和端口，就是點對點。公司網絡、校園網絡比較容易遇到中轉，可以自建 DERP 中轉伺服器，或者換用另一種網絡工具。

配對時找不到對方？

先確認兩部電腦的 Tailscale 都已連線：在終端機執行 tailscale ping 對方的地址，能 ping 通再試。

能 ping 通但仍找不到，多半是對方的防火牆阻擋了：對方是 Windows 的話，在它的隔空貼「設定 → 區域網絡」裏按「允許」；是 Mac 的話，確認「系統設定 → 私隱與保安 → 本地網絡」裏已開啟 PasteFerry Daemon。

一定要每部電腦都安裝 Tailscale 嗎？

是的，沒有安裝的電腦連不到以 100 開頭的地址。兩部電腦在同一個網絡裏時，不安裝也能用，見同一網絡教學。

以前照教學在家裏安裝過伺服器，還需要它嗎？

不需要了。在每部電腦的「設定」裏清空伺服器地址，再在家裏那部電腦上解除安裝伺服器即可，已經配對的裝置不用重新配對。保留它也沒關係，伺服器和 Tailscale 可以同時使用。

Tailscale 能看到我複製的內容嗎？

不能。Tailscale 的連線用 WireGuard 端對端加密，裏面跑的又是隔空貼自己的 DTLS 加密連線，兩層都只有兩部電腦能解開。Tailscale 的伺服器只交換裝置的公鑰和地址，中轉伺服器也只轉發加密後的封包。

Tailscale 地址會改變嗎？

一般不會。地址跟隨裝置，重新啟動、更換網絡都不會改變；只有把裝置從 Tailscale 裏刪除再重新加入，才會換一個。如果換了，在「裝置」裏為那部裝置重新輸入一次地址。

我有公網伺服器，還需要 Tailscale 嗎？

不需要。把伺服器部署在有公網 IP 的機器上，所有電腦填它的地址就可以，見公網伺服器部署教學。
