隔空貼 / 下載

下載隔空貼

免費開源，目前版本 2.4.1。每部要同步的電腦各安裝一個，Mac、Windows、Linux 可以混合使用。

Windows

下載安裝程式

在內地下載很慢的話，可以改用 Gitee 鏡像：安裝程式 · 便攜版

不想執行安裝程式的話，可以下載免安裝版，解壓後直接執行。

  1. 執行 PasteFerry-Setup.exe，它會安裝在目前用戶的目錄下，不需要管理員權限。提示「Windows 已保護您的電腦」時，按「其他資訊」，再按「仍要執行」。
  2. 開啟隔空貼，按「啟用背景同步」。防火牆詢問時選擇允許。
  • Windows 10 與 Windows 11，x64。
  • 安裝程式約 23 MB，免安裝版約 29 MB。
  • 關閉視窗後，隔空貼會在工作列右下角的系統匣裏繼續執行。

macOS

Apple 晶片（M1 或更新） Intel 處理器

在內地下載很慢的話，可以改用 Gitee 鏡像：Apple 晶片 · Intel 晶片 · 通用版

兩種 Mac 都能用的通用版也有提供，檔案大一倍。

  1. 開啟下載的 DMG，把隔空貼拖進「應用程式」。
  2. 從「應用程式」裏開啟。第一次會提示「無法驗證開發者」：到「系統設定 → 私隱與保安」，按頁面下方的「強制開啟」。
  3. 按「啟用背景同步」。系統詢問是否允許讀取剪貼簿、能否尋找本地網絡上的裝置時，都選擇允許。

不確定你的 Mac 屬於哪一種？

  • 按螢幕左上角的 Apple 選單，選擇「關於此 Mac」。
  • 寫着「晶片：Apple M1」（或 M2、M3、M4 等）的是 Apple 晶片；寫着「處理器：… Intel Core …」的是 Intel 處理器。
  • 2020 年底之後購買的 Mac 大多配備 Apple 晶片。選錯了也不要緊，換另一個下載就可以：Intel 版在 Apple 晶片的 Mac 上要先安裝 Rosetta，Apple 晶片版在 Intel 處理器的 Mac 上無法開啟。
  • 需要 macOS 13 Ventura 或以上。

Linux

Ubuntu、Debian 及其衍生版

x64 ARM64 
sudo apt install ./PasteFerry-linux-amd64.deb

其他發行版

x64 ARM64 
tar xzf PasteFerry-linux-amd64.tar.gz
./PasteFerry/install.sh

在內地下載很慢的話，可以改用 Gitee 鏡像：.deb x64 · .deb ARM64 · tar.gz x64 · tar.gz ARM64

  • 需要圖形桌面：X11，或者帶 XWayland 的 Wayland 桌面，GNOME、KDE 等主流桌面預設都已包含。
  • 不確定是 x64 還是 ARM64：在終端機執行 uname -m，顯示 x86_64 是 x64，aarch64 是 ARM64。
  • .deb 會安裝在 /opt/PasteFerry，並出現在應用程式選單裏。tar.gz 解壓到哪裏都能執行，install.sh 會把它加入應用程式選單。
  • 開啟後按「啟用背景同步」，之後會在登入時自動啟動。GNOME 預設不顯示系統匣圖示，請從應用程式選單開啟視窗。
  • 需要 GTK 3。已在 Ubuntu 24.04 的 GNOME（Wayland）上實測。

其他

伺服器
兩部電腦在同一個網絡裏不需要伺服器。跨網絡時的幾種方式見快速開始，伺服器的安裝檔在各自的教學裏。
校驗檔案
所有檔案的 SHA-256 都在 SHA256SUMS 裏。
更新內容與舊版本
這個版本改了甚麼，見發佈說明；舊版本在 GitHub Releases。
內地鏡像
程式碼和最近兩個版本的安裝檔同步在 Gitee，與 GitHub 上的檔案相同，可以用 SHA256SUMS 校驗。
