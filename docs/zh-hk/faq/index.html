隔空貼

常見問題

找不到答案的話，歡迎回報。

和 Mac 內建的「通用剪貼簿」有甚麼分別？

「通用剪貼簿」只在同一個 Apple ID 的 Apple 裝置之間、而且在附近時有效。隔空貼不看帳戶，Mac、Windows、Linux 都可以，家裏和公司之間也能用。

和 AirDrop 有甚麼分別？

AirDrop 只在附近的 Apple 裝置之間能用。隔空貼的「隔空傳送」Mac、Windows、Linux 互相都能傳，不在同一個網絡也可以。它不能和 Apple 的 AirDrop 互通，兩邊都要裝隔空貼。

一定要自己準備伺服器嗎？

不用。同一網絡裏裝好就能配對；不在同一個網絡，開啟服務就可以。也可以用自建伺服器或 Tailscale。

家裏沒有公網 IP，能在家和公司之間同步嗎？

能，開啟服務就可以。

伺服器能看到我複製的內容嗎？

看不到，內容是端對端加密的。詳情見私隱說明。

中轉額度有多少？

每部電腦每日 100 MB，直連不計。用完了直連照樣能用；要不限量可以自建伺服器。

在同一個網絡裏，為甚麼找不到另一部電腦？

多數是不在同一個網段，或者被防火牆擋住了。配對時按「不在同一網段？」填上對方地址，詳情見同一網絡教學。

能把檔案傳到別人的電腦嗎？

能。2.6 起加個好友就能傳，不用配對，對方按接受才開始傳。好友看不到你的剪貼簿和複製記錄。

大檔案怎樣處理？

50 MB 以內複製時已經傳好；更大的要用時再取，或者用「隔空傳送」直接傳，不限大小。

支援 Windows 和 Linux 嗎？iPhone 呢？

支援 Windows 10、11 和 Linux（x64、ARM64）。iPhone 和 iPad 暫不支援，iOS 不允許 App 在背景讀取剪貼簿。

為甚麼第一次開啟時系統會阻擋一下？

仍未做 Apple 公證和 Windows 程式碼簽署。在 Mac 上到「系統設定 → 私隱與保安」按「強制開啟」；在 Windows 上按「其他資訊」→「仍要執行」。只需要做一次。

免費嗎？公司可以用嗎？

免費，個人和公司都可以用。隔空貼以 GNU AGPL-3.0 開源。

公司網絡（雙線、多出口）能直連嗎？

能，隔空貼會把每個出口都試一次。

開啟 UU 遠程時，為甚麼不斷出現 .uuremote_ 檔案？

這是舊版本的問題，升級到新版本就好了。
