私隱說明

一句話

你複製的內容、傳送的檔案和檔案名稱、寫的備註，都在你自己的裝置之間端對端加密傳輸。我們看不到，也不保存。

服務（開啟後）

新安裝預設只用區域網絡。開啟「服務」後，裝置會連接官方伺服器，以便在不同網絡裏找到彼此。我們會記錄去識別化的裝置編號、首次與最近連接時間和每日的中轉用量。只有直連失敗、需要中轉時，才會產生一個隔空貼專用的機器摘要，用來讓同一部電腦共用一份中轉額度。真實裝置名稱、原始系統識別碼和任何內容都不會上傳。

檢查更新

App 每日檢查一次更新，從隔空貼官網、GitHub 和 Gitee 取得簽署過的更新清單。請求官網時會附帶版本、系統、語言，以及是否為當天、當週或當月的首次檢查，用於提供對應的更新和規劃後續版本；不附帶裝置 ID 或帳戶，不保存 IP。可以在「設定 → 關於」關閉自動檢查。新版本只有在你確認後才會安裝，並且必須與隔空貼發佈密鑰簽署的清單一致。

好友

加了好友，對方看得到你設定的顯示名稱和頭像、傳檔案那部電腦的名稱和系統，以及你用的是區域網絡、服務還是自建伺服器（自建伺服器只給出地址的摘要）。你的剪貼簿、複製記錄和其他裝置不會給好友；好友傳來的檔案，要你按接受才會傳。

官網

本站使用 Cloudflare Web Analytics，並自行彙總頁面瀏覽量與下載點擊（日期、頁面路徑、頁面語言、下載的版本與檔案）。不使用統計 Cookie 或持久訪客識別碼，不保存 IP 或瀏覽器識別資料。瀏覽器開啟 Do Not Track 或 Global Privacy Control 時，不傳送本站自有的統計。

用途

上述資料用於提供和改進服務、發佈更新、維護安全與防止濫用、統計與規劃，以及遵守法律要求。我們不出售這些資料，也不用於廣告。

第三方

GitHub、Gitee、Cloudflare，以及你自己選用的伺服器，會按各自的私隱政策處理你與它們之間的請求。

保存期限

「服務」的裝置每日明細保留 90 日；不含個人身分的每日彙總長期保存。

你的選擇

你可以只用區域網絡、關閉「服務」、關閉自動檢查更新，或者自建伺服器。隔空貼的用戶端與伺服器程式碼開源，可以自行查閱。

免責與變更

隔空貼與「服務」按現狀免費提供，中轉額度與功能可能調整或暫停。因網絡、裝置、第三方服務或自建伺服器造成的資料遺失或無法同步，我們不承擔責任。本說明更新後在官網公佈即生效，繼續使用即表示同意更新後的內容。
