隔空貼 / 快速開始

快速開始

安裝好 App，選一種連線方式，再把兩部電腦配對。在同一個網絡裏幾分鐘就完成，之後複製的內容就會自動同步。

  1. 安裝 App
  2. 選擇連線方式
  3. 配對

第 1 步

在每部電腦上安裝 App

要同步的每部電腦都安裝一個，Mac、Windows、Linux 可以混合使用。

Mac

  1. 下載 DMG，開啟後把隔空貼拖進「應用程式」。Apple 晶片與 Intel 處理器的 Mac 各有一個版本，下載頁會告訴你怎樣選擇。
  2. 從「應用程式」裏開啟。第一次會提示「無法驗證開發者」：到「系統設定 → 私隱與保安」，按頁面下方的「強制開啟」。
  3. 按「啟用背景同步」。系統詢問是否允許讀取剪貼簿、能否尋找本地網絡上的裝置時，都選擇允許。
下載 Mac 版

Windows

  1. 執行 PasteFerry-Setup.exe，不需要管理員權限。提示「Windows 已保護您的電腦」時，按「其他資訊」，再按「仍要執行」。
  2. 開啟隔空貼，按「啟用背景同步」。防火牆詢問時選擇允許。關閉視窗後，它會在右下角的系統匣裏繼續執行。
下載 Windows 版

Linux

  1. Ubuntu、Debian 等發行版安裝 .deb；其他發行版解壓 tar.gz，執行裏面的 install.sh。
  2. 從應用程式選單開啟隔空貼，按「啟用背景同步」。
下載 Linux 版

第 2 步

選擇一種連線方式

同一網絡裏裝好就能配對；不同網絡裏，啟用官方服務即可，無需自建。也保留自建伺服器與 Tailscale，按需要選擇。

官方服務

  1. 在每部需要同步的電腦上安裝最新版本，啟用背景同步。
  2. 在每部電腦的「設定」中開啟「使用官方服務」，閱讀並確認必要統計說明。不用填寫官方網域或端口。
  3. 一部產生配對碼，另一部輸入；核對兩邊的安全指紋後確認。原有配對關係可以繼續使用。

新安裝預設關閉。啟用後記錄必要連線統計；只在申請中轉時衍生項目專用機器摘要。真實裝置名稱、原始系統識別碼和複製內容不作為統計上傳。完整欄位與保留期限見私隱說明。

啟用官方服務 →
先直連，再中轉
官方信令只協助在線裝置交換連線資料。用戶端先用 STUN 探測和打洞；本輪直連失敗後，才申請官方中轉。傳輸內容始終端到端加密。
直連不消耗中轉額度
目前預設每機器額度組每日 100 MB 中轉流量，上傳與下載合計，北京時間午夜重設。重新安裝不保證獲得新額度。開啟後用量頁即顯示今日額度、剩餘量與更新時間，不必先使用中轉，並列出每部裝置目前是直連還是中轉；額度用完仍可直連。額度與服務可用性可能調整，以用戶端顯示為準。

同一網絡

  1. 每部電腦安裝好 App，按「啟用背景同步」。
  2. Windows 防火牆詢問時選擇允許；macOS 詢問能否尋找本地網絡上的裝置時，也選擇允許。
  3. 一部顯示配對碼，另一部輸入它，再核對指紋。不在同一網段時，還要輸入配對碼下面顯示的地址，見同一網絡教學。

不需要填寫伺服器地址。

同一網絡教學 →
適合
電腦都在同一個 Wi‑Fi 或有線網絡裏，例如家裏或辦公室。
要準備
甚麼都不用。每部電腦安裝好 App 就可以。
要注意
離開這個網絡就不會同步，回來後自動恢復。公司裏的有線和無線網絡不在同一網段時，配對時要多輸入一個地址。

自建公網伺服器

  1. 在雲端供應商的安全群組裏開放 TCP 8787、UDP 3478 和 UDP 32768–60999。
  2. 用 ssh 登入伺服器，下載並執行安裝腳本，帶上它的公網 IP：sudo ./install.sh 公網IP。
  3. 在每部電腦的「設定」裏填寫伺服器地址 ws://公網IP:8787/signal，按 Enter，然後配對。

在瀏覽器開啟 http://公網IP:8787/healthz，看到 ok 就代表安裝好了。

公網伺服器部署教學 →
適合
自行管理容量與部署
要準備
一部有公網 IP 的 Linux 雲端伺服器，最低配置已經足夠，需要 root 權限。
要注意
雲端伺服器要付費。打不通直連時經中轉，速度受伺服器頻寬限制。在內地的雲端伺服器上，域名未有 ICP 備案時，用戶端要填 IP。

Tailscale

  1. 每部電腦安裝 Tailscale，登入同一個帳戶。
  2. 在要配對的那部電腦上執行 tailscale ip -4，記下以 100 開頭的地址。
  3. 配對時，在輸入配對碼的那部電腦按「不在同一網段？」，填上這個地址。

不需要伺服器。Tailscale 地址不會改變，只需在配對時輸入一次。

Tailscale 教學 →
適合
電腦在不同的網絡裏，又沒有公網伺服器。
要準備
每部電腦都安裝 Tailscale，並登入同一個帳戶。
要注意
所有使用隔空貼的電腦都要安裝 Tailscale 並保持連線。Tailscale 本身打不通時會經境外中轉，在內地會比較慢。

第 3 步

把兩部電腦配對

每兩部電腦之間配對一次，之後就不用再理會了。

  1. 在一部電腦上開啟「裝置」，按「新增裝置」，會顯示一個 6 位配對碼，5 分鐘內有效，下面是這部電腦的地址。
  2. 在另一部電腦按「新增裝置 → 輸入配對碼」。官方服務無需填寫 IP；只在區域網絡跨網段或 Tailscale 配對時，展開地址欄填寫對方地址。
  3. 兩邊螢幕會顯示同樣的兩行安全指紋。逐字核對一致後，再按確認。這一步防止有人在中間冒充你的裝置，不要略過。

複製試試看。

在一部電腦上複製文字、圖片或檔案，到另一部按 ⌘V 或 Ctrl+V。兩邊複製過的內容都在「複製記錄」裏。
