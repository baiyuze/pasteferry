隔空貼 / 連線方式

在同一網絡裏直接使用

兩部電腦連着同一部路由器，就不需要伺服器。安裝好 App，輸入配對碼，之後複製的內容就會同步。

  1. 開始之前
  2. 配對
  3. 不在同一網段
  4. 常見問題

不需要伺服器

同一個網絡裏的兩部電腦，靠 mDNS 互相發現、直接交換連線資訊，然後建立加密的直連。沒有伺服器，也不需要長期開着的電腦。

  • 自動發現。每部電腦用 mDNS 在區域網絡裏廣播自己，廣播裏只有一個每天都會改變的匿名標識，看不出是誰的電腦。開啟「搜尋附近裝置」時才會帶上裝置名稱，關閉後就會撤下。
  • 直連。複製的內容在兩部電腦之間直接傳輸，速度就是區域網絡的速度。
  • 安全依舊。配對時核對兩行安全指紋，之後的每條訊息都帶簽名，同一網絡裏的其他人無法冒充你的裝置。

開始之前

在同一個網絡裏
兩部電腦連着同一部路由器就可以，Wi‑Fi 與有線混用也行。訪客網絡、開啟了「AP 隔離」的 Wi‑Fi 不讓裝置互相連接；公司裏的有線和無線網絡往往不在同一個網段，這時請看下面的不在同一網段。
Windows 防火牆
第一次執行時，Windows 防火牆會詢問是否允許隔空貼存取網絡，請選擇允許。如果按過取消，可在隔空貼的「設定 → 區域網絡」裏按「允許」，這會請求一次管理員權限。
macOS 的本地網絡權限
由 macOS 15 起，第一次連接區域網絡裏的裝置時，系統會詢問是否允許 PasteFerry Daemon 尋找本地網絡上的裝置，請選擇允許。如果拒絕過，可到「系統設定 → 私隱與保安 → 本地網絡」裏開啟它。
不用填寫伺服器
「設定」裏的伺服器地址留空就可以。日後要跨網絡同步，再填上伺服器或改用 Tailscale，已經配對的裝置不用重新配對。

第 1 步

把兩部電腦配對

每兩部電腦之間配對一次。如果仍未安裝 App，請先按快速開始安裝好。

  1. 在一部電腦上開啟「裝置」，按「新增裝置」，會顯示一個 6 位配對碼，5 分鐘內有效。
  2. 在另一部電腦上同樣按「新增裝置」，切換到「輸入配對碼」，輸入它，再按「繼續」。
  3. 兩邊螢幕會顯示同樣的兩行安全指紋。逐字核對一致後，再按確認。之後複製的內容就會同步。

不用配對碼：「搜尋附近裝置」

  1. 兩部電腦都開啟「裝置」，按「搜尋附近裝置」。視窗開啟期間，同一網絡裏的裝置才能看到這部電腦的名稱。
  2. 對方出現在雷達上之後，按一下它。兩邊螢幕會顯示同樣的兩行安全指紋，核對一致後各自確認。
  3. 只在同一網段裏有效。找不到對方時，請改用上面的配對碼。

第 2 步

不在同一網段

區域網絡發現只在一個網段裏有效。兩部電腦在不同網段、但網段之間互通時（公司裏很常見），配對時多輸入一個地址就可以。

  1. 顯示配對碼的那部電腦，在配對碼下面能看到本機的地址，例如 192.168.1.20。
  2. 輸入配對碼的那部電腦，按「不在同一網段？」，填上這個地址，再按「繼續」。
  3. 配對之後，兩部電腦會記住彼此的地址。其中一部換了地址時，只要另一部沒有換，就會自動重新找到；兩部都換了地址時，在「裝置」裏按那部裝置的「…」選單，選擇「輸入它的地址」。

兩個網段之間完全不通時（例如訪客網絡與辦公網絡分隔開），只能經一部兩邊都能連到的電腦中轉，見在區域網絡裏部署伺服器。

常見問題

找不到另一部電腦？

先確認兩部電腦連着同一個網絡，而且都已啟用後台同步。再試試在輸入配對碼的那部電腦填上對方的地址：這樣能找到的話，代表兩部不在同一網段，或者網絡阻擋了 mDNS。

仍然找不到，就檢查對方的防火牆：對方是 Windows 的話，在它的「設定 → 區域網絡」裏按「允許」；是 Mac 的話，確認「系統設定 → 私隱與保安 → 本地網絡」裏已開啟 PasteFerry Daemon，系統防火牆也沒有阻擋它。

離開這個網絡後還能同步嗎？

不能，回到這個網絡後會自動恢復，這期間複製的內容會補發到對方的複製記錄裏。要在不同網絡之間同步，可加一部公網伺服器，或者改用Tailscale，已經配對的裝置不用重新配對。

地址改變了怎麼辦？

一般不用理會。在同一網段裏靠 mDNS 隨時能找到；在不同網段時，只要有一部的地址沒有改變，就能自動重新連上。兩部都換了地址時，在「裝置」裏為那部裝置重新輸入一次地址。

長期放着不動的桌面電腦，可以在路由器的「DHCP 靜態分配」裏給它固定一個地址。

同一網絡裏的其他人會看到我的電腦嗎？

能看到網絡裏有一部隔空貼，但看不出是誰的：廣播裏只有一個每天都會改變的匿名標識，沒有裝置名稱，也沒有裝置 ID。只有在你開啟「搜尋附近裝置」的那段時間，廣播裏才會帶上裝置名稱，關閉視窗後就會撤下。沒有和你配對過的裝置，傳來的訊息一律丟棄；配對時還要兩邊核對安全指紋。

用了哪些端口？

UDP 8788 用來交換連線資訊（被佔用時會換一個隨機端口），mDNS 用 UDP 5353，連上之後的資料走另一個隨機的 UDP 端口。不需要在路由器上做任何設定。
