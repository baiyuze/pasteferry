Privacidad

En resumen

Lo que copias, los archivos que envías, sus nombres y tus notas viajan cifrados de extremo a extremo entre tus propios dispositivos. No podemos verlos y no almacenarlos.

Servicio (cuando está activado)

Las nuevas instalaciones utilizan únicamente la red local. Cuando activa el Servicio, sus dispositivos se conectan al servidor oficial para que puedan encontrarse entre sí a través de las redes. Mantenemos un número de dispositivo seudónimo, la primera y la última hora de conexión y el uso diario del relé. Solo cuando falla una conexión directa y se necesita retransmisión, la aplicación genera un resumen de máquina específico PasteFerry, de modo que una computadora comparte una asignación de retransmisión. Los nombres reales de los dispositivos, los identificadores del sistema sin procesar y el contenido nunca se cargan.

Comprobaciones de actualización

La aplicación busca actualizaciones una vez al día y obtiene una lista de actualizaciones firmadas del sitio web PasteFerry , GitHub y Gitee. La solicitud al sitio web incluye la versión, sistema e idioma, y ​​si es la primera verificación del día, semana o mes, para brindar la actualización adecuada y planificar futuros lanzamientos. No se incluye ninguna ID de dispositivo ni cuenta y no se almacenan direcciones IP. Las comprobaciones automáticas se pueden desactivar en Configuración → Acerca de. Las actualizaciones se instalan solo después de que usted confirme y solo si coinciden con una lista firmada con la clave de versión PasteFerry .

Contactos

Un contacto ve el nombre para mostrar y el avatar que usted configuró, el nombre y el sistema de la computadora desde donde envía, y si usa la red local, el Servicio o su propio servidor (para su propio servidor, solo un resumen de su dirección). Su portapapeles, historial y otros dispositivos nunca se comparten con sus contactos y sus archivos llegan solo después de que usted los acepta.

Sitio web

Este sitio web utiliza Cloudflare Web Analytics y mantiene sus propios totales de visitas a la página y clics de descarga (fecha, ruta de la página, idioma de la página, versión y archivo descargado). No se utilizan cookies analíticas ni identificadores persistentes de visitantes, y no se almacenan direcciones IP ni identificadores de navegador. Con Do Not Track o Global Privacy Control activados, no se envían los contadores propios del sitio web.

Discusión y comentarios

Los apodos y el texto que envíe se almacenan en el servidor para su revisión y soporte, y se vuelven públicos después de su aprobación. Cuando la revisión de IA está habilitada, el texto necesario se envía a un servicio de IA de terceros, como DeepSeek, según los términos de manejo de datos de ese proveedor; Los administradores también pueden leer y manejar los envíos. Su navegador guarda borradores, registros de envío y credenciales de acceso por mensaje por hasta 30 días. Borrar los datos locales no elimina los mensajes del servidor; utilice el navegador original para retirarlos. El contenido no publicado, retirado y oculto se elimina después de 90 días; El contenido público permanece hasta que sea retirado o eliminado. La prevención de abusos utiliza resúmenes temporales de fuentes en lugar de almacenar direcciones IP sin procesar. No envíe contraseñas, claves API o información privada.

como se usa

Esta información se utiliza para proporcionar y mejorar el servicio, publicar actualizaciones, mantener el servicio seguro y evitar abusos, medir y planificar, y cumplir con las obligaciones legales. No lo vendemos ni lo utilizamos para publicidad.

Terceros

GitHub, Gitee, Cloudflare y cualquier servidor que elija manejan sus solicitudes según sus propias políticas de privacidad.

Retención

Los detalles diarios por dispositivo para el Servicio se conservan durante 90 días; Los totales diarios sin identidad personal se mantienen indefinidamente.

Tus elecciones

Puede utilizar únicamente la red local, desactivar el Servicio, desactivar las comprobaciones de actualizaciones automáticas o ejecutar su propio servidor. El cliente y el servidor PasteFerry son de código abierto.

Descargo de responsabilidad y cambios

PasteFerry y el Servicio se proporcionan de forma gratuita y tal cual; Las asignaciones y características de retransmisión pueden cambiar o suspenderse. No somos responsables de la pérdida de datos o sincronizaciones fallidas causadas por redes, dispositivos, servicios de terceros o servidores autohospedados. Los cambios a este aviso entran en vigor cuando se publican en el sitio web; continuar usando PasteFerry significa que los acepta.

Contacto

Preguntas sobre este aviso: abra un problema en github.com/baiyuze/pasteferry/issues.
