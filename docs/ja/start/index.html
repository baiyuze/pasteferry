PasteFerry / はじめかた

はじめかた

アプリを入れて、接続方法を選び、2 台をペアリングします。同じネットワークなら数分で終わります。

  1. アプリを入れる
  2. 接続方法を選ぶ
  3. ペアリング
  4. スマホの使い方

ステップ 1

各コンピューターにアプリを入れる

同期したいコンピューターすべてに入れます。Mac、Windows、Linux の組み合わせも自由です。

Mac

  1. DMG をダウンロードして開き、PasteFerry を「アプリケーション」にドラッグします。Apple シリコン版と Intel 版があります。どちらを選べばよいかはダウンロードページで確かめられます。
  2. 「アプリケーション」から開きます。初回は「開発元を検証できません」と表示されます。「システム設定 → プライバシーとセキュリティ」を開き、ページ下部の「このまま開く」をクリックします。
  3. 「バックグラウンド同期を有効にする」をクリックします。クリップボードの読み取りと、ローカルネットワーク上のデバイスを探すことについて聞かれたら、どちらも許可します。
Mac 版をダウンロード

Windows

  1. PasteFerry-Setup.exe を実行します。管理者権限は要りません。「Windows によって PC が保護されました」と出たら、「詳細情報」を押してから「実行」を押します。
  2. PasteFerry を開き、「バックグラウンド同期を有効にする」をクリックします。ファイアウォールに聞かれたら許可します。ウィンドウを閉じても通知領域で動き続けます。
Windows 版をダウンロード

Linux

  1. Ubuntu や Debian などでは .deb をインストールします。ほかのディストリビューションでは tar.gz を展開し、中の install.sh を実行します。
  2. アプリケーションメニューから PasteFerry を開き、「バックグラウンド同期を有効にする」をクリックします。
Linux 版をダウンロード

ステップ 2

接続方法を選ぶ

同じネットワークなら、入れてそのままペアリング。別のネットワークなら「サービス」をオンにするだけです。自分で管理したいなら、独自サーバーや Tailscale も使えます。

サービス

  1. 各パソコンに最新版を入れ、「バックグラウンド同期を有効にする」をクリックします。
  2. 「設定 → 接続」で「サービスを使う」をオンにします。
  3. 2 台をペアリングします。ペアリング済みならそのままで使えます。

新しく入れたアプリではオフになっています。コピーした内容はサーバーに届きません。詳しくはプライバシーに関する説明をご覧ください。

「サービス」をオンにする →
直接つながれば中継しない
直接つながればそのまま、つながらないときだけサーバーが中継します。内容は暗号化され、サーバーには読めません。
中継は 1 日 100 MB、直接接続は無制限
中継はパソコン 1 台につき 1 日 100 MB、直接接続は無制限です。残りは使用量のページで確認できます。

同じネットワーク

  1. 各コンピューターにアプリを入れ、「バックグラウンド同期を有効にする」をクリックします。
  2. Windows ファイアウォールと、macOS のローカルネットワークの確認には、どちらも「許可」を選びます。
  3. 一台でコードを表示し、もう一台で入力して指紋を照合します。別のサブネットにある場合は、コードの下のアドレスも入力します（同じネットワークでの手順）。

サーバーのアドレスは入力不要です。

同じネットワークでの手順 →
向いている
家や会社で、2 台が同じ Wi‑Fi か有線ネットワークにある場合。
必要なもの
特にありません。各コンピューターにアプリを入れるだけです。
注意
そのネットワークを離れると同期は止まり、戻れば自動で再開します。有線と Wi‑Fi でサブネットが違う場合は、ペアリング時にアドレスをひとつ入力します。

独自の公開サーバー

  1. クラウドのセキュリティグループで TCP 8787、UDP 3478、UDP 32768–60999 を開けます。
  2. ssh でログインし、インストールスクリプトをダウンロードして実行します：sudo ./install.sh グローバルIP。
  3. 各コンピューターの「設定 → 接続」に ws://グローバルIP:8787/signal を入力して Return を押し、ペアリングします。

ブラウザーで http://グローバルIP:8787/healthz を開き、ok と表示されれば完了です。

公開サーバーでの手順 →
向いている
サーバーを自分で管理したい場合や、中継をたくさん使う場合。
必要なもの
グローバル IP のある Linux クラウドサーバーと root 権限。
注意
クラウドサーバーの費用がかかります。中継の速度はサーバーの帯域しだいです。中国本土では ICP 登録のないドメインが使えないため、IP を入力します。

Tailscale

  1. 各コンピューターに Tailscale を入れ、同じアカウントでサインインします。
  2. 相手のコンピューターで tailscale ip -4 を実行し、100 で始まるアドレスを控えます。
  3. ペアリングのときに「別のサブネットにありますか？」をクリックし、そのアドレスを入力します。

サーバーは要りません。Tailscale のアドレスは変わらないので、入力はペアリングのときの一度だけです。

Tailscale での手順 →
向いている
すでに Tailscale を使っている場合や、どのサーバーにも頼りたくない場合。
必要なもの
すべてのコンピューターに、同じアカウントでサインインした Tailscale。
注意
Tailscale は常に接続しておきます。Tailscale 自体が直接つなげないときは DERP サーバー経由になり、遅くなることがあります。

ステップ 3

2 台をペアリングする

2 台ごとに一度ペアリングすれば、あとは何もする必要はありません。

  1. 一台で「デバイス」を開き、「デバイスを追加」をクリックします。5 分間有効な 6 桁のコードと、その下にこのコンピューターのアドレスが表示されます。
  2. もう一台で「デバイスを追加 → コードを入力」を選びます。「サービス」なら相手のアドレスは不要です。別のサブネットや Tailscale でペアリングするときだけ、アドレス欄を開いて入力します。
  3. 両方の画面に同じ 2 行の指紋が表示されます。1 文字ずつ照合して一致していれば確定します。途中で誰かがあなたのデバイスになりすますのを防ぐ手順です。省略しないでください。

スマホの使い方

パソコン同士をペアリングしたら、スマホもいつでも参加できます。QR コードを読んでウェブ版、または Android アプリを。

ウェブ版：インストール不要

  1. パソコン：「デバイス › スマホのウェブ転送」を開いてスイッチをオンにすると QR コードが出ます。
  2. スマホ：カメラかブラウザで読み取り、名前を付けます。
  3. 以後、スマホのブラウザにパソコンの履歴が出ます。「コピー」でスマホへ、「送信」でテキスト・写真・ファイルをパソコンへ。

Android アプリ：パソコンと同じようにペアリング

  1. スマホ：APK をダウンロードしてインストール（提供元不明のアプリのインストールを許可）。
  2. パソコン：「デバイス → デバイスを追加 → コードを表示」。
  3. スマホ：コードを入力し、指紋が一致したら確認。
  4. 以後、パソコンでコピーした内容がスマホの履歴に入り、クリップボードにも反映されます。

コピーしてみましょう。

一台でテキスト、画像、ファイルをコピーし、もう一台で ⌘V か Ctrl+V を押します。どちらでコピーしたものも履歴に残ります。

困ったときは：同じネットワークのよくある質問 · Tailscale のよくある質問 · 公開サーバーのよくある質問 · 問題を報告
