プライバシー

ひとことで

コピーした内容、送信したファイルとファイル名、メモは、あなたのデバイス間でエンドツーエンドで暗号化して送られます。私たちには見えず、保存もしません。

サービス（オンにした場合）

新規インストールではローカルネットワークだけを使います。「サービス」をオンにすると、別のネットワークにあるデバイス同士が見つけ合えるよう公式サーバーに接続します。仮名化した端末番号、初回・最終接続時刻、日別の中継使用量を記録します。直接接続できず中継が必要なときだけ、同じパソコンで中継の上限を共有するための PasteFerry 専用のマシンダイジェストを作ります。実際の端末名、元のシステム識別子、内容は送信しません。

アップデートの確認

アプリは 1 日 1 回、PasteFerry の Web サイト、GitHub、Gitee から署名付きのアップデート一覧を取得します。Web サイトへのリクエストには、バージョン、OS、言語と、その日・週・月で最初の確認かどうかを含めます。適切なアップデートの提供と今後のリリースの計画に使います。端末 ID やアカウントは含めず、IP アドレスは保存しません。自動確認は「設定 → このアプリについて」でオフにできます。アップデートは確認後にのみインストールし、PasteFerry のリリース鍵で署名された一覧と一致するものだけを使います。

連絡先

連絡先に見えるのは、設定した表示名とアイコン、送信するパソコンの名前と OS、ローカルネットワーク・サービス・自前のサーバーのどれを使っているか（自前のサーバーはアドレスのダイジェストのみ）です。クリップボード、履歴、ほかのデバイスが連絡先に渡ることはなく、相手からのファイルはあなたが受け入れたときだけ届きます。

Web サイト

当サイトは Cloudflare Web Analytics を使い、ページの閲覧数とダウンロードのクリック数（日付、ページのパス、表示言語、ダウンロードしたバージョンとファイル）を独自に集計しています。統計用 Cookie や永続的な訪問者 ID は使わず、IP アドレスやブラウザーの識別情報は保存しません。Do Not Track または Global Privacy Control が有効な場合、当サイト独自の集計は送信しません。

利用目的

これらの情報は、サービスの提供と改善、アップデートの配信、セキュリティの維持と不正利用の防止、集計と計画、法令の遵守のために使います。販売したり広告に使ったりすることはありません。

第三者

GitHub、Gitee、Cloudflare、およびあなたが選んだサーバーは、それぞれのプライバシーポリシーに従ってリクエストを扱います。

保存期間

サービスの端末ごとの日別明細は 90 日間保存し、個人を特定しない日別の集計は無期限に保存します。

あなたの選択

ローカルネットワークだけを使う、サービスをオフにする、自動アップデート確認をオフにする、自前のサーバーを使う、のいずれも選べます。PasteFerry のクライアントとサーバーはオープンソースです。

免責と変更

PasteFerry とサービスは無料で現状のまま提供され、中継の上限や機能は変更・停止されることがあります。ネットワーク、デバイス、第三者のサービス、自前のサーバーが原因のデータ消失や同期の失敗について責任を負いません。本説明の変更は Web サイトで公開した時点で有効となり、引き続き利用することで変更後の内容に同意したものとみなします。
