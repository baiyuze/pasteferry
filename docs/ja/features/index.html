PasteFerry の機能

コピペは、
こうあるべき。

Mac、Windows、Linux の間でクリップボードを同期。コピーしたものは、いつでも呼び出せます。

PasteFerry をダウンロード ▶ 紹介ムービーを見る

こっちでコピー、
あっちでペースト。

⌘CCtrl+C を押すと、ほかのパソコンに同期されます。向こうで ⌘VCtrl+V を押すだけ。同じアカウントは不要で、Mac、Windows、Linux を自由に組み合わせられます。

MacBook⌘C
WindowsCtrl+V
LinuxCtrl+V

  • テキスト、画像、ファイル、フォルダ

    書式付きテキストをプレーンテキストの欄に貼っても、タグは出ません。

  • 50 MB までは、コピーした時点で転送済み

    大きいものはまず記録だけ同期し、必要なときに取得。上限は変更できます。

  • 相手がオフラインでも失われない

    その間にコピーしたものは、つながった後に相手の履歴へ届きます。

  1. 1

    ⌥VAlt+V を押す

    どのアプリでも。画面の中央に開き、選び終わると元のアプリに戻ります。

  2. 2

    数文字を入力

    テキストもファイル名も検索できます。検索しないときは、最初の 9 件を数字で選べます。

  3. 3

    ↩Enter を押せば完了

    カーソルの位置にペーストされます。⇧↩Shift+Enter でプレーンテキスト、⌘↩Ctrl+Enter はコピーだけ。

ショートカットは設定で変更・オフにできます。Mac で直接ペーストするにはアクセシビリティの許可が必要で、許可しない場合はコピーされるので ⌘V で貼り付けます。Linux の Wayland でも、選んだ後に Ctrl+V で貼り付けます。

2.4 の新機能

よく使うものは、
お気に入りに。

請求先、住所、定型の返信。星をクリックすれば別に保存されます。お気に入りは期限切れにならず、履歴を消しても残ります。

  • 自動では削除されない

    履歴は期限が来ると消えますが、お気に入りは残ります。

  • 別のコピーとして保存

    元のファイルを変更・削除しても、お気に入りは影響を受けません。

  • クイックペーストでも

    「お気に入り」タブに切り替えるか、⌘DCtrl+D で選んだ項目をお気に入りに。

ポインタを置くだけで全文 新機能

項目にポインタを 0.5 秒置くと、全文、大きな画像、すべてのファイル名が表示されます。

コピーしたものを検索

テキストやファイル名で検索し、クリックでクリップボードに戻せます。履歴は既定で 3 日、最長 30 日保存。

大きなファイルは必要なときに

50 MB を超えるものはまず記録だけを同期し、「受信」をクリックしたときに転送します。

フォルダごとでも

フォルダをコピーすれば、向こうには同じ構成のフォルダがそのままペーストされます。

  • design-assets
  • logo.svg
  • banner@2x.png
  • fonts

ファイル名も安心

Mac では使えて Windows では使えない文字は全角に置き換えるので、名前はそのまま読めます。

Mac議事録 10:30?.md
Windows議事録 10：30？.md

自宅と職場も、
直接つながる。

同じネットワークなら、入れてペアリングするだけ。別のネットワークでも公式サービスをオンにすれば、自前のサーバーは不要です。可能な限り直接つながり、だめなときだけ暗号化して中継します。

  • 同じネットワーク

    サーバー不要。ペアリングコードを入れるだけ。

  • 別のネットワーク

    公式サービス、自前のサーバー、Tailscale から選べます。

  • エンドツーエンド暗号化

    ペアリング時に指紋を照合。サーバーは内容を見られません。
