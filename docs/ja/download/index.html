PasteFerry / ダウンロード

PasteFerry をダウンロード

無料・オープンソース · バージョン 2.13.1

Windows

インストーラーをダウンロード

ポータブル版（インストール不要）

はじめかた →

  • Windows 10 と Windows 11、x64。

macOS

Apple シリコン（M1 以降） Intel プロセッサ

ユニバーサル版もあります。

Homebrew：brew install --cask baiyuze/tap/pasteferry。インストールと更新

はじめかた →

どちらのチップかわからない場合

  • 画面左上のアップルメニューから「この Mac について」を選びます。
  • 「チップ：Apple M1」（または M2、M3、M4 など）と表示されていれば Apple シリコン、「プロセッサ：… Intel Core …」と表示されていれば Intel プロセッサです。
  • macOS 13 Ventura 以降が必要です。

Linux

Ubuntu、Debian とその派生ディストリビューション

x64 ARM64 
sudo apt install ./PasteFerry-linux-amd64.deb

ほかのディストリビューション

x64 ARM64 
tar xzf PasteFerry-linux-amd64.tar.gz
./PasteFerry/install.sh
  • GTK 3 と X11、または XWayland 対応の Wayland デスクトップが必要です。
  • uname -m が x86_64 なら x64、aarch64 なら ARM64。

スマホ（Android アプリまたはウェブ版）

Android 版をダウンロード（APK）

Android 9 以降 · ARM64

ウェブ版（インストール不要）

パソコンで「デバイス › スマホのウェブ転送」を開き、スマホで QR コードを読み取ります。

  1. アプリを入れたら、パソコンの「デバイス」から別のパソコンと同じようにスマホをペアリングします。
  2. スマホでコピーした内容は貼り付けてから送信します。パソコンでコピーした内容はスマホの履歴に自動で入ります。
  • スマホとパソコンは同じネットワークに接続。
  • iPhone・iPad は Web 版をご利用ください。

その他

サーバー
2 台が同じネットワークにあればサーバーは要りません。ネットワークをまたぐ方法ははじめかたにまとめていて、サーバーのパッケージはそれぞれの手順ページにあります。
チェックサム
すべてのファイルの SHA-256 は SHA256SUMS にあります。
