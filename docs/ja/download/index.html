PasteFerry / ダウンロード

PasteFerry をダウンロード

無料・オープンソースで、現在のバージョンは 2.5.2 です。同期するコンピューターそれぞれに入れます。Mac、Windows、Linux の組み合わせも自由です。

Windows

インストーラーをダウンロード

インストーラーを使いたくない場合は、ポータブル版をダウンロードし、展開してそのまま実行できます。

  1. PasteFerry-Setup.exe を実行します。現在のユーザーのフォルダにインストールされ、管理者権限は要りません。「Windows によって PC が保護されました」と出たら、「詳細情報」を押してから「実行」を押します。
  2. PasteFerry を開き、「バックグラウンド同期を有効にする」をクリックします。ファイアウォールに聞かれたら許可します。
  • Windows 10 と Windows 11、x64。
  • インストーラーは約 23 MB、ポータブル版は約 29 MB。
  • ウィンドウを閉じても、PasteFerry は画面右下の通知領域で動き続けます。

macOS

Apple シリコン（M1 以降） Intel プロセッサ

両方で動くユニバーサル版もあります。サイズは 2 倍です。

  1. ダウンロードした DMG を開き、PasteFerry を「アプリケーション」にドラッグします。
  2. 「アプリケーション」から開きます。初回は「開発元を検証できません」と表示されます。「システム設定 → プライバシーとセキュリティ」を開き、ページ下部の「このまま開く」をクリックします。
  3. 「バックグラウンド同期を有効にする」をクリックします。クリップボードの読み取りと、ローカルネットワーク上のデバイスを探すことについて聞かれたら、どちらも許可します。

どちらのチップかわからない場合

  • 画面左上のアップルメニューから「この Mac について」を選びます。
  • 「チップ：Apple M1」（または M2、M3、M4 など）と表示されていれば Apple シリコン、「プロセッサ：… Intel Core …」と表示されていれば Intel プロセッサです。
  • 2020 年末以降に購入した Mac は、ほぼすべて Apple シリコンです。間違えても、もう一方をダウンロードし直せば大丈夫です。Apple シリコンの Mac で Intel 版を使うには先に Rosetta のインストールが必要で、Apple シリコン版は Intel プロセッサの Mac では開けません。
  • macOS 13 Ventura 以降が必要です。

Linux

Ubuntu、Debian とその派生ディストリビューション

x64 ARM64 
sudo apt install ./PasteFerry-linux-amd64.deb

ほかのディストリビューション

x64 ARM64 
tar xzf PasteFerry-linux-amd64.tar.gz
./PasteFerry/install.sh
  • グラフィカルなデスクトップが必要です。X11、または XWayland 付きの Wayland デスクトップで動きます。GNOME、KDE などの主要なデスクトップには標準で入っています。
  • x64 か ARM64 かわからないときは、ターミナルで uname -m を実行します。x86_64 なら x64、aarch64 なら ARM64 です。
  • .deb は /opt/PasteFerry にインストールされ、アプリケーションメニューに表示されます。tar.gz はどこに展開しても動き、install.sh でアプリケーションメニューに追加できます。
  • 開いたら「バックグラウンド同期を有効にする」をクリックします。以後はログイン時に自動で起動します。GNOME は標準ではトレイアイコンを表示しないので、ウィンドウはアプリケーションメニューから開きます。
  • GTK 3 が必要です。Ubuntu 24.04 の GNOME（Wayland）で動作を確認しています。

その他

サーバー
2 台が同じネットワークにあればサーバーは要りません。ネットワークをまたぐ方法ははじめかたにまとめていて、サーバーのパッケージはそれぞれの手順ページにあります。
チェックサム
すべてのファイルの SHA-256 は SHA256SUMS にあります。
変更内容と旧バージョン
このバージョンの変更点はリリースノートを、旧バージョンは GitHub Releases をご覧ください。
