PasteFerry

よくある質問

インストール、接続、同期、料金について。答えが見つからなければお知らせください。

Mac のユニバーサルクリップボードとの違いは？

ユニバーサルクリップボードは、同じ Apple ID の Apple 製品どうしが近くにあるときだけ使えます。PasteFerry はアカウントに関係なく Mac・Windows・Linux で使え、自宅と会社のあいだでも同期できます。コピーしたものはあとから履歴で探せます。

同じ Apple ID の Mac が 2 台だけで、主にテキストをコピーするなら、標準機能で十分です。

AirDrop との違いは？

AirDrop は近くにある Apple 製品どうしでしか使えず、毎回相手が受け取る必要があります。PasteFerry の「ファイル送信」は Mac・Windows・Linux のあいだで、別のネットワークでも使え、大きなファイルは切れても続きから送れます。自分のパソコンどうしなら受け取りの操作は不要で、連絡先に送るときは相手が「受け入れる」を押します。

サーバーは自分で用意する必要がありますか？

いいえ。同じネットワークなら、入れてそのままペアリングできます。別のネットワークなら、両方のパソコンでサービスをオンにするだけです。クラウドサーバーの契約もアドレスの入力も要りません。

自分で管理したいなら、独自サーバーや Tailscale も使えます。

自宅にグローバル IP がありません。自宅と会社のあいだで同期できますか？

できます。サービスをオンにすると、2 台はまず直接つながろうとし、ほとんどの家庭と会社のネットワークで成功します。つながらないときはサーバーが中継し、1 日 100 MB まで使えます。

サーバーにコピーした内容は見えますか？

見えません。内容を復号できるのはあなたのデバイスだけです。直接接続ならサーバーを通らず、中継でもサーバーが運ぶのは暗号化されたデータだけです。

「サービス」を使うと、サーバーは接続と残量の計算に必要な情報を記録します。詳しくはプライバシーに関する説明をご覧ください。アプリとサーバーのコードは公開しています。

中継はどのくらい使えますか？使い切ったら？

パソコン 1 台につき 1 日 100 MB（送受信の合計）で、北京時間の午前 0 時にリセットされます。直接接続は数えないので、使い切っても直接接続はそのまま使えます。上限は今後変わることがあり、アプリに表示される値が最新です。

中継をたくさん使うなら、独自サーバーを立てれば無制限です。

同じネットワークなのに、もう一台が見つからないのはなぜ？

まず 2 台が本当に同じサブネットか確認してください。会社の有線と Wi‑Fi、ゲストネットワーク、AP アイソレーションが有効な Wi‑Fi では、お互いが見えないことがよくあります。その場合は、コードを入力する側で「別のサブネットにありますか？」をクリックし、相手のコードの下に表示されたアドレスを入力します。

Windows では、初回起動時のファイアウォールの確認で許可します。キャンセルした場合は「設定 → 接続」で「許可」をクリックします。Mac では「システム設定 → プライバシーとセキュリティ → ローカルネットワーク」で PasteFerry Daemon をオンにします。詳しくは同じネットワークでの手順をご覧ください。

ほかの人のパソコンにファイルを送れますか？

送れます。2.6 から連絡先を追加できます。相手が「連絡先」ページの「連絡先を追加」でコードを表示し、あなたが入力して双方で確認すれば完了です。ペアリングは要りません。あとは相手のアイコンにファイルをドロップし、相手が受け入れると転送が始まります。ひとことメモも添えられます。

連絡先とはファイルと画像だけをやり取りし、クリップボード、履歴、デバイスはお互いに見えません。誰から受け取るかは「ファイル送信」ページの下で選べます：許可しない、連絡先のみ、すべての人（ローカルネットワーク内のみ、10 分後に自動でオフ）。

大きなファイルはどうなりますか？

50 MB までのものは、コピーした時点でもう一台に届いていて、そのまま貼り付けられます。それより大きいファイルは記録だけを同期し、必要なときに履歴で「受信」をクリックすると転送されます。この上限は設定で変えられます。

大きなファイルを特定のパソコンに直接送るなら「ファイル送信」を使います。サイズ無制限で、切れても続きから送ります。

出口が複数ある会社のネットワークでも直接つながりますか？

つながります。こうしたネットワークには出口がいくつもあり、PasteFerry はそれぞれの出口のアドレスを調べて相手に渡し、順に試してもらいます。テストでは、出口が 4 つある会社のネットワークと自宅の回線が直接つながりました。相手のルーターが毎回ポートをランダムに変える場合は、中継になります。

Windows や Linux に対応していますか？iPhone は？

Windows 10・11（x64）と Linux（x64、ARM64。X11、または XWayland 付きの Wayland デスクトップで、GNOME や KDE は標準で対応）で使えます。コピーしたファイルは本物のファイルとして貼り付けられるので、エクスプローラー、ファイルマネージャー、Office にそのまま貼り付けられます。

iPhone と iPad には対応していません。iOS ではアプリがバックグラウンドでクリップボードを読めないため、コピーしてすぐ同期できないからです。

初めて開くときにシステムに止められるのはなぜ？

PasteFerry はまだ Apple の公証も Windows のコード署名も受けていません。どちらも毎年費用のかかる証明書が必要です。

Mac では「システム設定 → プライバシーとセキュリティ」でページ下部の「このまま開く」をクリック、Windows では「Windows によって PC が保護されました」で「詳細情報」を押してから「実行」を押してください。一度だけで済みます。

無料ですか？会社で使えますか？

無料です。PasteFerry は GNU AGPL-3.0 のオープンソースで、個人も会社も無料で使え、改変もできます。配布する場合や、改変したものをネットワーク越しにほかの人に使わせる場合は、同じようにソースコードを公開する必要があります。

UU Remote を使っていると .uuremote_ ファイルが増え続けるのはなぜ？

UU Remote はクリップボードに一時的なプレースホルダーファイルを書き込み、1.3.2 より前の PasteFerry はそれを通常のファイルとして同期していました。新しいバージョンに更新すれば直ります。通常の空ファイルや隠しファイルには影響しません。
