PasteFerry

よくある質問

インストール、接続、同期、料金について。答えが見つからなければお知らせください。

UU Remote の使用中に .uuremote_ ファイルが増え続けるのはなぜですか？

UU Remote は一時的なプレースホルダーファイルをシステムのクリップボードに書き込みます。旧版の PasteFerry はそれを通常のファイルとして記録・転送していました。1.3.2 では確認済みの命名パターンを送受信時に除外し、起動時にプレースホルダーだけの履歴を削除します。通常の空ファイル、隠しファイル、大容量ファイルは対象外です。50 MB は自動転送のしきい値であり、UU の UDP P2P 設定とは関係ありません。両端を更新してください。他のクリップボード同期ツールによる通常コンテンツの重複は起こり得ます。

macOS のユニバーサルクリップボードとの違いは？

Mac・Windows・Linux でテキスト、画像、ファイル、フォルダを同期。同じアカウントは不要。公式サービスをオンにすれば、サーバーを構築せずに別ネットワーク間でも使えます。直接接続を優先し、常にエンドツーエンド暗号化。

2 台の Mac が同じ Apple ID でいつも並んでいて、主にテキストをコピーするだけなら、標準機能で十分です。

サーバーにコピーした内容は見えますか？

コピー内容は復号できません。直接通信は端末間で行い、中継はエンドツーエンド暗号化されたパケットを転送します。公式サービスは必要な端末・使用量統計を保持します。公開ソースだけで非公開の本番保存動作まで証明できるわけではありません。

出口が複数ある会社のネットワークでも直接つながりますか？

つながります。こうしたネットワークは宛先ごとに出口を選びます。PasteFerry はひとつのポートから複数のサーバーに問い合わせて出口ごとのアドレスを集め、すべて相手に送り、相手がひとつずつ試します。テストでは、出口が 4 つある会社の Mac と家庭の回線が直接つながりました。相手がポートをランダムに割り当てる NAT の場合は中継になります。

サーバーは自分で用意する必要がありますか？

不要です。別ネットワークなら両方で公式サービスを有効にします。クラウド契約やアドレス入力は不要。初期状態はオフで、現在の中継上限は 100 MB/日、直接通信は消費しません。LAN、独自サーバー、Tailscale も使えます。

自宅にグローバル IP がありません。自宅と会社のあいだで同期できますか？

不要です。別ネットワークなら両方で公式サービスを有効にします。クラウド契約やアドレス入力は不要。初期状態はオフで、現在の中継上限は 100 MB/日、直接通信は消費しません。LAN、独自サーバー、Tailscale も使えます。

同じネットワークなのに、もう一台が見つからないのはなぜ？

まず本当に同じサブネットか確認してください。会社の有線と Wi‑Fi、ゲストネットワーク、クライアント分離が有効な Wi‑Fi では、デバイス同士が見えないことがよくあります。その場合は、コードを入力する側で「別のサブネットにありますか？」をクリックし、相手のコードの下に表示されたアドレスを入力します。

Windows では初回起動時にファイアウォールに聞かれたら許可してください。キャンセルした場合は「設定 → ローカルネットワーク」で「許可」をクリックします。Mac では「システム設定 → プライバシーとセキュリティ → ローカルネットワーク」で PasteFerry Daemon をオンにします。詳しくは同じネットワークでの手順を。

Windows や Linux に対応していますか？iPhone は？

Windows 10 と Windows 11（x64）に対応し、Mac と相互に使えます。Windows で貼り付けたファイルは本物のファイルなので、エクスプローラーや Office にそのまま貼り付けられます。

x64 と ARM64 の Linux デスクトップにも対応しています。X11、または XWayland 付きの Wayland デスクトップ（GNOME、KDE などは標準で搭載）で動きます。コピーしたファイルはファイルマネージャーにそのまま貼り付けられます。

iPhone と iPad には対応していません。iOS ではアプリがバックグラウンドでクリップボードを監視できないため、コピーしてすぐ同期することができないからです。

初めて開くときにシステムに止められるのはなぜ？

PasteFerry はまだ Apple の公証を受けておらず、Windows 版もコード署名していません。どちらも毎年費用のかかる証明書が必要です。

Mac では「システム設定 → プライバシーとセキュリティ」でページ下部の「このまま開く」をクリック、Windows では「Windows によって PC が保護されました」で「詳細情報」から「実行」を押してください。どちらも一度だけで済みます。

大きなファイルはどうなりますか？

初期設定では 50 MB までのものはコピーした時点でもう一台に送られ、そのまま貼り付けられます。それより大きいファイルは記録だけを同期し、必要なときに履歴から「このデバイスに取り込む」で転送します。上限は「設定」で変えられます。

特定のパソコンにファイルを直接送るなら「ファイル送信」を。サイズ無制限で履歴には残らず、切断されても続きから再開します。

無料ですか？会社で使えますか？

無料です。PasteFerry は GNU AGPL-3.0 のオープンソースで、個人も会社も無料で使い、改変できます。配布する場合や、改変したものをネットワーク越しに提供する場合は、同じライセンスでソースコードを公開する必要があります。

公式中継は無制限ですか？

現在の標準中継上限は端末の上限グループごとに送受信合計 100 MB/日で、北京時間午前 0 時にリセットします。再インストールで新たな残量が得られる保証はありません。使用量画面に実際の上限、残量、更新時刻を表示します。上限に達しても直接接続は利用できます。上限と提供状況は変更される場合があるため、アプリでご確認ください。
