PasteFerry

よくある質問

答えが見つからないときは、お知らせください。

Mac のユニバーサルクリップボードとの違いは？

ユニバーサルクリップボードは、同じ Apple ID の Apple 製品が近くにあるときだけ使えます。PasteFerry はアカウントに関係なく Mac・Windows・Linux で使え、自宅と会社のあいだでも使えます。

AirDrop との違いは？

AirDrop は近くの Apple 製品どうしでしか使えません。PasteFerry の「ファイル送信」は Mac・Windows・Linux のあいだで、別のネットワークでも送れます。AirDrop とはやり取りできないので、両方に PasteFerry が必要です。

サーバーは自分で用意する必要がありますか？

いいえ。同じネットワークなら入れてそのままペアリングでき、別のネットワークならサービスをオンにするだけです。独自サーバーや Tailscale も使えます。

自宅にグローバル IP がありません。自宅と会社のあいだで同期できますか？

できます。サービスをオンにしてください。

サーバーにコピーした内容は見えますか？

見えません。内容はエンドツーエンドで暗号化されます。詳しくはプライバシーに関する説明をご覧ください。

中継はどのくらい使えますか？

パソコン 1 台につき 1 日 100 MB で、直接接続は数えません。使い切っても直接接続は使え、無制限にしたいなら独自サーバーを立てられます。

同じネットワークなのに、もう一台が見つからないのはなぜ？

たいていはサブネットが違うか、ファイアウォールに止められています。ペアリング時に「別のサブネットにありますか？」から相手のアドレスを入力してください。詳しくは同じネットワークでの手順をご覧ください。

ほかの人のパソコンにファイルを送れますか？

送れます。2.6 から、連絡先に追加すればペアリングなしで送れ、相手が受け入れると転送が始まります。連絡先からクリップボードや履歴は見えません。

大きなファイルはどうなりますか？

50 MB まではコピーした時点で届いています。それより大きいものは使うときに取りに行くか、「ファイル送信」で直接送れます。サイズは無制限です。

Windows や Linux に対応していますか？iPhone は？

Windows 10・11 と Linux（x64、ARM64）に対応しています。iPhone と iPad は未対応です。iOS ではアプリがバックグラウンドでクリップボードを読めないためです。

初めて開くときにシステムに止められるのはなぜ？

まだ Apple の公証も Windows のコード署名も受けていないためです。Mac では「システム設定 → プライバシーとセキュリティ」で「このまま開く」、Windows では「詳細情報」→「実行」を押してください。一度だけで済みます。

無料ですか？会社で使えますか？

無料で、個人も会社も使えます。PasteFerry は GNU AGPL-3.0 のオープンソースです。

出口が複数ある会社のネットワークでも直接つながりますか？

つながります。PasteFerry はすべての出口を順に試します。

UU Remote を使っていると .uuremote_ ファイルが増え続けるのはなぜ？

古いバージョンの問題です。新しいバージョンに更新すれば直ります。

ディスカッションとフィードバック →問題を報告 →
