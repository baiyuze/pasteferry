2.1 新機能：サーバー不要で別ネットワーク間を同期 →

こっちでコピーして、
あっちで貼り付け。

Mac・Windows・Linux でテキスト、画像、ファイル、フォルダを同期。同じアカウントは不要。公式サービスをオンにすれば、サーバーを構築せずに別ネットワーク間でも使えます。直接接続を優先し、常にエンドツーエンド暗号化。

バージョン 2.2.0、無料・オープンソース。macOS 13 以降、Windows 10・11、Linux（x64 と ARM64）。

はじめての方は、3 ステップのはじめかたへ →
直接接続、エンドツーエンド暗号化

2 台をどうつなぐか

同じネットワークならインストールしてペアリング。別ネットワークなら公式サービスをオンにするだけで、サーバーの準備は不要です。独自サーバーと Tailscale も選べます。

別ネットワーク間、構築不要

公式サービス

スイッチひとつで自宅と会社のパソコンを接続。直接接続を優先し、失敗時のみ暗号化中継を使います。クラウド契約やアドレス入力は不要です。

公式サービスを有効にする → 準備は何も要らない

同じネットワーク

家や会社で、同じルーターにつながっている場合。2 台にアプリを入れてペアリングコードを入力するだけ。サーバーも、電源を入れたままのコンピューターも要りません。

同じネットワークでの手順 → 容量と運用を自分で管理

独自の公開サーバー

グローバル IP を持つ Linux のクラウドサーバー。最小構成で足ります。各コンピューターが直接つながり、自宅でも会社でも外出先でも、ほかに入れるものはありません。

公開サーバーでの手順 → ネットワークをまたぐ、サーバーなし

Tailscale

各コンピューターに Tailscale を入れて同じアカウントでサインインし、ペアリング時に相手の Tailscale アドレスを入力します。自宅でも会社でも同期でき、サーバーも電源を入れたままのコンピューターも要りません。

Tailscale での手順 →

初めての方はクイックスタートへ。公式サービスは任意です。現在の標準中継上限は 100 MB/日で、直接通信では消費しません。

どのデバイスでコピーしたものも、ここに

履歴には直近 3 日分が残り、いつでもクリップボードに戻せます。画像はクリックでプレビュー。50 MB までのファイルはコピーした時点で届いていて、それより大きいものは必要なときにワンクリックで取り込めます。前にコピーしたものは、テキストやファイル名で検索できます。

コピーしたあと、何が起きるか

テキストも画像も、ファイルもフォルダも、同じ道を通ります。

  1. 気づく

    Mac ではバックグラウンドサービスが短い間隔でクリップボードの変更カウントを確認します。カウントと種類を見るだけなので許可は不要で、確認ダイアログも出ません。Windows ではコピーした瞬間にシステムが知らせます。

  2. 送る

    テキストはメッセージと一緒に送ります。50 MB までの画像とファイルはその場でストリームとして送り、それより大きいファイルは記録だけを送って、必要になったときに転送します。

  3. 貼り付ける

    受け取った側はまず内容をローカルに保存してから、クリップボードに入れます。⌘V や Ctrl+V で貼り付けられるのは、手元にある本物のファイルです。

いまある方法では足りない理由

ユニバーサルクリップボードは同じ Apple ID で、近くにいる必要があります。AirDrop は毎回受け取り操作が要ります。自分宛てにメッセージで送ると手動でダウンロードすることになり、ファイルは他社のサーバーに残ります。Mac と Windows の組み合わせでは、標準の方法はどれも使えません。

しくみ

同じネットワークではサーバーなしで端末を検出します。別ネットワークでは公式サービスまたは独自サーバーが接続情報を交換。直接接続を優先し、失敗時に暗号化中継を使います。図は共通のシグナリングと中継構成です。

会社のネットワークでも直接つながる

2 つの回線を持つ会社や、キャリアの NAT アドレスプールのようなネットワークには出口が複数あり、宛先ごとに出口が変わります。一度調べただけでは出口のひとつしか分からず、中継頼みになります。PasteFerry はすべての出口を調べ、そのアドレスをすべて相手に伝えます。

やっていること

  • ポートはひとつ。すべての接続をひとつのローカル UDP ポートで送受信するので、別々のサーバーから得たアドレスがかみ合います。
  • 出口をすべて調べる。そのポートから IP の散らばった 7 台のサーバーに同時に問い合わせ、出口の数だけアドレスを得ます。DNS 汚染されたアドレスは先に除外します。
  • すべて相手に伝える。相手はひとつずつ試し、実際の出口と合うものがつながります。
  • 見た出口を覚えておく。ポートを書き換えない出口を取りこぼしたときは、「出口の IP ＋ローカルポート」で補います。
  • どちらが先に送るかを決める。相手のパケットが先に届くとポートをふさいでしまうルーターがあります。片方が先にアドレスを公開し、もう片方はそこへ送ってから自分のアドレスを公開します。再試行では順番を入れ替えます。
  • 待機中に直接接続を再試行。直接接続に失敗して中継が利用可能なら、中継で同期を続けます。待機中に直接接続を再試行し、成功したら中継を解放します。

実際のネットワーク構成で検証

NAT 穴あけ実験室では、Linux のネットワーク名前空間と iptables でこれらの構成を組み、PasteFerry の本物の接続コードをそれぞれで動かします。コミットのたびに自動で実行されます。

実測：出口が 4 つある会社の Mac と自宅の Mac は、以前は中継しかできず、サーバーの帯域で 0.6 MB/s に抑えられていました。いまは直接つながり、サーバーに接続してから約 3 秒で確立します。

測定の過程、設計の判断、ハマった点は技術資料（中国語）にまとめています。

サーバーにはコピーした内容が見えない

  • サーバーはアカウントも内容も保存しない。デバイスの身元は Ed25519 の鍵で、デバイス ID は公開鍵から計算されます。サーバーはユーザー表なしで身元を確かめられます。
  • ペアリングでは指紋をあなたが照合する。両方の画面に同じ 2 行、つまりお互いの公開鍵の指紋が表示されます。サーバーは転送中の公開鍵をすり替えられますが、すり替えれば 2 つの画面が一致しなくなります。この照合が中間者攻撃を防ぐ関門です。
  • その後のメッセージはすべて署名付き。サーバーがあなたのデバイスになりすますことはできません。直接接続の証明書もハンドシェイク後にもう一度照合し、食い違えばすぐ切断します。
  • 中継も暗号文を転送するだけ。TURN が運ぶのは暗号化済みのパケットです。中継用の認証情報はデバイスごとに発行され、12 時間で失効します。
  • ローカルネットワークでも同じ。デバイスが LAN に流すのは毎日変わる匿名の識別子だけで、誰のコンピューターかはわかりません。デバイス名を流すのは「近くを検索」を開いている間だけです。ペアリングでは同じく指紋を照合し、その後のメッセージも署名付きです。

うまくいかないときに起きること

ネットワークの事情は人それぞれです。ここに挙げたケースはどれも想定済みで、テストがあります。

同じネットワークなのに相手が見つからない
サブネットが違う、ゲストネットワーク、クライアント分離（AP アイソレーション）が有効な Wi‑Fi では、LAN 内の検出が届きません。ペアリング時に相手のコードの下に表示されたアドレスを入力してください。アドレスはその後も記憶され、両方のアドレスが変わったときはデバイス一覧からもう一度入力します。
システムがローカルネットワークを止めている
macOS 15 以降、バックグラウンドサービスが LAN 上のデバイスに接続するにはあなたの許可が要ります。Windows は初回起動時にファイアウォールについて聞いてきます。許可されていないときはアプリが知らせ、設定へ直接飛べるボタンを出します。
2 台が直接つながらない
公式モードでは直接接続に失敗した後、残量の範囲内で中継を申請します。独自サーバーではその TURN 中継を使います。どちらも内容はエンドツーエンド暗号化されます。
公開 STUN サーバーにつながらない
中国本土などでは公開 STUN が不安定です。サーバーは STUN を内蔵していて、クライアントはそちらを優先します。
直接接続へ切り替える
直接接続に失敗して中継が利用可能なら、中継で同期を続けます。待機中に直接接続を再試行し、成功したら中継を解放します。
相手がスリープ、切断、再起動した
黙って切れた接続にも気づき、すぐに閉じて再接続します。そのあいだにコピーしたものは記録しておき、つながったら相手の履歴に追加します。相手のいまのクリップボードは上書きしません。
サーバーとの接続が切れた
自動で再接続します。間隔は 1 秒から倍々で最大 30 秒、ランダムな揺らぎ付きで、たくさんのデバイスが一斉に再接続しないようにしています。同じネットワークのデバイスは影響を受けず、そのまま同期します。
ファイルが大きすぎる
上限を超えるものは記録だけを同期し、必要なときに取り込みます。そのとき元のファイルが消えていれば、あいまいな失敗ではなく、はっきりそう伝えます。
プレーンテキストしか受け付けない場所に貼り付ける
Web からコピーした書式付きテキストは HTML とプレーンテキストの両方で書き込むので、どこに貼り付けてもタグが混ざりません。
Windows では使えないファイル名
Mac では使えるコロンや疑問符などは、対応する全角文字に置き換えて受け取るので、名前はそのまま読めます。大文字と小文字だけが違う 2 つのファイルが上書きし合うこともありません。
パスワードをコピーした
Windows ではパスワードマネージャーがコピーした内容に「記録しない」印が付きます。PasteFerry はそれを見て飛ばします。同期も履歴への保存もしません。
クリップボードの読み取りをまだ許可していない
内容は読みに行きません。読みに行くと、バックグラウンドプロセスが見えないダイアログで止まってしまうからです。アプリが許可を促し、設定へ直接飛べるボタンを出します。
バックグラウンドサービスが落ちた
Mac ではシステムの launchd が、Windows では PasteFerry 自身の監視プロセスが再起動します。10 秒に 1 回までに抑え、暴走はしません。
アプリを更新した、または移動した
アプリを開いたときにログイン項目を正しい場所に向け直し、バックグラウンドサービスを新しいバージョンで再起動します。

インストール

それぞれのコンピューターにアプリを入れます。同じネットワークならそのままペアリングでき、ネットワークをまたぐときは 2 台がお互いを見つける方法をひとつ選びます。はじめての方ははじめかたをどうぞ。

Mac

  1. DMG をダウンロードして開き、PasteFerry を「アプリケーション」にドラッグします。Apple シリコン版と Intel 版があります。自分の Mac がどちらかの確かめ方は、ダウンロードページにあります。
  2. 「アプリケーション」から開きます。初回は「開発元を検証できません」と表示されます。PasteFerry はまだ Apple の公証を受けていないためです。「システム設定 → プライバシーとセキュリティ」を開き、ページ下部の「このまま開く」をクリックします。必要なのは一度だけです。
  3. 「バックグラウンド同期を有効にする」をクリックします。クリップボードの読み取りと、ローカルネットワーク上のデバイスを探すことについて聞かれたら、どちらも許可します。
  4. 別ネットワークで使う場合は各パソコンの「設定 → 公式サービスを使う」をオンにします。アドレス入力は不要。独自サーバーも利用できます。
Mac 版をダウンロード

Windows

  1. PasteFerry-Setup.exe を実行します。現在のユーザーのフォルダにインストールされ、管理者権限は要りません。PasteFerry はまだコード署名されていないため、「Windows によって PC が保護されました」と表示されます。「詳細情報」を押してから「実行」を押してください。インストーラーを使いたくない場合はポータブル版もあります。
  2. PasteFerry を開き、「バックグラウンド同期を有効にする」をクリックします。ファイアウォールに聞かれたら許可します。ウィンドウを閉じても、画面右下の通知領域で動き続けます。
  3. 別ネットワークで使う場合は各パソコンの「設定 → 公式サービスを使う」をオンにします。アドレス入力は不要。独自サーバーも利用できます。
Windows 版をダウンロード

Linux

  1. Ubuntu や Debian などでは .deb をダウンロードし、sudo apt install ./PasteFerry-linux-amd64.deb を実行します。ほかのディストリビューションでは tar.gz をダウンロードして展開し、./PasteFerry/install.sh を実行します。
  2. アプリケーションメニューから PasteFerry を開き、「バックグラウンド同期を有効にする」をクリックします。以後はログイン時に自動で起動します。
  3. 別ネットワークで使う場合は各パソコンの「設定 → 公式サービスを使う」をオンにします。アドレス入力は不要。独自サーバーも利用できます。

よくある質問

UU Remote の使用中に .uuremote_ ファイルが増え続けるのはなぜですか？

UU Remote は一時的なプレースホルダーファイルをシステムのクリップボードに書き込みます。旧版の PasteFerry はそれを通常のファイルとして記録・転送していました。1.3.2 では確認済みの命名パターンを送受信時に除外し、起動時にプレースホルダーだけの履歴を削除します。通常の空ファイル、隠しファイル、大容量ファイルは対象外です。50 MB は自動転送のしきい値であり、UU の UDP P2P 設定とは関係ありません。両端を更新してください。他のクリップボード同期ツールによる通常コンテンツの重複は起こり得ます。

macOS のユニバーサルクリップボードとの違いは？

Mac・Windows・Linux でテキスト、画像、ファイル、フォルダを同期。同じアカウントは不要。公式サービスをオンにすれば、サーバーを構築せずに別ネットワーク間でも使えます。直接接続を優先し、常にエンドツーエンド暗号化。

2 台の Mac が同じ Apple ID でいつも並んでいて、主にテキストをコピーするだけなら、標準機能で十分です。

サーバーにコピーした内容は見えますか？

コピー内容は復号できません。直接通信は端末間で行い、中継はエンドツーエンド暗号化されたパケットを転送します。公式サービスは必要な端末・使用量統計を保持します。公開ソースだけで非公開の本番保存動作まで証明できるわけではありません。

出口が複数ある会社のネットワークでも直接つながりますか？

つながります。こうしたネットワークは宛先ごとに出口を選びます。PasteFerry はひとつのポートから複数のサーバーに問い合わせて出口ごとのアドレスを集め、すべて相手に送り、相手がひとつずつ試します。テストでは、出口が 4 つある会社の Mac と家庭の回線が直接つながりました。相手がポートをランダムに割り当てる NAT の場合は中継になります。

サーバーは自分で用意する必要がありますか？

不要です。別ネットワークなら両方で公式サービスを有効にします。クラウド契約やアドレス入力は不要。初期状態はオフで、現在の中継上限は 100 MB/日、直接通信は消費しません。LAN、独自サーバー、Tailscale も使えます。

自宅にグローバル IP がありません。自宅と会社のあいだで同期できますか？

不要です。別ネットワークなら両方で公式サービスを有効にします。クラウド契約やアドレス入力は不要。初期状態はオフで、現在の中継上限は 100 MB/日、直接通信は消費しません。LAN、独自サーバー、Tailscale も使えます。

同じネットワークなのに、もう一台が見つからないのはなぜ？

まず本当に同じサブネットか確認してください。会社の有線と Wi‑Fi、ゲストネットワーク、クライアント分離が有効な Wi‑Fi では、デバイス同士が見えないことがよくあります。その場合は、コードを入力する側で「別のサブネットにありますか？」をクリックし、相手のコードの下に表示されたアドレスを入力します。

Windows では初回起動時にファイアウォールに聞かれたら許可してください。キャンセルした場合は「設定 → ローカルネットワーク」で「許可」をクリックします。Mac では「システム設定 → プライバシーとセキュリティ → ローカルネットワーク」で PasteFerry Daemon をオンにします。詳しくは同じネットワークでの手順を。

Windows や Linux に対応していますか？iPhone は？

Windows 10 と Windows 11（x64）に対応し、Mac と相互に使えます。Windows で貼り付けたファイルは本物のファイルなので、エクスプローラーや Office にそのまま貼り付けられます。

x64 と ARM64 の Linux デスクトップにも対応しています。X11、または XWayland 付きの Wayland デスクトップ（GNOME、KDE などは標準で搭載）で動きます。コピーしたファイルはファイルマネージャーにそのまま貼り付けられます。

iPhone と iPad には対応していません。iOS ではアプリがバックグラウンドでクリップボードを監視できないため、コピーしてすぐ同期することができないからです。

初めて開くときにシステムに止められるのはなぜ？

PasteFerry はまだ Apple の公証を受けておらず、Windows 版もコード署名していません。どちらも毎年費用のかかる証明書が必要です。

Mac では「システム設定 → プライバシーとセキュリティ」でページ下部の「このまま開く」をクリック、Windows では「Windows によって PC が保護されました」で「詳細情報」から「実行」を押してください。どちらも一度だけで済みます。

大きなファイルはどうなりますか？

初期設定では 50 MB までのものはコピーした時点でもう一台に送られ、そのまま貼り付けられます。それより大きいファイルは記録だけを同期し、必要なときに履歴から「このデバイスに取り込む」で転送します。上限は「設定」で変えられます。

無料ですか？会社で使えますか？

無料です。PasteFerry は GNU AGPL-3.0 のオープンソースで、個人も会社も無料で使い、改変できます。配布する場合や、改変したものをネットワーク越しに提供する場合は、同じライセンスでソースコードを公開する必要があります。

公式中継は無制限ですか？

現在の標準中継上限は端末の上限グループごとに送受信合計 100 MB/日で、北京時間午前 0 時にリセットします。再インストールで新たな残量が得られる保証はありません。使用量画面に実際の上限、残量、更新時刻を表示します。上限に達しても直接接続は利用できます。上限と提供状況は変更される場合があるため、アプリでご確認ください。
