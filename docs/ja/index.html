2 台をどうつなぐか

同じネットワークなら、入れてペアリングするだけ。別のネットワークなら「サービス」をオンにします。独自サーバーや Tailscale も使えます。

自宅と職場の間でも使える

サービス

スイッチをひとつオンにするだけで、自宅と会社のパソコンが同期できます。サーバーの契約は要りません。

「サービス」をオンにする → 準備は不要

同じネットワーク

同じルーターにつながった 2 台なら、アプリを入れてペアリングコードを入力するだけ。サーバーは要りません。

同じネットワークでの手順 → 自分のサーバーで、中継は無制限

独自の公開サーバー

グローバル IP のある Linux クラウドサーバー。最小構成で足ります。すべてのコンピューターがここにつながり、どこからでも同期できます。

公開サーバーでの手順 → ネットワークをまたぐ、サーバーなし

Tailscale

各コンピューターに Tailscale を入れて同じアカウントでサインインし、ペアリング時に相手の Tailscale アドレスを入力します。

Tailscale での手順 →

はじめての方ははじめかたの手順どおりにどうぞ。「サービス」は無料で、中継は 1 日 100 MB まで、直接接続は無制限です。
