最新アップデート · 2.13.1

文字もアイコンも、
見やすい大きさに。

2.13.1 では表示サイズを 90%〜150% に調整できます。文字・アイコン・余白が一緒に変わり、メインとクイックペーストの両ウィンドウに反映。Mac・Windows・Linux の「設定 → 外観」かショートカットで変更できます。

最近の主な改善

  • 2.13.0

    モバイル回線でも安定

    モバイル Wi-Fi での直接接続を改善。IPv6 での直接接続と、一時的な混雑から復帰できる中継にも対応。

  • 2.12.2

    システムメニューから送信

    Finder、Windows の右クリック、Android の共有メニューからファイルを送信できます。

  • 2.12.0

    離れた相手への大容量転送を高速化

    低速な直接接続で並列転送を試します。送信側・受信側の両方を更新すると有効になります。

コピー履歴を、
いつでも。

⌥VAlt+V でコピー履歴を検索し、選んだ内容を今のアプリに貼り付け。よく使う内容はお気に入りに、ファイルは別のコピーとして保存できます。

クイックペーストについて →

ドラッグすれば、
もう届いている。

パソコン間でファイルやフォルダーをドラッグ転送。大容量ファイルも中断後に再開でき、受信ファイルは「ダウンロード」にまとめて保存します。

ファイル送信について →

スマホでも使える。

同じネットワークで、Android は写真やファイルを双方向に転送し、複数選択・保存・共有も可能。iPhone・iPad は QR コードで Web 版を開き、コピー履歴や転送を利用できます。ページは開いたままにします。

スマホの使い方 →

クリップボードの同期だけじゃない。

  • 友だちにファイルを送る

    友だちを追加し、相手が確認してから受信。友だちにクリップボードやコピー履歴は見えません。

  • 9 種のテーマとカスタマイズ

    デフォルト・ピクセルと 7 種のスタイルにライト・ダーク配色。色や背景の変更、AI によるテーマの作成・適用も可能です。

  • 内容は自分のデバイスだけに

    ペアリング時にフィンガープリントを確認し、内容はエンドツーエンド暗号化。サーバーは接続や中継のみを担い、復号できません。
