PasteFerry

Le serveur ne peut pas voir ce que vous copiez

Chiffrement de bout en bout et vérification des empreintes à l’association.

  • Pas de compte, pas de contenu stocké.L'identité d'un périphérique est une clé, le serveur n'a donc pas besoin de table utilisateur.
  • Vérifiez les empreintes digitales lors du couplage.Les deux écrans affichent la même empreinte digitale ; si quelqu'un échange une clé, ils ne correspondront pas.
  • Chaque message est signé,le serveur ne peut donc pas se faire passer pour votre appareil.
  • Le relais transmet uniquement le texte chiffré.Les identifiants de relais expirent après 12 heures.
  • Privé sur le réseau local également.Un appareil diffuse un jeton anonyme qui change quotidiennement, afin que personne ne puisse savoir de qui il s’agit.
