PasteFerry / Télécharger

Télécharger PasteFerry

Gratuit et open source, version 2.13.1. Installez-le sur chaque ordinateur que vous souhaitez synchroniser ; Mac, Windows et Linux se mélangent librement.

Windows

Téléchargez le programme d'installation

Vous préférez ne pas exécuter de programme d'installation ? Obtenez le zip portable , extrayez-le et exécutez PasteFerry à partir de là.

  1. Exécutez PasteFerry-Setup.exe. Il s'installe pour l'utilisateur actuel, aucun droit d'administrateur n'est requis.Si vous voyez «Windows a protégé votre PC », cliquez sur Plus d'informations, puis sur Exécuter quand même.
  2. Ouvrez PasteFerry et cliquez sur Activer la synchronisation en arrière-plan. Autorisez-le si le pare-feu Windows le demande.
  • Windows 10 et Windows 11, x64.
  • Le programme d'installation fait environ 23 Mo, le zip portable environ 29 Mo.
  • Après avoir fermé la fenêtre, PasteFerry continue de s'exécuter dans la zone de notification.

macOS

Puces Apple (M1+) Intel

Une version universelle , , qui fonctionne sur les deux, est également disponible, avec une taille deux fois plus grande.

Vous pouvez également installer l'application de bureau et la CLI fournie avec brew install --cask baiyuze/tap/pasteferry. Si elle est déjà installée manuellement, quittez et déplacez d'abord l'application existante ; conservez vos données de candidature. Consultez le guide d'installation et de mise à niveau .

  1. Ouvrez le DMG que vous avez téléchargé et faites glisser PasteFerry dans Applications.
  2. Ouvrez-le depuis Applications.La première fois, macOS indique qu'il ne peut pas vérifier le développeur : accédez à Paramètres système → Confidentialité et sécurité et cliquez sur Ouvrir quand même en bas.
  3. Cliquez sur Activer la synchronisation en arrière-plan. Lorsque macOS vous demande comment accéder au presse-papiers et rechercher des appareils sur votre réseau local, autorisez les deux.

Vous ne savez pas quelle puce ?

  • Cliquez sur le menu Pomme dans le coin supérieur gauche de l'écran et choisissez À propos de ce Mac.
  • « Puce : Apple M1 » (ou M2, M3, M4…) désigne le silicium Apple ; « Processeur : … Intel Core … » signifie Intel.
  • Presque tous les Mac achetés depuis fin 2020 sont équipés de silicium Apple. Si vous choisissez la mauvaise, téléchargez simplement l'autre : sur un Mac Apple Silicon, la version Intel nécessite que Rosetta soit installée en premier, et la version Apple Silicon ne s'ouvrira pas sur un Mac Intel.
  • Nécessite macOS 13 Ventura ou version ultérieure.

Linux

Ubuntu, Debian et dérivés

x64 ARM64 
sudo apt install ./PasteFerry-linux-amd64.deb

Autres distributions

x64 ARM64 
tar xzf PasteFerry-linux-amd64.tar.gz
./PasteFerry/install.sh
  • Nécessite un bureau graphique : X11, ou Wayland avec XWayland, que GNOME, KDE et d'autres bureaux majeurs incluent par défaut.
  • Vous ne savez pas si vous possédez x64 ou ARM64? Exécutez uname -m dans un terminal : x86_64 signifie x64, aarch64 signifie ARM64.
  • Le .deb s'installe dans /opt/PasteFerry et ajoute PasteFerry au menu de l'application. Le tar.gz s'exécute partout où vous l'extrayez et install.sh l'ajoute au menu de l'application.
  • Une fois ouvert, cliquez sur Activer la synchronisation en arrière-plan ; à partir de là, il démarre lorsque vous vous connectez. GNOME n'affiche aucune icône de barre d'état par défaut, alors ouvrez la fenêtre à partir du menu de l'application.
  • Nécessite GTK 3. Testé sur Ubuntu 24.04 avec GNOME (Wayland).

Téléphone (application Android ou page Web)

Télécharger pour Android (APK)

Android 9 ou version ultérieure, téléphones arm64 . Android demande une fois avant de l'installer.

La page web (rien à installer)

Allumez Appareils › Transfert Web par téléphone sur l'ordinateur et scannez le code avec votre téléphone.

  1. Après avoir installé l'application, associez le téléphone à partir des appareils sur l'ordinateur, de la même manière que vous associez un autre ordinateur.
  2. Ou utilisez la page Web : activez Appareils > Transfert Web par téléphone sur l'ordinateur et scannez le code.
  3. Sur le téléphone, collez ce que vous avez copié et envoyez-le ; ce que vous copiez sur l’ordinateur apparaît dans les enregistrements du téléphone.
  • Le texte, les captures d’écran et les fichiers vont dans les deux sens.
  • Il n'existe pas d'application iPhone ou iPad : iOS ne permet pas aux applications de lire le presse-papiers en arrière-plan et sa distribution nécessite un certificat. Utilisez plutôt la page Web.
  • Le contenu est crypté entre le téléphone et l'ordinateur ; utilisez-le à la maison ou sur un réseau de confiance.

Plus

Serveur
Deux ordinateurs sur le même réseau n'ont pas besoin de serveur. Les moyens de se connecter à travers les réseaux figurent dans le démarrage rapide ; chaque guide a son propre serveur de téléchargement.
Sommes de contrôle
Les sommes de contrôle SHA-256 de chaque fichier se trouvent dans SHA256SUMS.
Quoi de neuf et anciennes versions
Consultez les notes de version pour connaître les modifications apportées à cette version ; les anciennes versions se trouvent sur GitHub publie.
