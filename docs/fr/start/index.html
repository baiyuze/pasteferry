PasteFerry / Démarrage rapide

Démarrage rapide

  1. Installez l'application
  2. Choisissez un moyen de vous connecter
  3. Paire
  4. Utiliser un téléphone

Étape 1

Installez l'application sur chaque ordinateur

Mac

  1. Téléchargez le DMG, ouvrez-le et faites glisser PasteFerry dans Applications.Il y en a un pour le silicium Apple et un pour Intel ; la page de téléchargement vous aide à choisir.
  2. Ouvrez-le depuis Applications.La première fois, macOS indique qu'il ne peut pas vérifier le développeur : accédez à Paramètres système → Confidentialité et sécurité et cliquez sur Ouvrir quand même en bas.
  3. Cliquez sur Activer la synchronisation en arrière-plan. Lorsque macOS vous demande comment accéder au presse-papiers et rechercher des appareils sur votre réseau local, autorisez les deux.
Télécharger pour Mac

Windows

  1. Exécutez PasteFerry-Setup.exe ; aucun droit d'administrateur n'est nécessaire.Si vous voyez «Windows a protégé votre PC », cliquez sur Plus d'informations, puis sur Exécuter quand même.
  2. Ouvrez PasteFerry et cliquez sur Activer la synchronisation en arrière-plan. Autorisez-le si le pare-feu Windows le demande. Après avoir fermé la fenêtre, elle continue de s'exécuter dans la zone de notification.
Télécharger pour Windows

Linux

  1. Sur Ubuntu, Debian et similaires, installez le .deb ; sur d'autres distributions, extrayez le tar.gz et exécutez le install.sh à l'intérieur.
  2. Ouvrez PasteFerry dans le menu de l'application et cliquez sur Activer la synchronisation en arrière-plan.
Télécharger pour Linux

Étape 2

Choisissez un moyen de vous connecter

Connectez en local ou choisissez le Service, votre serveur ou Tailscale à distance.

Service

  1. Activez Utiliser le service dans Paramètres → Connexion.
Activer le service →

100 Mo de relais par ordinateur et par jour. Transferts directs illimités.

Même réseau

  1. Connectez les deux ordinateurs au même réseau Wi-Fi ou filaire.
Même guide réseau →

Sans serveur

Votre propre serveur public

  1. Installez le serveur en suivant le guide.
  2. Saisissez l’adresse générée dans Paramètres → Connexion.
Guide du serveur public →

Votre serveur, relais illimité

Tailscale

  1. Installez Tailscale sur chaque ordinateur et connectez-vous au même compte.
  2. Sur l'autre ordinateur, exécutez tailscale ip -4 et notez l'adresse commençant par 100.
Guide Tailscale →

Sur les réseaux, pas de serveur

Étape 3

Associez vos ordinateurs

  1. Sur un ordinateur, ouvrez Appareils et cliquez sur Ajouter un appareil. Il affiche un code à 6 caractères, valable 5 minutes, et l'adresse de cet ordinateur en dessous.
  2. Sur l'autre ordinateur, choisissez Ajouter un appareil → Entrez un code. Avec Service, il n'y a pas d'adresse IP à saisir ; ce n'est que sur les sous-réseaux ou avec Tailscale que vous ouvrez le champ d'adresse et saisissez l'adresse de l'autre ordinateur.
  3. Les deux écrans affichent les deux mêmes lignes d’empreintes digitales. Vérifiez-les caractère par caractère, puis confirmez.Cela empêche toute personne intermédiaire de se faire passer pour votre appareil. Ne le sautez pas.

Utiliser un téléphone

Une fois les ordinateurs couplés ci-dessus, un téléphone peut se connecter à tout moment : scannez un code pour la page Web ou installez l'application Android .

La page web : rien à installer

  1. Ordinateur : ouvrez Appareils > Transfert Web du téléphone, allumez l'interrupteur et un code apparaît.
  2. Téléphone : scannez le code avec l'appareil photo ou un navigateur et donnez un nom au téléphone.
  3. Le navigateur du téléphone affiche ensuite les enregistrements de l'ordinateur : appuyez sur Copier pour envoyer un texte sur le téléphone ou utilisez Envoyer pour envoyer du texte, des photos et des fichiers vers l'ordinateur.

L'application Android : s'associe comme un autre ordinateur

  1. Téléphone : téléchargez l'APK et installez-le (autorisez l'installation à partir de sources inconnues lorsque cela vous est demandé).
  2. Ordinateur : Appareils → Ajouter un appareil → Afficher un code.
  3. Téléphone : saisissez le code et confirmez lorsque les deux empreintes correspondent.
  4. Ce que vous copiez sur l’ordinateur apparaît ensuite dans les enregistrements et le presse-papiers du téléphone.

Maintenant, copiez quelque chose.

Copiez du texte, une image ou un fichier sur un ordinateur et appuyez sur ⌘V or Ctrl+V on the other. Tout ce qui est copié de part et d'autre est dans l'historique.
