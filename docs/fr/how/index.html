PasteFerry

Comment ça marche

Que se passe-t-il lorsque vous copiez, comment les ordinateurs se connectent et que se passe-t-il lorsqu'ils ne le peuvent pas.

Que se passe-t-il lorsque vous copiez

Le texte, les images et les fichiers empruntent tous le même chemin.

  1. Avis

    Le service en arrière-plan voit que le presse-papiers a changé.

  2. Envoyer

    Les textes et fichiers jusqu'à 50 Mo sont immédiatement transmis. Les plus grands sont d'abord envoyés sous forme d'enregistrement.

  3. Coller

    L'autre ordinateur l'enregistre localement et le place dans le presse-papiers. Vous collez un vrai fichier.

Comment PasteFerry se connecte

Sur un même réseau, les ordinateurs se retrouvent directement. Sur différents réseaux, un serveur les introduit afin qu'ils puissent essayer de se connecter directement, et les relaye uniquement en cas d'échec. Le contenu est toujours crypté.

Directement sur les réseaux de bureau également

Les réseaux de bureau avec plusieurs liaisons montantes passaient par le relais. PasteFerry trouve chaque liaison montante et permet à l'autre côté de les essayer chacune.

Ce que ça fait

  • Un port partagé.Toutes les connexions utilisent le même port UDP .
  • Chaque liaison montante a été sondée.Il demande sept serveurs à la fois et obtient une adresse par liaison montante.
  • Tous envoyés de l’autre côté.L'autre ordinateur essaie chacun d'eux jusqu'à ce que l'un d'entre eux réussisse.
  • Réessayez directement en mode inactif.Le relais maintient le fonctionnement et passe en mode direct lorsqu'il est inactif.

Testé sur des configurations réseau réelles

Chaque commit est testé automatiquement sur des réseaux simulés.

Quand les choses tournent mal

Les cas courants sont traités.

Impossible de trouver l'autre ordinateur sur le réseau
Entrez son adresse lors de l'appairage ; on s'en souvient après.
Pas de connexion directe
Les données sont relayées via le serveur, toujours cryptées.
L'autre ordinateur se met en veille ou s'éteint
Il se reconnecte tout seul à son retour.
Déconnecté lors de l'envoi de fichiers
Le transfert reprend là où il s'était arrêté.
Un nom de fichier Windows ne permet pas
Les mauvais caractères deviennent des caractères pleine chasse, donc le nom se lit toujours de la même manière.
Copier un mot de passe
Sur Windows, tout ce qui est copié à partir d'un gestionnaire de mots de passe est ignoré.

Limite de synchronisation auto50 Mo par défaut, réglable de 1 Mo à 1 Go
Envoi de fichiersVers un appareil, n’importe quelle taille, fichiers ou dossiers entiers ; sur le réseau local via une liaison cryptée TCP (les deux parties ont besoin de 2.5.1), en revenant à WebRTC lorsque celle-ci n'est pas disponible ; WebRTC via Internet et relais ; reprend après une déconnexion ; SHA-256 par fichier. Mac mesuré sur VM Linux , 1 Go : 144,3 Mo/s ; la vitesse réelle dépend du réseau et des disques.
ContactsCode de contact à 7 caractères commençant par F, échangé sur le réseau local ou le Service, avec vérification optionnelle du code de sécurité ; les contacts ne peuvent s'envoyer que des fichiers et des images, avec une note de 200 caractères maximum, et chaque lot doit être accepté ; les contacts ne voient jamais votre presse-papiers, votre historique ou vos appareils ; les fichiers reçus perdent le bit exécutable et sont mis en quarantaine sur un Mac ; les deux côtés ont besoin de 2.6 ou version ultérieure
