隐私与必要数据

你决定是否使用官方服务

新安装默认只使用局域网。开启官方公网后才连接官方信令并记录必要接入统计；自建服务器模式不向官方上报。先尝试直连，失败后才申请中转授权和读取机器额度摘要。

仅保留服务所需数据

官方网关保留脱敏设备编号、首次及最近接入时间、每日中转用量、必要额度绑定和累计汇总。每日设备明细保留 90 天。统计表示官方服务设备数，不能代表真实人数或全部安装量。

内容与机器标识

剪贴板、文件内容与真实设备名通过设备间加密通道传输。网关不收集文件名、路径、用户名、MAC、UA 或行为轨迹；原始系统标识不上传，机器摘要仅用于中转额度归组，不能保证不可伪造。

网络可见性和额度

联网端点必然能看到临时网络地址和路由信息，但官方统计库及普通代理日志不保存这些信息。默认每日 100 MB 中转额度，上下行合计，北京时间零点重置；直连不消耗额度。开启后客户端只凭设备签名查询自己的额度，不申请中转，也不读取机器标识。关闭官方服务会停止其请求、轮询与中转通道。

检查更新

2.3.0 起，App 启动一分钟后和之后每天检查一次新版本：从 GitHub 和 Gitee 下载签过名的更新清单，请求里不带设备 ID、账号或其他标识，这些服务只能看到一次普通的下载和网络地址。可以在「设置 → 关于」关掉自动检查。新版本只有在你确认后才会安装，而且安装包必须与隔空贴发布密钥签名的清单里的校验值一致。

网站与可审计边界

本站使用既有的 Cloudflare Web Analytics，网站访问不等于软件用户统计。客户端、信令和 TURN 保持开源，公开所有官方网关协议与字段；私有生产后台的实际存储行为仍需要部署审计。
