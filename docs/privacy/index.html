隐私说明

一句话

你复制的内容、发送的文件和文件名、写的备注，都在你自己的设备之间端到端加密传输。我们看不到，也不保存。

服务（开启后）

新安装默认只用局域网。开启「服务」后，设备会连接官方服务器，以便在不同网络里找到彼此。我们会记录脱敏的设备编号、首次与最近接入时间和每天的中转用量。只有直连失败、需要中转时，才会生成一个隔空贴专用的机器摘要，用来让同一台电脑共用一份中转额度。真实设备名、原始系统标识和任何内容都不会上传。

检查更新

App 每天检查一次更新，从隔空贴官网、GitHub 和 Gitee 获取签过名的更新清单。请求官网时会附带版本、系统、语言，以及是否为当天、当周或当月的首次检查，用于提供对应的更新和规划后续版本；不附带设备 ID 或账号，不保存 IP。可以在「设置 → 关于」关闭自动检查。新版本只有在你确认后才会安装，并且必须与隔空贴发布密钥签名的清单一致。

好友

加了好友，对方能看到你设置的显示名和头像、发文件那台电脑的名称和系统，以及你用的是局域网、服务还是自建服务器（自建服务器只给出地址的摘要）。你的剪贴板、复制记录和其他设备不会给好友；好友发来的文件，要你点接受才会传。

官网

本站使用 Cloudflare Web Analytics，并自行汇总页面浏览量与下载点击（日期、页面路径、页面语言、下载的版本与文件）。不使用统计 Cookie 或持久访客标识，不保存 IP 或浏览器标识。浏览器开启 Do Not Track 或 Global Privacy Control 时，不发送本站自有的统计。

讨论与反馈

主动提交的昵称和文字会保存在服务器上用于审核及处理反馈，通过后公开。启用 AI 审核时，必要的文本会发送给第三方 AI 服务（如 DeepSeek），由其按自身数据处理条款处理；管理员也可查看和处理提交。浏览器保存草稿、提交记录和逐条查询凭证，最多保留 30 天。清除本地记录不会撤回服务器消息；可在原浏览器中撤回。未公开、已撤回和已下架内容保留 90 天后清理，公开内容保留至撤回或删除。防刷使用临时来源摘要，不保存原始 IP。请勿提交密码、密钥或个人隐私。

用途

上述信息用于提供和改进服务、发布更新、维护安全与防止滥用、统计与规划，以及遵守法律要求。我们不出售这些信息，也不用于广告。

第三方

GitHub、Gitee、Cloudflare，以及你自己选用的服务器，会按各自的隐私政策处理你与它们之间的请求。

保存期限

「服务」的设备每日明细保留 90 天；不含个人身份的每日汇总长期保存。

你的选择

你可以只用局域网、关闭「服务」、关闭自动检查更新，或者自建服务器。隔空贴的客户端与服务器代码开源，可以自行查阅。

免责与变更

隔空贴与「服务」按现状免费提供，中转额度与功能可能调整或暂停。因网络、设备、第三方服务或自建服务器造成的数据丢失或无法同步，我们不承担责任。本说明更新后在官网公布即生效，继续使用即表示同意更新后的内容。

联系我们
