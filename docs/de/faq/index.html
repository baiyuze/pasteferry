PasteFerry

Fragen

Sie können keine Antwort finden? Lassen Sie es uns wissen.

Wie unterscheidet sich das von der universellen Zwischenablage?

Die universelle Zwischenablage funktioniert nur zwischen nahegelegenen Apple-Geräten auf demselben Apple ID. PasteFerry kümmert sich nicht um Konten, funktioniert auf Mac, Windows und Linux sowie zwischen Zuhause und dem Büro.

Wie unterscheidet sich das von AirDrop?

AirDrop funktioniert nur zwischen Apple-Geräten in der Nähe. „Dateien senden“ von PasteFerry funktioniert zwischen Mac, Windows und Linux, auch über Netzwerke hinweg. Es kommuniziert nicht mit AirDrop; beide Seiten benötigen PasteFerry.

Brauche ich einen eigenen Server?

Nein. Im selben Netzwerk installieren und koppeln; Aktivieren Sie in verschiedenen Netzwerken den -Dienst. Sie können auch Ihren eigenen Server oder Tailscaleverwenden.

Keine öffentliche IP zu Hause. Kann ich zwischen Zuhause und dem Büro synchronisieren?

Ja, aktivieren Sie den -Dienst.

Kann der Server sehen, was ich kopiere?

Nein, der Inhalt ist Ende-zu-Ende-verschlüsselt. Weitere Informationen finden Sie in der Datenschutzerklärung .

Wie viel Staffel bekomme ich?

100 MB pro Computer und Tag; Direktverbindungen zählen nicht. Wenn es aufgebraucht ist, funktioniert Direct immer noch. Ohne Limit betreiben Sie mit Ihren eigenen Server.

Beide Computer befinden sich im selben Netzwerk. Warum können sie sich nicht finden?

Normalerweise befinden sie sich in unterschiedlichen Subnetzen oder werden von einer Firewall blockiert. Klicken Sie beim Koppeln auf In einem anderen Subnetz? und geben Sie die andere Adresse ein. Mehr im gleichen Netzwerkhandbuch.

Kann ich Dateien an den Computer einer anderen Person senden?

Ja. Fügen Sie sie ab 2.6 als Kontakt hinzu, keine Kopplung erforderlich; Die Übertragung beginnt, sobald sie akzeptiert haben. Kontakte können Ihre Zwischenablage oder Ihren Verlauf nicht sehen.

Was ist mit großen Dateien?

Beim Kopieren werden bis zu 50 MB gesendet. Größere Dateien werden abgerufen, wenn Sie sie benötigen, oder verwenden Sie „Dateien senden“, für das es keine Größenbeschränkung gibt.

Windows? Linux? iPhone?

Windows 10 und 11 und Linux auf x64 und ARM64. iPhone und iPad werden nicht unterstützt: iOS lässt nicht zu, dass Apps die Zwischenablage im Hintergrund lesen.

Warum warnt mich das System beim ersten Mal?

PasteFerry ist noch nicht von Apple notariell beglaubigt oder für Windows codesigniert. Klicken Sie auf einem Mac in den Systemeinstellungen → Datenschutz und Sicherheit auf „Trotzdem öffnen“; Klicken Sie unter Windows auf Weitere Informationen → Trotzdem ausführen. Dies machen Sie nur einmal.

Ist es kostenlos? Kann mein Unternehmen es nutzen?

Ja, kostenlos für Privatpersonen und Unternehmen. PasteFerry ist Open Source unter der GNU AGPL-3.0.

Verbindet es sich direkt mit Büronetzwerken mit mehreren Uplinks?

Ja. PasteFerry versucht jeden Uplink.

Warum werden .uuremote_-Dateien weiterhin angezeigt, während UU Remote ausgeführt wird?

Das war ein Fehler in älteren Versionen. Aktualisieren Sie auf die neueste Version.
