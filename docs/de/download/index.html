macOS

Apple-Chip (M1+) Intel

Auch als Universal-Version verfügbar.

Homebrew: brew install --cask baiyuze/tap/pasteferry. Installation und Updates

Schnellstart →

Nicht sicher, welcher Chip?

  • Klicken Sie auf das Apple-Menü in der oberen linken Ecke des Bildschirms und wählen Sie „Über diesen Mac“.
  • „Chip: Apple M1“ (oder M2, M3, M4…) bedeutet Apple-Silizium; „Prozessor: … Intel Core …“ bedeutet Intel.
  • Erfordert macOS 13 Ventura oder höher.

Linux

Ubuntu, Debian und Derivate

x64 ARM64 
sudo apt install ./PasteFerry-linux-amd64.deb

Andere Distributionen

x64 ARM64 
tar xzf PasteFerry-linux-amd64.tar.gz
./PasteFerry/install.sh
  • Benötigt GTK 3 sowie X11 oder Wayland mit XWayland.
  • uname -m ausführen: x86_64 = x64, aarch64 = ARM64.

Telefon (Android -App oder die Webseite)

Herunterladen für Android (APK)

Android 9 oder neuer · ARM64

Die Webseite (nichts zu installieren)

Aktivieren Sie „Geräte › Telefon-Webübertragung“ auf dem Computer und scannen Sie den Code mit Ihrem Telefon.

  1. Koppeln Sie das Telefon nach der Installation der App über Geräte auf dem Computer, genauso wie Sie einen anderen Computer koppeln.
  2. Fügen Sie auf dem Telefon ein, was Sie kopiert haben, und senden Sie es. Was Sie auf dem Computer kopieren, erscheint in den Telefonaufzeichnungen.
  • Handy und Computer müssen im selben Netzwerk sein.
  • Auf iPhone und iPad die Webversion nutzen.
