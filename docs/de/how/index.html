PasteFerry

Wie es funktioniert

Was passiert beim Kopieren, wie verbinden sich Computer und was passiert, wenn dies nicht möglich ist?

Was passiert beim Kopieren?

Texte, Bilder und Dateien nehmen alle denselben Weg.

  1. Hinweis

    Der Hintergrunddienst erkennt, dass sich die Zwischenablage geändert hat.

  2. Senden

    Texte und Dateien bis zu 50 MB werden sofort übernommen. Größere Exemplare werden zunächst als Datensatz versendet.

  3. Einfügen

    Der andere Computer speichert es lokal und legt es in der Zwischenablage ab. Sie fügen eine echte Datei ein.

Wie PasteFerry eine Verbindung herstellt

Im selben Netzwerk finden sich die Computer direkt zueinander. In verschiedenen Netzwerken stellt ein Server sie vor, sodass sie versuchen können, eine direkte Verbindung herzustellen, und leitet sie nur weiter, wenn dies fehlschlägt. Inhalte werden immer verschlüsselt.

Auch direkt in Büronetzwerken

Früher liefen Büronetzwerke mit mehreren Uplinks über das Relay. PasteFerry findet jeden Uplink und lässt die andere Seite jeden einzelnen ausprobieren.

Was es bewirkt

  • Ein gemeinsamer Port.Alle Verbindungen verwenden denselben UDP -Port.
  • Jeder Uplink wurde untersucht.Es fragt sieben Server gleichzeitig an und erhält eine Adresse pro Uplink.
  • Alle wurden auf die andere Seite geschickt.Der andere Computer probiert jeden aus, bis einer durchkommt.
  • Im Leerlauf direkt erneut versuchen.Das Relais sorgt dafür, dass alles funktioniert, und schaltet im Leerlauf auf Direktbetrieb.

Getestet an realen Netzwerk-Setups

Jeder Commit wird automatisch in simulierten Netzwerken getestet.

SzenarioErgebnis
Einzelner Uplink ↔ HeimrouterDirekt
Zwei Uplinks, Vorgängerversion (Steuerung)Relay
Vier Uplinks ↔ HeimrouterDirekt
Zwei Uplinks ↔ zwei UplinksDirekt
Zwei Uplinks ↔ NAT, das Ports randomisiertRelay
Zunächst blockiert, das Netzwerk wird später wiederhergestelltWeiterleiten, dann direkt
Kein Server, dasselbe SubnetzDirekt
Kein Server, voneinander isolierte SubnetzeKeine Verbindung

Gemessen: ein Mac in einem 4-Uplink-Büronetzwerk und einer zu Hause, zuvor mit 0,6 MB/s weitergeleitet. Jetzt verbinden sie sich direkt.

Einzelheiten finden Sie im -Designdokument (auf Chinesisch).

Wenn etwas schief geht

Die häufigsten Fälle werden behandelt.

Der andere Computer im Netzwerk kann nicht gefunden werden
Geben Sie beim Pairing die Adresse ein. man erinnert sich später daran.
Keine direkte Verbindung
Die Daten werden weiterhin verschlüsselt über den Server weitergeleitet.
Der andere Computer geht in den Ruhezustand oder bricht ab
Es stellt die Verbindung von selbst wieder her, wenn es zurück ist.
Beim Senden von Dateien wurde die Verbindung unterbrochen
Die Übertragung wird dort fortgesetzt, wo sie gestoppt wurde.
Ein Dateiname, der Windows nicht zulässt
Schlechte Zeichen werden zu Zeichen voller Breite, sodass der Name immer noch derselbe lautet.
Ein Passwort kopieren
Bei Windows wird alles, was von einem Passwort-Manager kopiert wird, übersprungen.
