2.13.1: Oberflächengröße für größere Texte und Symbole →

Ihre Computer. Ihr Smartphone.
Alles in Reichweite.

Auf einem Computer kopieren, auf einem anderen einfügen. Frühere Einträge wiederfinden und Fotos und Dateien zwischen Mac, Windows, Linux und Android übertragen – ohne gemeinsames Konto. Auf dem Smartphone lässt sich die Webversion per Code öffnen. Android und die Webversion funktionieren im selben Netzwerk.

PasteFerry herunterladen ▶ Sehen Sie sich die komplette Tour an 1:25

Version 2.13.1, kostenlos und Open Source. Für macOS 13 oder neuer, Windows 10 und 11, Linux (x64 und ARM64) sowie Android 9 oder neuer. Mit der neuen Oberflächengröße lassen sich Text, Symbole und Abstände gemeinsam vergrößern oder verkleinern.

So verbinden sich Ihre Computer

Im selben Netzwerk installieren und koppeln. Aktivieren Sie in verschiedenen Netzwerken den Dienst oder führen Sie Ihren eigenen Server oder Tailscale aus.

Funktioniert zwischen Zuhause und Büro

Dienst

Schalten Sie einen Schalter ein und Ihre Heim- und Bürocomputer werden synchronisiert, ohne dass Sie einen Server kaufen müssen.

Schalten Sie den Dienst ein → Nichts einzurichten

Gleiches Netzwerk

Zwei Computer am selben Router: App installieren, Pairing-Code eingeben, fertig. Kein Server erforderlich.

Gleicher Netzwerkführer → Ihr Server, unbegrenztes Relay

Ihr eigener öffentlicher Server

Eine Linux -VM mit einer öffentlichen IP; die kleinste Größe reicht aus. Jeder Computer verbindet sich damit und synchronisiert von überall aus.

Leitfaden für öffentliche Server → Über Netzwerke hinweg, kein Server

Tailscale

Installieren Sie Tailscale auf jedem Computer, melden Sie sich bei demselben Konto an und geben Sie beim Koppeln die Tailscale -Adresse des anderen Computers ein.

Tailscale -Anleitung →

Neu hier? Befolgen Sie die Kurzanleitung . Der Service ist kostenlos: 100 MB Relay pro Tag, Direktverbindungen unbegrenzt.
