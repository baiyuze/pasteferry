隔空贴 / 快速开始

快速开始

装好 App，选一种连接方式，再把两台电脑配对。同一个网络里几分钟就好，之后复制就会自动同步。

  1. 安装 App
  2. 选连接方式
  3. 配对

第 1 步

在每台电脑上安装 App

要同步的每台电脑都装一个，Mac、Windows、Linux 可以混用。

Mac

  1. 下载 DMG，打开后把隔空贴拖进「应用程序」。Apple 芯片与 Intel 芯片各有一版，下载页会告诉你怎么选。
  2. 从「应用程序」里打开。第一次会提示「无法验证开发者」：到「系统设置 → 隐私与安全性」，点页面下方的「仍要打开」。
  3. 点「启用后台同步」。系统询问是否允许读取剪贴板、能否查找本地网络上的设备时，都选择允许。
下载 Mac 版

Windows

  1. 运行 PasteFerry-Setup.exe，不需要管理员权限。提示「Windows 已保护你的电脑」时，点「更多信息」，再点「仍要运行」。
  2. 打开隔空贴，点「启用后台同步」。防火墙询问时选择允许。关掉窗口后它在右下角的托盘里继续运行。
下载 Windows 版

Linux

  1. Ubuntu、Debian 等安装 .deb；其他发行版解压 tar.gz，运行里面的 install.sh。
  2. 从应用菜单里打开隔空贴，点「启用后台同步」。
下载 Linux 版

第 2 步

选一种连接方式

同一网络里装好就能配对；不同网络里，开启官方服务即可，无需自建。也保留自建服务器与 Tailscale，按你的需要选择。

官方服务

  1. 在需要同步的每台电脑上安装最新版本，启用后台同步。
  2. 在每台电脑的「设置」中开启「使用官方服务」，阅读并确认必要统计说明。不用填写官方域名或端口。
  3. 一台生成配对码，另一台输入；核对两边的安全指纹后确认。已有配对关系可以继续使用。

新安装默认关闭。开启后记录必要接入统计；仅申请中转时派生项目专用机器摘要。真实设备名、原始系统标识和复制内容不会作为统计上传。完整字段与保留期限见隐私说明。

开启官方服务 →
先直连，再中转
官方信令只帮助在线设备交换连接信息。客户端先用 STUN 探测和打洞；本轮直连失败后，才申请官方中转。传输内容始终端到端加密。
直连不消耗中转额度
当前默认每机器额度组每日 100 MB 中转流量，上传与下载合计，北京时间零点重置。重新安装不会保证获得新额度。开启后用量页即显示今日额度、剩余量与更新时间，不必先用中转，并列出每台设备当前是直连还是中转；额度用尽仍可直连。额度与服务可用性可能调整，以客户端显示为准。

同一网络

  1. 每台电脑装好 App，点「启用后台同步」。
  2. Windows 防火墙询问时选择允许；macOS 询问能否查找本地网络上的设备时，也选择允许。
  3. 一台显示配对码，另一台输入它，核对指纹。不在同一网段时，再输入配对码下面显示的地址，见同一网络教程。

不需要填服务器地址。

同一网络教程 →
适合
电脑都在同一个 Wi‑Fi 或有线网络里，比如家里或办公室。
要准备
什么都不用。每台电脑装好 App 就行。
要注意
离开这个网络就不同步，回来后自动恢复。公司里有线和无线不在同一网段时，配对时多输一个地址。

自建公网服务器

  1. 在云厂商的安全组里放行 TCP 8787、UDP 3478 和 UDP 32768–60999。
  2. ssh 登录服务器，下载并运行安装脚本，带上它的公网 IP：sudo ./install.sh 公网IP。
  3. 在每台电脑的「设置」里填服务器地址 ws://公网IP:8787/signal，按回车，再配对。

在浏览器里打开 http://公网IP:8787/healthz，能看到 ok 就装好了。

公网服务器部署教程 →
适合
自己管理容量与部署
要准备
一台有公网 IP 的 Linux 云主机，最低配置就够，需要 root。
要注意
云主机要花钱。打不通直连时走中转，速度受服务器带宽限制。国内域名没有备案时，客户端要填 IP。

Tailscale

  1. 每台电脑装上 Tailscale，登录同一个账号。
  2. 在要配对的那台电脑上运行 tailscale ip -4，记下 100 开头的地址。
  3. 配对时，输入配对码的那台点「不在同一网段？」，填上这个地址。

不需要服务器。Tailscale 地址不会变，只在配对时输入一次。

Tailscale 教程 →
适合
电脑在不同的网络里，又没有公网服务器。
要准备
每台电脑都装 Tailscale，登录同一个账号。
要注意
所有用隔空贴的电脑都要装 Tailscale 并保持连接。Tailscale 自己打不通时经境外中转，在国内会慢。

第 3 步

把两台电脑配对

每两台电脑之间配对一次，之后就不用再管了。

  1. 在一台电脑上打开「设备」，点「添加设备」，会显示一个 6 位配对码，5 分钟内有效，下面是这台电脑的地址。
  2. 在另一台电脑上点「添加设备 → 输入配对码」。官方服务无需填 IP；仅局域网跨网段或 Tailscale 配对时，展开地址栏填写对方地址。
  3. 两块屏幕会显示同样的两行安全指纹。逐字核对一致后，再点确认。这一步防止有人在中间冒充你的设备，不要跳过。

复制试试。

在一台电脑上复制文字、图片或文件，到另一台按 ⌘V 或 Ctrl+V。两边复制过的内容都在「复制记录」里。
