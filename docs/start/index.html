隔空贴 / 快速开始

快速开始

装好 App，选一种连接方式，再把两台电脑配对。同一个网络里几分钟就好。

  1. 安装 App
  2. 选连接方式
  3. 配对

第 1 步

在每台电脑上安装 App

要同步的每台电脑都装一个，Mac、Windows、Linux 可以混用。

Mac

  1. 下载 DMG，打开后把隔空贴拖进「应用程序」。Apple 芯片与 Intel 芯片各有一版，下载页会告诉你怎么选。
  2. 从「应用程序」里打开。第一次会提示「无法验证开发者」：到「系统设置 → 隐私与安全性」，点页面下方的「仍要打开」。
  3. 点「启用后台同步」。系统询问是否允许读取剪贴板、能否查找本地网络上的设备时，都选择允许。
下载 Mac 版

Windows

  1. 运行 PasteFerry-Setup.exe，不需要管理员权限。提示「Windows 已保护你的电脑」时，点「更多信息」，再点「仍要运行」。
  2. 打开隔空贴，点「启用后台同步」。防火墙询问时选择允许。关掉窗口后它在右下角的托盘里继续运行。
下载 Windows 版

Linux

  1. Ubuntu、Debian 等安装 .deb；其他发行版解压 tar.gz，运行里面的 install.sh。
  2. 从应用菜单里打开隔空贴，点「启用后台同步」。
下载 Linux 版

第 2 步

选一种连接方式

在同一个网络里，装好就能配对。不在一个网络，打开「服务」就行。想自己掌控，也可以自建服务器或用 Tailscale。

服务

  1. 每台电脑装好最新版，点「启用后台同步」。
  2. 在每台电脑的「设置 → 连接」里打开「使用服务」。
  3. 一台显示配对码，另一台输入，核对两边的安全指纹后确认。已经配对过的不用重新配。

新装的 App 默认不开。打开后，服务器会记录连接和计算额度所需的信息，不会收到你复制的内容和设备名。具体记了什么、存多久，见隐私说明。

开启「服务」 →
能直连就不中转
服务器先帮两台电脑交换连接信息，让它们尝试直接相连。大多数家庭和公司网络都能连上；实在连不上，才由服务器转发。不管哪种方式，内容都是加密的，服务器解不开。
中转每天 100 MB，直连不限
经服务器中转的流量，每台电脑每天 100 MB（上传下载合计），北京时间零点重置，重装 App 不会重置。直连不算在内，额度用完了直连照样能用。用量页能看到今天还剩多少，以及每台设备现在是直连还是中转。额度以后可能调整，以 App 里显示的为准。

同一网络

  1. 每台电脑装好 App，点「启用后台同步」。
  2. Windows 防火墙和 macOS「查找本地网络设备」的询问都选允许。
  3. 一台显示配对码，另一台输入，核对指纹。不在同一网段时，再填配对码下面的地址，见同一网络教程。

不用填服务器地址。

同一网络教程 →
适合
家里或办公室，两台电脑连同一个 Wi‑Fi 或有线网络。
要准备
不用准备，每台电脑装好 App 就行。
要注意
离开这个网络就不同步，回来自动恢复。有线和无线不在一个网段时，配对时多填一个地址。

自建公网服务器

  1. 在云厂商的安全组里放行 TCP 8787、UDP 3478 和 UDP 32768–60999。
  2. ssh 登录服务器，下载并运行安装脚本：sudo ./install.sh 公网IP。
  3. 每台电脑在「设置 → 连接」里填 ws://公网IP:8787/signal，按回车，再配对。

浏览器打开 http://公网IP:8787/healthz，显示 ok 就装好了。

公网服务器部署教程 →
适合
想自己掌控服务器，或者中转流量用得多。
要准备
一台有公网 IP 的 Linux 云主机，需要 root。
要注意
云主机要花钱；中转速度受它的带宽限制。国内域名没备案时，客户端要填 IP。

Tailscale

  1. 每台电脑装上 Tailscale，登录同一个账号。
  2. 在对方电脑上运行 tailscale ip -4，记下 100 开头的地址。
  3. 配对时点「不在同一网段？」，填上这个地址。

不需要服务器。Tailscale 地址不会变，配对时填一次就行。

Tailscale 教程 →
适合
已经在用 Tailscale，或者不想依赖任何服务器。
要准备
每台电脑都装 Tailscale，登录同一个账号。
要注意
Tailscale 要一直连着。它自己打不通时走境外中转，国内会慢。

第 3 步

把两台电脑配对

每两台电脑之间配对一次，之后就不用再管了。

  1. 在一台电脑上打开「设备」，点「添加设备」，会显示一个 6 位配对码，5 分钟内有效，下面是这台电脑的地址。
  2. 在另一台电脑上点「添加设备 → 输入配对码」。「服务」无需填 IP；仅局域网跨网段或 Tailscale 配对时，展开地址栏填写对方地址。
  3. 两块屏幕会显示同样的两行安全指纹。逐字核对一致后，再点确认。这一步防止有人在中间冒充你的设备，不要跳过。

复制试试。

在一台电脑上复制文字、图片或文件，到另一台按 ⌘V 或 Ctrl+V。两边复制过的内容都在「复制记录」里。
