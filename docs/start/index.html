隔空贴 / 快速开始

快速开始

  1. 安装 App
  2. 选连接方式
  3. 配对
  4. 手机怎么用

第 1 步

在每台电脑上安装 App

Mac

  1. 下载 DMG，将隔空贴拖入「应用程序」。
  2. 首次打开受阻时，到「系统设置 → 隐私与安全性」点「仍要打开」。
  3. 开启后台同步，允许剪贴板和本地网络权限。
下载 Mac 版

Windows

  1. 运行安装程序；SmartScreen 拦截时，点「更多信息 → 仍要运行」。
  2. 开启后台同步，并允许防火墙访问。
下载 Windows 版

Linux

  1. Ubuntu、Debian 等安装 .deb；其他发行版解压 tar.gz，运行里面的 install.sh。
  2. 从应用菜单里打开隔空贴，点「启用后台同步」。
下载 Linux 版

第 2 步

选一种连接方式

同一网络直接连接；跨网络请选择「服务」、自建服务器或 Tailscale。

服务

  1. 在「设置 → 连接」里打开「使用服务」。
开启「服务」 →

每台电脑每天 100 MB 中转流量，直连不限。

同一网络

  1. 两台电脑连接同一 Wi-Fi 或有线网络。
同一网络教程 →

无需服务器

自建公网服务器

  1. 按部署教程安装服务器。
  2. 在「设置 → 连接」中填入生成的服务器地址。
公网服务器部署教程 →

自己的服务器，中转不限量

Tailscale

  1. 每台电脑装上 Tailscale，登录同一个账号。
  2. 在对方电脑上运行 tailscale ip -4，记下 100 开头的地址。
Tailscale 教程 →

跨网络，不用服务器

第 3 步

把两台电脑配对

  1. 一台电脑打开「设备 → 添加设备」，显示配对码。
  2. 另一台输入配对码；跨网段或使用 Tailscale 时，补填对方地址。
  3. 核对两边的安全指纹一致后确认。

手机怎么用

手机与电脑连接同一网络，选择安卓 App 或网页版。

网页版：不用安装

  1. 电脑打开「设备 › 手机网页传输」。
  2. 手机扫码，输入设备名称。
  3. 查看复制记录，或发送文字、照片和文件。

安卓 App：像配电脑一样配对

  1. 手机：下载 APK 并安装（设置里允许安装未知来源的应用）。
  2. 电脑：「设备 → 添加设备 → 显示配对码」。
  3. 手机：输入配对码，核对两边的指纹一致后确认。
  4. 之后电脑复制的内容自动出现在手机的记录里并写入剪贴板。

复制试试。

在一台电脑复制，到另一台粘贴。
