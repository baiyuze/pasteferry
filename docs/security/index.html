服务器看不到你复制了什么

内容只有你的设备能解密，服务器看不到。

  • 没有账号，不存内容。设备身份是一把密钥，服务器不需要用户表。
  • 配对时核对指纹。两边显示同样的指纹，有人从中替换就会对不上。
  • 每条消息都带签名。服务器冒充不了你的设备。
  • 中转只转发密文。中转凭证 12 小时过期。
  • 局域网里也不暴露。广播的是每天都变的匿名标识，看不出是谁的电脑。
