隔空贴 / 下载

下载隔空贴

免费开源，当前版本 2.4.1。每台要同步的电脑各装一个，Mac、Windows、Linux 可以混用。

Windows

下载安装程序

在中国大陆下载慢？用 Gitee 国内镜像：安装程序 · 便携版

不想运行安装程序的话，可以下载便携版，解压后直接运行。

  1. 运行 PasteFerry-Setup.exe，装在当前用户目录下，不需要管理员权限。提示「Windows 已保护你的电脑」时，点「更多信息」，再点「仍要运行」。
  2. 打开隔空贴，点「启用后台同步」。防火墙询问时选择允许。
  • Windows 10 与 Windows 11，x64。
  • 安装程序约 23 MB，便携版约 29 MB。
  • 关掉窗口后，隔空贴在任务栏右下角的托盘里继续运行。

macOS

Apple 芯片（M1 及更新） Intel 芯片

在中国大陆下载慢？用 Gitee 国内镜像：Apple 芯片 · Intel 芯片 · 通用版

两种芯片都能用的通用版也在，体积大一倍。

  1. 打开下载的 DMG，把隔空贴拖进「应用程序」。
  2. 从「应用程序」里打开。第一次会提示「无法验证开发者」：到「系统设置 → 隐私与安全性」，点页面下方的「仍要打开」。
  3. 点「启用后台同步」。系统询问是否允许读取剪贴板、能否查找本地网络上的设备时，都选择允许。

不确定是哪种芯片？

  • 点屏幕左上角的苹果菜单，选「关于本机」。
  • 写着「芯片：Apple M1」（或 M2、M3、M4 等）的是 Apple 芯片；写着「处理器：… Intel Core …」的是 Intel 芯片。
  • 2020 年底以后买的 Mac 基本都是 Apple 芯片。选错了也不要紧，换另一个下载就行：Intel 版在 Apple 芯片的 Mac 上要先装 Rosetta，Apple 芯片版在 Intel 的 Mac 上打不开。
  • 需要 macOS 13 Ventura 及以上。

Linux

Ubuntu、Debian 及其衍生版

x64 ARM64 
sudo apt install ./PasteFerry-linux-amd64.deb

其他发行版

x64 ARM64 
tar xzf PasteFerry-linux-amd64.tar.gz
./PasteFerry/install.sh

在中国大陆下载慢？用 Gitee 国内镜像：.deb x64 · .deb ARM64 · tar.gz x64 · tar.gz ARM64

  • 需要图形桌面：X11，或者带 XWayland 的 Wayland 桌面，GNOME、KDE 等主流桌面默认都带。
  • 不确定是 x64 还是 ARM64：在终端运行 uname -m，显示 x86_64 是 x64，aarch64 是 ARM64。
  • .deb 装在 /opt/PasteFerry，出现在应用菜单里。tar.gz 解压到哪里都能运行，install.sh 把它加进应用菜单。
  • 打开后点「启用后台同步」，之后随登录自动启动。GNOME 默认不显示托盘图标，从应用菜单打开窗口。
  • 需要 GTK 3。在 Ubuntu 24.04 的 GNOME（Wayland）上实测过。
