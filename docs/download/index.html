下载隔空贴

免费开源 · 版本 2.13.2

Windows

下载安装程序

GitHub：安装程序 · 便携版

便携版（免安装）

快速开始 →

  • Windows 10 与 Windows 11，x64。

macOS

Apple 芯片（M1 及更新） Intel 芯片

GitHub：Apple 芯片 · Intel 芯片 · 通用版

也可下载通用版。

Homebrew：brew install --cask baiyuze/tap/pasteferry。安装与升级

快速开始 →

不确定是哪种芯片？

  • 在苹果菜单中打开「关于本机」。
  • 显示「芯片」选 Apple 芯片版；显示「Intel」选 Intel 版。
  • 需要 macOS 13 及以上。

Linux

Ubuntu、Debian 及其衍生版

x64 ARM64 
sudo apt install ./PasteFerry-linux-amd64.deb

其他发行版

x64 ARM64 
tar xzf PasteFerry-linux-amd64.tar.gz
./PasteFerry/install.sh

GitHub：.deb x64 · .deb ARM64 · tar.gz x64 · tar.gz ARM64

  • 需要 X11 或带 XWayland 的 Wayland 桌面，以及 GTK 3。
  • 运行 uname -m：x86_64 选 x64，aarch64 选 ARM64。

手机（安卓 App 或网页版）

下载安卓版（APK）

GitHub：安卓版

Android 9 及以上 · ARM64

网页版（不用安装）

电脑打开「设备 › 手机网页传输」，用手机扫码连接。

  1. 装好 App 后，在电脑的「设备」里像配对另一台电脑一样配对手机。
  2. 手机上复制的内容粘贴到隔空贴再发送；电脑复制的内容会自动出现在手机的记录里。
  • 手机与电脑需在同一网络。
  • iPhone、iPad 请使用网页版。
