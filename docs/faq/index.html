隔空贴

常见问题

没找到答案的话，欢迎反馈。

和 Mac 自带的「通用剪贴板」有什么区别？

通用剪贴板只在同一个 Apple ID 的苹果设备之间、离得近时有效。隔空贴不看账号，Mac、Windows、Linux 都行，家里和公司之间也能用。

和隔空投送有什么区别？

隔空投送只在附近的苹果设备之间能用。隔空贴的「隔空传送」Mac、Windows、Linux 互相都能发，不在一个网络也行。它不能和苹果的隔空投送互通，两边都要装隔空贴。

必须自己准备服务器吗？

不用。同一网络里装好就能配对；不在一个网络，打开服务就行。也可以用自建服务器或 Tailscale。

家里没有公网 IP，能在家和公司之间同步吗？

能，打开服务就行。

服务器能看到我复制的内容吗？

看不到，内容是端到端加密的。详见隐私说明。

中转额度有多少？

每台电脑每天 100 MB，直连不算。用完了直连照样能用；要不限量可以自建服务器。

在同一个网络里，为什么找不到另一台？

多半是不在同一个网段，或者被防火墙拦了。配对时点「不在同一网段？」填对方地址，详见同一网络教程。

能把文件发到别人的电脑上吗？

能。2.6 起加个好友就能发，不用配对，对方点接受才开始传。好友看不到你的剪贴板和复制记录。

大文件怎么处理？

50 MB 以内复制时就传好；更大的用时再取，或者用「隔空传送」直接发，不限大小。

支持 Windows 和 Linux 吗？iPhone 呢？

支持 Windows 10、11 和 Linux（x64、ARM64）。iPhone 和 iPad 暂不支持，iOS 不让 App 在后台读剪贴板。

为什么第一次打开时系统会拦一下？

还没有做 Apple 公证和 Windows 代码签名。Mac 上到「系统设置 → 隐私与安全性」点「仍要打开」；Windows 上点「更多信息」→「仍要运行」。只需要一次。

免费吗？公司能用吗？

免费，个人和公司都能用。隔空贴以 GNU AGPL-3.0 开源。

公司网络（双线、多出口）能直连吗？

能，隔空贴会把每个出口都试一遍。

开着 UU 远程时，为什么一直冒出 .uuremote_ 文件？

这是旧版本的问题，升级到新版就好了。
