隔空贴

常见问题

安装、连接、同步、费用。没找到答案的话，欢迎反馈。

和 Mac 自带的「通用剪贴板」有什么区别？

通用剪贴板只在同一个 Apple ID 的苹果设备之间有效，还要离得近。隔空贴不看账号，Mac、Windows、Linux 都能互通，家里和公司之间也能同步，复制过的内容还能在复制记录里找回来。

如果你只有两台同一个 Apple ID 的 Mac，平时主要复制文字，系统自带的就够用了。

和隔空投送有什么区别？

隔空投送只在苹果设备之间、离得近时能用，每次都要对方点接收。隔空贴的「隔空传送」在 Mac、Windows、Linux 之间都能发，不在一个网络也行，大文件断了能接着传。自己的电脑之间不用点接收；发给好友时，对方点一下接受。

必须自己准备服务器吗？

不用。两台电脑在同一个网络里，装好就能配对。不在一个网络，在两台电脑上打开服务就行，不用买云主机，也不用填地址。

想自己掌控的话，也可以用自建服务器或 Tailscale。

家里没有公网 IP，能在家和公司之间同步吗？

能。打开服务，两台电脑会先尝试直接相连，大多数家庭宽带和公司网络都连得上；连不上时经服务器转发，每天有 100 MB 额度。

服务器能看到我复制的内容吗？

看不到。内容只有你的设备能解密：直连时不经过服务器，走中转时服务器转发的也只是加密后的数据。

用「服务」时，服务器会记录连接和计算额度所需的信息，具体见隐私说明。客户端和服务器的代码都是公开的。

中转额度有多少？用完了怎么办？

每台电脑每天 100 MB，上传下载合计，北京时间零点重置。直连不算额度，用完了直连照样能用。额度以后可能调整，以 App 里显示的为准。

中转用得多的话，可以自建服务器，不限量。

在同一个网络里，为什么找不到另一台？

先确认两台真的在同一个网段：公司里有线和无线、访客网络、开了「AP 隔离」的 Wi‑Fi 常常不互通。这时在输入配对码的那台点「不在同一网段？」，填上另一台配对码下面显示的地址。

Windows 上，第一次运行时防火墙会询问，要选允许；点过取消的话，在「设置 → 连接」里点「放行」。Mac 上，在「系统设置 → 隐私与安全性 → 本地网络」里打开 PasteFerry Daemon。更多见同一网络教程。

能把文件发到别人的电脑上吗？

能。2.6 起可以加好友：对方在「好友」页点「添加好友」给出好友码，你输入，两边确认就加上了，不用配对。之后把文件拖到对方头像上，对方点接受就开始传，还能附一句备注。

好友之间只传文件和图片，看不到彼此的剪贴板、复制记录和设备。谁能给你发，在隔空传送页底部选：均不允许、仅限好友或所有人（只在局域网，10 分钟后自动关掉）。

大文件怎么处理？

50 MB 以内的内容，复制时就已经传到另一台，那边直接粘贴。更大的文件先只同步一条记录，需要时在复制记录里点「接收」再传。这个上限可以在设置里改。

想把大文件直接发到某一台，用「隔空传送」：不限大小，断了接着传。

公司网络（双线、多出口）能直连吗？

能。这类网络有好几个出口，隔空贴会把每个出口的地址都探出来交给对方逐个尝试。实测公司 4 个出口的网络和家里宽带之间可以直连。对方的路由器每次随机换端口时，还是只能中转。

支持 Windows 和 Linux 吗？iPhone 呢？

支持 Windows 10、11（x64）和 Linux（x64、ARM64，X11 或带 XWayland 的 Wayland 桌面，GNOME、KDE 默认都带）。复制的文件粘贴出来就是真实文件，能直接粘进资源管理器、文件管理器、微信、Office。

iPhone 和 iPad 暂不支持：iOS 不让 App 在后台读剪贴板，做不到复制完就同步。

为什么第一次打开时系统会拦一下？

隔空贴还没有做 Apple 公证和 Windows 代码签名，这两样都要每年付费买证书。

Mac 上到「系统设置 → 隐私与安全性」，点页面下方的「仍要打开」；Windows 上在「Windows 已保护你的电脑」里点「更多信息」，再点「仍要运行」。只需要一次。

免费吗？公司能用吗？

免费。隔空贴以 GNU AGPL-3.0 开源，个人和公司都能免费用、免费改。如果你分发它，或者把改过的版本放到网上给别人用，需要同样公开源码。

开着 UU 远程时，为什么一直冒出 .uuremote_ 文件？

UU 远程会往剪贴板里写临时占位文件，1.3.2 以前的隔空贴把它们当成普通文件同步。升级到新版就好了，正常的空文件、隐藏文件不受影响。
