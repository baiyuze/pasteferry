隔空贴

常见问题

安装、连接、同步、费用。没找到答案的话，欢迎反馈。

UU 远程开启时，为什么不断出现 .uuremote_ 文件？

UU 远程会在系统剪贴板里写入临时占位文件，旧版隔空贴把它们当成普通文件反复记录和转发。1.3.2 在发送和接收时过滤已确认的占位命名，启动时清理纯占位记录。正常空文件、隐藏文件和大文件不受此规则影响。50 MB 只决定是否自动传输，与 UU 的 UDP P2P 设置无关。建议两端都升级；其他软件如果也同步剪贴板，仍可能产生普通内容的重复记录。

和 macOS 自带的「通用剪贴板」有什么区别？

Mac、Windows、Linux 互通，文字、图片、文件、整个文件夹都可以，不要求同一个账号。现在开启官方服务就能跨网络同步，无需自己搭服务器。优先直连，始终端到端加密。

如果你的两台 Mac 是同一个 Apple ID、总在一起、主要复制文字，系统自带的已经够用了。

服务器会看到我复制的内容吗？

服务器无法解密复制内容：直连时内容不经过中转服务器；中转时转发的是端到端加密数据包。官方服务保留必要设备与用量统计，详见隐私说明。客户端和服务器源码公开，但源码可审计不等于对私有生产存储行为的证明。

公司网络（双线、多出口）能直连吗？

能。这类网络按目标地址选出口，隔空贴会在同一个端口上向多台服务器探测，拿到每个出口的地址一并发给对端，对端逐个尝试。实测公司 4 个出口与家用宽带之间可以直连。对端是端口随机分配的 NAT 时仍会走中转。

必须自己准备服务器吗？

不需要。不同网络时，在两台电脑上开启官方服务即可，不用购买云主机或填写地址。默认关闭，当前提供每日 100 MB 中转额度，直连不消耗此额度。局域网、自建服务器与 Tailscale 继续可用。

家里没有公网 IP，能在家和公司之间同步吗？

不需要。不同网络时，在两台电脑上开启官方服务即可，不用购买云主机或填写地址。默认关闭，当前提供每日 100 MB 中转额度，直连不消耗此额度。局域网、自建服务器与 Tailscale 继续可用。

在同一个网络里，为什么找不到另一台？

先看两台是不是真的在同一个网段：公司里有线和无线、访客网络、开了「AP 隔离」的 Wi‑Fi 常常不互通，局域网发现过不去。这时在输入配对码的那台点「不在同一网段？」，填上另一台配对码下面显示的地址。

Windows 上，第一次运行时防火墙会询问，要选允许；点过取消的话，在「设置 → 局域网」里点「放行」。Mac 上，要在「系统设置 → 隐私与安全性 → 本地网络」里打开 PasteFerry Daemon。更多见同一网络教程。

支持 Windows 和 Linux 吗？iPhone 呢？

支持 Windows 10 与 Windows 11（x64），与 Mac 互通。复制的文件在 Windows 上粘贴出来就是真实文件，能直接粘进资源管理器、微信、Office。

也支持 x64 与 ARM64 的 Linux 桌面：X11，或者带 XWayland 的 Wayland 桌面（GNOME、KDE 等默认都带）。复制的文件能直接粘进文件管理器。

iPhone 和 iPad 暂不支持：iOS 不允许 App 在后台监听剪贴板，做不到复制后立即同步。

为什么第一次打开时系统会拦一下？

隔空贴还没有经过 Apple 公证，Windows 版也还没有代码签名，两者都需要每年付费的证书。

Mac 上到「系统设置 → 隐私与安全性」，点页面下方的「仍要打开」；Windows 上在「Windows 已保护你的电脑」提示里点「更多信息」，再点「仍要运行」。都只需要这一次。

大文件怎么处理？

默认 50 MB 以内的内容在你复制时就推送到另一台电脑，那边可以直接粘贴；更大的文件只同步一条记录，需要时在复制记录里点「拉取到本机」再传。上限可以在设置里调整。

免费吗？公司能用吗？

免费。隔空贴以 GNU AGPL-3.0 开源，个人和公司都可以免费使用和修改。分发它、或通过网络提供修改过的版本时，需要以同样的许可公开源码。

官方中转无限量吗？

当前默认每机器额度组每日 100 MB 中转流量，上传与下载合计，北京时间零点重置。重新安装不会保证获得新额度。用量页显示实际额度、剩余量与更新时间；额度用尽仍可直连。额度与服务可用性可能调整，以客户端显示为准。
