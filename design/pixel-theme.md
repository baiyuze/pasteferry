> 设计稿 · 2026-11-06 · 已定稿并实现（第 11 节）
>
> - 样稿：`design/pixel-theme-mockup.html`（浏览器打开，字体用 `ui/assets/fonts/` 里的像素字体）。

## 1. 第一版的问题

第一版（深蓝星空、黑底白框、红金配色）有像素感，但是显得旧、显得吵：

| 问题 | 表现 |
|---|---|
| 对比全开 | 深色是饱和的深蓝底、纯黑面板、纯白边框，每处都是最大对比，眼睛没处休息 |
| 没有层级 | 面板、按钮、输入框、列表都描同样 2px 的粗边，分不出哪个能点、哪个只是容器 |
| 原色太多 | 马力欧红、金币黄、草绿同时出现，像儿童玩具，不像工具 |
| 背景太花 | 星空、方格纸铺满内容区，和文字抢注意力 |
| 字只有两档 | 12 和 24，加上假粗体，标题、正文、说明靠颜色硬分 |

## 2. 参考：现代的像素组件库

- **[8bitcn/ui](https://github.com/TheOrcDev/8bitcn-ui)**（MIT，基于 shadcn/ui）：配色直接用 shadcn 的中性色，深色是 `oklch(0.145 0 0)` 的近黑灰，边框用低对比的 `ring` 色而不是白色。像素感只在三处：6px 的方块边框（四角留空）、按钮上下各一条 20% 的明暗带、Press Start 2P 字体。它另外提供 Gameboy、Nintendo、Zelda 等 20 多套配色，都是在同一套结构上换颜色。
- **[Pixelact UI](https://github.com/pixelact-ui/pixelact-ui)**（基于 shadcn/ui）：同样是中性底色。按钮右边、下边各一条 4px 的暗边（按钮色混 30% 黑），像实体按键；按下时整个按钮下移 3px。

共同点就是这次的方向：**结构像素化，颜色现代化**。像素感来自形状与字体，颜色负责层次与舒适。

## 3. 设计原则

1. **颜色退后，形状说话**。底色用中性灰分层，强调色只出现在主按钮、选中、进度、链接上。
2. **边框分三级**，看边框就知道是什么（第 5 节）。
3. **立体感用斜面，不用黑影**。按钮像实体按键（上亮下暗），输入框是凹下去的槽，弹层才有投影。
4. **装饰只放在空白处**。空状态、关于页、雷达里可以有像素小插画；有内容的地方背景是干净的纯色。
5. **字少几档，但每档都清楚**。层级靠字号、颜色深浅和像素标记（▸、方块项目符号），不用假粗体。

## 4. 配色

### 4.1 深色「石墨」（推荐）

接近 Linear、Vercel 的暗色：近黑的冷灰，层与层之间亮度差 4% 到 6%。

| 角色 | 色值 | 用在 |
|---|---|---|
| background | `#111215` | 内容区 |
| sidebar | `#0C0D0F` | 侧边栏，比内容区更深一层 |
| surface | `#17191D` | 分组容器、列表 |
| raised | `#1F2227` | 按钮、选中行、菜单（新角色） |
| border | `#2A2D34` | 一级边框、分隔线 |
| borderStrong | `#3C414B` | 二级、三级边框（新角色） |
| text | `#E6E8EB` | 正文 |
| textDim | `#9AA0AA` | 说明 |
| textFaint | `#5F6570` | 提示、占位 |
| accent | 见 4.3 | |
| online / warning / danger | `#4ADE80` / `#FBBF24` / `#F87171` | 状态，降饱和的亮色 |

### 4.2 浅色「纸」

暖一点的白，不是米黄。

| 角色 | 色值 |
|---|---|
| background | `#F5F5F2` |
| sidebar | `#ECECE7` |
| surface | `#FFFFFF` |
| raised | `#FAFAF8` |
| border | `#DCDCD5` |
| borderStrong | `#1C1D20`（按钮、弹层用深色描边，像素感最强的地方） |
| text / textDim / textFaint | `#1C1D20` / `#5E626A` / `#9A9DA4` |
| online / warning / danger | `#15803D` / `#B45309` / `#DC2626` |

### 4.3 强调色（待定，样稿里都有）

| 选项 | 深色 / 浅色 | 感觉 |
|---|---|---|
| **像素绿**（推荐） | `#3DDC97` / `#0E9F6E` | 清新，带一点 Game Boy 与《我的世界》的影子，又不土；深色下配深色字 |
| 电光蓝 | `#5B9DFF` / `#2563EB` | 和现在默认主题的蓝一脉相承，最稳 |
| 像素紫 | `#A78BFA` / `#7C3AED` | 更潮，游戏感强 |
| 珊瑚橙 | `#FF8A5B` / `#EA580C` | 温暖、醒目 |

将来用户自定义主题时，换的主要就是这一个颜色。

## 5. 边框与立体感：三级

所有边框都是 2px，四角留空一格（像素圆角）。

| 级别 | 用在 | 边框 | 立体感 |
|---|---|---|---|
| 0 级 | 列表行、设置行 | 无，行间是 2px 的虚线分隔（隔一格画一格） | 无 |
| 1 级 | 分组容器、卡片 | `border`，低对比 | 无投影 |
| 2 级 | 按钮、输入框、分段控件、开关 | `borderStrong` | 按钮：上、左 2px 亮边（白 8%），下、右 2px 暗边（黑 30%）；按下时下移 2px、明暗互换。输入框反过来，是凹槽 |
| 3 级 | 对话框、菜单、快捷粘贴窗口、悬停预览 | `borderStrong` | 向右下错开 4px 的投影（黑 45%），只有这一级有投影 |

## 6. 文字

### 6.1 全部像素字（推荐）与混排（待定）

- **全部像素字**：正文、标题、按钮都用缝合像素字体。最有味道；复制记录里的长文字、文件名也是点阵字，密度大时稍累。
- **混排**：标题、导航、按钮、标签、数字用像素字；复制下来的内容、文件名、说明文字用系统字体。读起来最轻松，但像素感弱一半。

推荐全部像素字，但给复制内容留一个开关（「记录内容用系统字体」）。

### 6.2 字号

| 档 | 字号 | 用在 |
|---|---|---|
| 标题 | 24 | 页面标题 |
| 正文 | 12 | 正文、按钮、导航 |
| 小字（待定） | 10 | 时间、大小这类元数据。需要再打包 10px 的点阵字体，约 4 MB；不加的话小字也是 12，靠颜色区分 |

- 不用粗体。分组标题用 `textDim` 加一个 4px 的强调色方块作前缀（▪ 同步），像游戏菜单的小标题。
- 行高取整数像素：正文 18（1.5 倍），标题 32。
- 数字与代码用等宽的像素字体。

## 7. 组件

| 组件 | 做法 |
|---|---|
| 侧边栏选中项 | 不再整块填色。`raised` 底，左边一条 4px 的强调色竖条，图标变强调色 |
| 主按钮 | 强调色底、斜面，深色下字是 `#0C0D0F` |
| 次按钮 | `raised` 底、`borderStrong` 边、斜面 |
| 文字按钮 | 无边框，悬停时出现 2px 的下划虚线 |
| 输入框 | 凹槽（上、左暗，下、右亮），聚焦时边框变强调色，光标是闪烁的方块 |
| 分段控件 | 槽是凹的，选中的一段是凸起的按钮 |
| 开关 | 方形槽，滑块是一个 8×8 的凸起方块；开时槽填强调色 |
| 复选框 | 方框，勾是像素画的 ✓ |
| 进度条 | 按格子填：每格 6px、格间 2px，不是平滑的条 |
| 列表行 | 悬停时整行 `raised` 底；选中时左边 4px 强调色竖条 |
| 角标（数字） | 强调色小方块，深色字 |
| 工具提示 | `inverse` 底，3 级边框，带一个像素小三角 |
| 滚动条 | 方形滑块，`borderStrong` 色 |
| 对话框 | 3 级；标题栏下面一条 2px 虚线 |

## 8. 图标与插画

- 图标继续用 Pixelarticons，16px 时一格一个像素。颜色跟文字的三档走。
- 新增一套 32×32 的像素小插画，只放在空状态、引导页、关于页：空的剪贴板、两台电脑之间飞的纸飞机、一只拿着文件的小猫之类（待定，需要画）。
- App 图标出一个像素版，在侧边栏左上角用。

## 9. 背景与彩蛋

- 内容区是干净的纯色，去掉星空与方格纸。
- 雷达页的轨道用低对比的点线圈，波纹一格一格往外跳。
- 草方块那一排不放在侧边栏常驻，改成彩蛋（待定）：比如传输完成时，进度条下面长出一株像素小草；或者只放在「关于」页。

## 10. 动效

- 悬停、按下：4 帧跳变，按钮按下下移 2px。
- 弹层出现：从中心按 3 档放大，不淡入。
- 加载：方块旋转改成 4 个方格依次点亮。
- 系统开了「减少动态效果」时都不做。

## 11. 定稿（2026-11-06）

1. 深色用「石墨」，强调色用像素绿（用户确定）。浅色「纸」的像素绿加深到 `#08875B`，白底上作文字也够清楚；
   浅色的选中底用 `#FAFAF8`，和侧边栏拉开差别。
2. 以下三项用户没有表态，先按推荐做，之后可以再改：
   - 全部像素字，暂不加 10px 小字；
   - 去掉星空、方格纸与草方块，彩蛋以后再定；
   - 暂不画空状态插画。
3. 已实现：两套配色、三级边框、按钮斜面（按下时明暗互换）、凹下的输入框与分段槽、只给浮层的硬投影、
   侧边栏与快捷粘贴窗口的强调色竖条、分组里的点线分隔、分组标题前的小方块、方块开关、点线雷达。
   点阵字体的字重标成 700，界面要粗体时不会被描粗。
4. 补齐的细节：
   - 格子进度条（`ThemedProgressBar`）：界面里 10 处进度条都换成它，默认主题仍是原来的进度条；不知道进度时三格亮块往右跳；
   - 列表行之间的点线分隔（`ThemedDivider`）：复制记录、收藏、好友、手机端的列表都用它；
   - 按钮按下时文字下沉 2px，斜面明暗互换；
   - 文字按钮悬停时出现点线下划线；
   - 像素版 App 图标（`PixelAppMark`）：16×16 点阵画，前页用强调色，只按整数倍放大。

## 12. 画面、插画与动效（方案，待定）

> 样稿：`design/pixel-theme-art-mockup.html`（会动，浏览器打开）。

第一版定稿后的反馈是「太单调」。在不影响阅读的前提下加三样东西。场景与插画都由程序按规则画（山脊用几条正弦叠加、星星与树按坐标算随机数、插画用方块拼），不打包图片，窗口多大都清晰。

### 12.1 场景

| 位置 | 深色 | 浅色 |
|---|---|---|
| 页眉（每页标题后面，约 200px 高） | 远山三层、松树、月亮、星星、绿色萤火虫 | 太阳、方块云、丘陵、树 |
| 侧边栏最底下（约 96px） | 草地、小帐篷、篝火（火苗跳动） | 草地、小房子、花 |

- 场景只在页眉，底部用像素抖动（4×4 Bayer）渐隐进背景色；列表、设置这些有内容的地方仍是纯色。
- 颜色都是低对比的灰蓝、灰绿，标题叠在上面照样清楚；强调色只出现在萤火虫这类小点上。
- 将来的「自定义背景图」（`design/themes.md` 第 7 节）放在同一个位置：用户的图替换页眉场景。

### 12.2 插画

空状态、引导、出错的地方各放一张 24×24 左右的插画，按 4 倍放大：空剪贴板、两台没连上的电脑、纸飞机、宝箱（传输完成）、断开的云（连不上服务器）、两个小人（还没有好友）。

### 12.3 动效

| 动效 | 用在 |
|---|---|
| 菜单光标 ▶ 一闪一闪 | 侧边栏选中项、悬停的列表行 |
| 四格依次点亮 | 加载中，代替转圈 |
| 像素星星迸开 | 传送完成、配对成功 |
| 一格一格上下跳 | 拖着文件经过的设备 |
| 纸飞机从本机飞向对方 | 隔空传送发送中 |
| 像素提示条分 3 帧滑入 | 放入剪贴板、复制成功 |
| 星星闪、萤火虫闪、篝火跳 | 页眉与侧边栏场景，每秒 2 到 4 帧 |
| CRT 扫描线（可选） | 整个窗口叠一层很淡的扫描线，默认关 |

都按 4 到 8 帧跳变。系统开了「减少动态效果」时全部停用。场景只在可见时动，窗口在后台时不重画，省电。
